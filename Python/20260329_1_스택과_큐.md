# TIL - 스택과 큐

> 원본 자료: `-`  
> 학습 주제: 데이터의 처리 구조, 스택, 큐, LIFO, FIFO

## 오늘 배운 내용

데이터를 저장하는 방법은 단순히 변수나 리스트에 값을 넣는 것에서 끝나지 않는다.  
프로그램에서는 **데이터가 들어오고 나가는 순서**가 중요할 때가 많다.

이번 수업에서는 대표적인 데이터 처리 구조인 **스택(Stack)** 과 **큐(Queue)** 를 배웠다.

- 스택은 **가장 나중에 들어온 데이터가 가장 먼저 나가는 구조**이다.
- 큐는 **가장 먼저 들어온 데이터가 가장 먼저 나가는 구조**이다.

즉, 스택과 큐의 가장 큰 차이는 **데이터를 꺼내는 순서**이다.

## 스택(Stack)

### 1. 스택이란?

스택은 데이터를 차곡차곡 쌓아 올리는 구조이다.

```text
stack = 쌓아 놓은 더미
```

예를 들어 책을 아래에서 위로 쌓아 놓았다고 생각하면 된다.  
가장 위에 있는 책을 먼저 꺼낼 수 있고, 가장 아래에 있는 책은 나중에 꺼낼 수 있다.

스택은 **LIFO** 구조라고 한다.

```text
LIFO = Last In First Out
     = 마지막에 들어온 것이 가장 먼저 나감
```

### 2. 스택의 동작 방식

스택에 데이터가 들어간 순서가 다음과 같다고 하자.

```text
A → B → C
```

그러면 꺼내는 순서는 다음과 같다.

```text
C → B → A
```

즉, 가장 마지막에 들어온 `C`가 가장 먼저 나온다.

### 3. 스택의 기본 연산

스택에서는 데이터를 넣는 작업과 빼는 작업이 중요하다.

| 연산 | 의미 |
|---|---|
| `push` | 스택에 데이터를 넣음 |
| `pop` | 스택에서 데이터를 꺼냄 |
| `top` | 가장 위에 있는 데이터 또는 다음에 들어갈 위치를 가리킴 |

수업 자료에서는 `top`을 **비어 있는 위치**로 설명한다.  
다만 일반적인 설명에서는 `top`을 **가장 위에 있는 데이터**라고 설명하기도 한다.

중요한 것은 `top`이 스택에서 **데이터를 넣고 빼는 위치를 관리하는 기준**이라는 점이다.

## 파이썬 리스트로 스택 구현하기

파이썬에서는 리스트를 이용해 스택을 쉽게 구현할 수 있다.

```python
stack = []

stack.append("A")  # push
stack.append("B")  # push
stack.append("C")  # push

print(stack)        # ['A', 'B', 'C']

print(stack.pop())  # C
print(stack.pop())  # B
print(stack.pop())  # A
```

실행 흐름은 다음과 같다.

```text
push A → [A]
push B → [A, B]
push C → [A, B, C]

pop → C
pop → B
pop → A
```

리스트의 `append()`는 뒤쪽에 데이터를 추가하고, `pop()`은 기본적으로 뒤쪽 데이터를 꺼낸다.  
그래서 파이썬 리스트는 스택을 표현하기에 적합하다.

## 스택이 사용되는 예

### 1. 되돌리기 기능

문서 작성 프로그램이나 그림판에서 `Ctrl + Z`를 누르면 이전 작업으로 되돌아간다.

이때 최근 작업 기록을 스택에 저장해 두면, 가장 최근 작업부터 하나씩 꺼내서 되돌릴 수 있다.

```text
작업 순서: 글자 입력 → 색 변경 → 그림 삽입
되돌리기: 그림 삽입 취소 → 색 변경 취소 → 글자 입력 취소
```


### 2. 미로 탐색

로봇이 미로를 탐색할 때 이동 경로를 스택에 저장하면,  
막다른 길을 만났을 때 최근에 지나온 길부터 되돌아갈 수 있다.

```text
이동 순서: 입구 → A → B → C
되돌아오기: C → B → A → 입구
```

## 큐(Queue)

### 1. 큐란?

큐는 줄을 서는 구조와 비슷하다.

먼저 줄을 선 사람이 먼저 서비스를 받고, 나중에 줄을 선 사람은 나중에 서비스를 받는다.

큐는 **FIFO** 구조라고 한다.

```text
FIFO = First In First Out
     = 먼저 들어온 것이 먼저 나감
```

### 2. 큐의 동작 방식

큐에 데이터가 들어간 순서가 다음과 같다고 하자.

```text
A → B → C
```

큐에서 데이터가 나오는 순서도 같다.

```text
A → B → C
```

즉, 큐는 들어간 순서와 나오는 순서가 같다.

### 3. 큐의 기본 연산

| 연산 | 의미 |
|---|---|
| `enqueue` | 큐에 데이터를 넣음 |
| `dequeue` | 큐에서 데이터를 꺼냄 |
| `front` | 큐의 맨 앞 데이터 |
| `rear` | 큐의 맨 뒤 데이터 |

큐에서는 데이터를 뒤쪽에 넣고, 앞쪽에서 꺼낸다.

```text
enqueue → 뒤에 추가
dequeue → 앞에서 제거
```

## 파이썬에서 큐 구현하기

### 1. 리스트로 큐 구현하기

리스트를 이용해서 큐를 만들 수도 있다.

```python
queue = []

queue.append("A")  # enqueue
queue.append("B")  # enqueue
queue.append("C")  # enqueue

print(queue)        # ['A', 'B', 'C']

print(queue.pop(0)) # A
print(queue.pop(0)) # B
print(queue.pop(0)) # C
```

실행 흐름은 다음과 같다.

```text
enqueue A → [A]
enqueue B → [A, B]
enqueue C → [A, B, C]

dequeue → A
dequeue → B
dequeue → C
```

다만 리스트에서 `pop(0)`을 사용하면 맨 앞 데이터를 제거한 뒤 나머지 데이터를 앞으로 당겨야 한다.  
데이터가 많을 때는 비효율적일 수 있다.

### 2. `deque`로 큐 구현하기

파이썬에서는 큐를 구현할 때 `collections.deque`를 많이 사용한다.

```python
from collections import deque

queue = deque()

queue.append("A")      # enqueue
queue.append("B")      # enqueue
queue.append("C")      # enqueue

print(queue.popleft()) # A
print(queue.popleft()) # B
print(queue.popleft()) # C
```

`deque`는 앞쪽에서 데이터를 꺼내는 `popleft()`가 효율적이다.  
따라서 큐를 구현할 때는 리스트보다 `deque`가 더 적합하다.

## 큐가 사용되는 예

### 1. 서비스센터 대기열

서비스센터에 고객이 도착한 순서대로 줄을 서면, 먼저 온 고객이 먼저 상담을 받는다.

```text
도착 순서: 고객 A → 고객 B → 고객 C
상담 순서: 고객 A → 고객 B → 고객 C
```

### 2. 프린터 인쇄 작업

프린터에 여러 문서가 들어오면 먼저 요청한 문서부터 출력된다.

```text
요청 순서: 문서1 → 문서2 → 문서3
출력 순서: 문서1 → 문서2 → 문서3
```


## 스택과 큐 비교

| 구분 | 스택(Stack) | 큐(Queue) |
|---|---|---|
| 구조 | 한쪽에서 넣고 한쪽에서 뺌 | 한쪽에서 넣고 다른 쪽에서 뺌 |
| 순서 | 나중에 들어온 것이 먼저 나감 | 먼저 들어온 것이 먼저 나감 |
| 영어 표현 | LIFO | FIFO |
| 넣기 | `push` | `enqueue` |
| 빼기 | `pop` | `dequeue` |
| 예시 | 되돌리기, 미로 탐색 | 대기열, 프린터 작업 |

## 실습 예제: 버스 타기 프로그램

수업 자료에서는 스택과 큐를 이용하여 버스 정류장에 줄 선 학생들을 버스 뒷자리부터 채워 앉히는 예제를 다룬다.

이 문제는 다음 두 가지 구조를 함께 사용한다.

```text
1. 버스 정류장 줄       → 큐
2. 버스의 남은 좌석 번호 → 스택
```

학생들은 줄 선 순서대로 버스를 타야 하므로 큐가 적합하다.  
좌석은 뒷자리부터 채우고 싶으므로, 뒤쪽 좌석 번호가 먼저 나오도록 스택을 사용할 수 있다.

### 예제 코드

```python
from collections import deque

# 버스 정류장에 줄 선 학생들: 먼저 선 학생이 먼저 탐
waiting_line = deque(["학생A", "학생B", "학생C", "학생D"])

# 버스 좌석: index 0은 앞자리, index 3은 뒷자리라고 가정
bus_seats = [None, None, None, None]

# 뒷자리부터 채우기 위한 좌석 스택
# pop()을 하면 3, 2, 1, 0 순서로 나온다.
seat_stack = [0, 1, 2, 3]

while waiting_line and seat_stack:
    student = waiting_line.popleft()  # 큐: 먼저 줄 선 학생부터 꺼냄
    seat_index = seat_stack.pop()     # 스택: 뒷자리부터 꺼냄
    bus_seats[seat_index] = student

print(bus_seats)
```

### 실행 결과

```text
['학생D', '학생C', '학생B', '학생A']
```

결과를 해석하면 다음과 같다.

```text
학생A → 3번 좌석, 즉 가장 뒤쪽
학생B → 2번 좌석
학생C → 1번 좌석
학생D → 0번 좌석, 즉 가장 앞쪽
```

학생은 줄 선 순서대로 탔지만, 좌석은 뒷자리부터 채워졌다.

## 코드에서 주의할 점

### 1. 스택과 큐의 차이를 순서로 기억하기

스택과 큐는 모두 여러 데이터를 저장한다.  
하지만 가장 중요한 차이는 **꺼내는 순서**이다.

```text
스택: 마지막 데이터부터 꺼냄
큐: 첫 번째 데이터부터 꺼냄
```

### 2. 큐를 리스트로 만들 때는 `pop(0)`에 주의하기

```python
queue.pop(0)
```

위 코드는 동작은 하지만, 데이터가 많으면 비효율적일 수 있다.  
큐를 자주 사용한다면 `deque`를 사용하는 것이 좋다.

```python
from collections import deque

queue = deque()
queue.append("A")
queue.popleft()
```

### 3. 빈 스택이나 빈 큐에서 꺼내면 오류가 날 수 있음

```python
stack = []
# stack.pop()  # 오류 발생
```

데이터를 꺼내기 전에는 비어 있는지 확인하는 습관이 필요하다.

```python
if stack:
    value = stack.pop()
```

큐도 마찬가지이다.

```python
if queue:
    value = queue.popleft()
```

## 오늘의 정리

스택과 큐는 데이터를 저장하는 자료구조이지만, 단순히 저장만 하는 것이 아니라 **처리 순서**를 정하는 구조이다.

스택은 **LIFO** 구조로, 마지막에 들어온 데이터가 가장 먼저 나간다.  
그래서 되돌리기나 미로 탐색처럼 최근 기록을 먼저 처리해야 하는 상황에 적합하다.

큐는 **FIFO** 구조로, 먼저 들어온 데이터가 먼저 나간다.  
그래서 대기열이나 프린터 작업처럼 순서를 지켜야 하는 상황에 적합하다.

```text
스택 = 나중에 들어온 것이 먼저 나감
큐   = 먼저 들어온 것이 먼저 나감
```

자료구조를 공부할 때는 이름을 외우는 것보다,  
**어떤 순서로 데이터가 들어오고 어떤 순서로 나가는지**를 이해하는 것이 중요하다.
