# TIL - 반복구조와 함수
> 원본 자료 `-`</br>
> 학습 주제: 반복문, `for`, `while`, `range()`, 반복문 실습, 함수, 매개변수, 반환값

## 오늘 배운 내용

오늘은 프로그램의 제어 구조 중 **반복구조**를 학습했다. 반복구조는 같은 작업을 여러 번 수행해야 할 때 사용하는 구조이며, 파이썬에서는 대표적으로 `for`문과 `while`문을 사용한다.

또한 반복문 실습을 통해 로그인 프로그램, 숫자들의 합, 구구단, 무한 반복 구구단을 작성하는 흐름을 익혔다. 마지막으로 코드를 재사용하기 위해 사용하는 **함수**의 개념과 `def`, 함수 호출, 매개변수, 인수, 반환값을 정리했다.

---

## 제어문의 종류

프로그램은 단순히 위에서 아래로만 실행되는 것이 아니라, 상황에 따라 실행 흐름을 바꾸거나 같은 코드를 반복해서 실행할 수 있다.

| 제어 구조 | 의미 | 예시 |
|---|---|---|
| 순차구조 | 명령어가 위에서 아래로 순서대로 실행됨 | 입력 → 계산 → 출력 |
| 선택구조 | 조건에 따라 실행할 코드를 선택함 | `if`, `if~else` |
| 반복구조 | 같은 명령어를 여러 번 반복함 | `for`, `while` |

반복구조는 같은 일을 여러 번 처리해야 할 때 사용한다. 예를 들어 `안녕하세요`를 100번 출력해야 한다면 `print()`를 100번 쓰는 것보다 반복문을 사용하는 것이 훨씬 효율적이다.

---

## 반복문의 개념

반복문은 컴퓨터가 같은 작업을 여러 번 수행하도록 만드는 명령문이다. 반복문은 루프문(loop statement)이라고도 한다.

반복문을 사용하면 다음과 같은 장점이 있다.

- 같은 코드를 여러 번 작성하지 않아도 된다.
- 코드의 길이가 줄어든다.
- 반복 횟수를 쉽게 바꿀 수 있다.
- 규칙적인 작업을 자동화할 수 있다.

예를 들어 반복문 없이 5번 출력하려면 다음처럼 작성해야 한다.

```python
print("안녕하세요")
print("안녕하세요")
print("안녕하세요")
print("안녕하세요")
print("안녕하세요")
```

하지만 반복문을 사용하면 다음처럼 줄일 수 있다.

```python
for i in range(5):
    print("안녕하세요")
```

---

## `for`문

`for`문은 **반복 횟수가 정해져 있을 때** 자주 사용한다. 특히 파이썬에서는 `range()` 함수와 함께 많이 사용한다.

### 기본 구조

```python
for 변수 in range(반복횟수):
    반복할 문장
```

예시:

```python
for i in range(5):
    print(i)
```

출력 결과:

```text
0
1
2
3
4
```

`range(5)`는 `0`부터 `4`까지의 값을 만든다. 즉, 마지막 숫자 `5`는 포함하지 않는다.

---

## `range()` 함수

`range()`는 반복문에서 사용할 숫자의 범위를 만들어주는 함수이다.

```python
range(끝)
range(시작, 끝)
range(시작, 끝, 증가값)
```

예시:

```python
for i in range(1, 6):
    print(i)
```

출력 결과:

```text
1
2
3
4
5
```

`range(1, 6)`은 `1`부터 시작해서 `6` 바로 전인 `5`까지 반복한다.

증가값을 사용할 수도 있다.

```python
for i in range(2, 0, -1):
    print(i)
```

출력 결과:

```text
2
1
```

`range(2, 0, -1)`은 `2`부터 시작해서 1씩 감소하며, `0`이 되기 전까지 반복한다.

---

## 한 줄 출력과 `end`

`print()`는 기본적으로 출력 후 줄바꿈을 한다. 한 줄에 이어서 출력하고 싶으면 `end`를 사용한다.

```python
for i in range(1, 6):
    print(i, end=" ")
```

출력 결과:

```text
1 2 3 4 5
```

`end=" "`는 출력 후 줄바꿈 대신 공백을 넣겠다는 의미이다.

---

## `while`문

`while`문은 **조건이 참인 동안** 계속 반복하는 반복문이다.

### 기본 구조

```python
while 조건식:
    반복할 문장
```

예시:

```python
i = 0

while i < 5:
    print(i)
    i += 1
```

출력 결과:

```text
0
1
2
3
4
```

`while`문은 조건식이 `True`이면 계속 실행되고, 조건식이 `False`가 되면 반복을 멈춘다.

---

## `for`문과 `while`문의 차이

| 구분 | `for`문 | `while`문 |
|---|---|---|
| 주 사용 상황 | 반복 횟수가 정해져 있을 때 | 조건을 만족하는 동안 반복할 때 |
| 예시 | 1부터 10까지 출력 | 비밀번호가 맞을 때까지 입력 |
| 종료 방식 | 정해진 범위가 끝나면 종료 | 조건식이 거짓이 되면 종료 |

예를 들어 10번 반복처럼 횟수가 정해져 있으면 `for`문이 편하고, 사용자가 올바른 비밀번호를 입력할 때까지 반복하는 경우에는 `while`문이 더 자연스럽다.

---

## 반복문 실습 1: 단순 `for`문

1부터 5까지 출력하는 코드이다.

```python
for i in range(1, 6):
    print(i)
```

한 줄로 출력하고 싶다면 다음처럼 작성한다.

```python
for i in range(1, 6):
    print(i, end=" ")
```

---

## 반복문 실습 2: `for`문과 `while`문 비교

같은 결과를 `for`문과 `while`문으로 각각 작성할 수 있다.

### `for`문 사용

```python
for i in range(1, 6):
    print(i)
```

### `while`문 사용

```python
i = 1

while i <= 5:
    print(i)
    i += 1
```

두 코드는 모두 1부터 5까지 출력한다. 하지만 `while`문은 직접 `i`를 증가시키지 않으면 무한 반복이 될 수 있으므로 주의해야 한다.

---

## 반복문 실습 3: 로그인 프로그램

비밀번호가 맞을 때까지 계속 입력받는 프로그램이다.

```python
password = "1234"

while True:
    user_input = input("비밀번호를 입력하세요: ")

    if user_input == password:
        print("로그인 성공")
        break
    else:
        print("비밀번호가 틀렸습니다. 다시 입력하세요.")
```

여기서 `while True`는 무한 반복을 의미한다. 반복을 끝내기 위해서는 조건이 만족되었을 때 `break`를 사용해야 한다.

---

## 반복문 실습 4: 숫자들의 합

1부터 `n`까지의 합을 구하는 프로그램이다.

```python
n = int(input("숫자를 입력하세요: "))
total = 0

for i in range(1, n + 1):
    total += i

print("1부터", n, "까지의 합:", total)
```

예를 들어 `n`에 5를 입력하면 다음과 같이 계산된다.

```text
1 + 2 + 3 + 4 + 5 = 15
```

`total += i`는 다음 코드와 같은 의미이다.

```python
total = total + i
```

---

## 반복문 실습 5: 구구단 프로그램

사용자가 입력한 단의 구구단을 출력하는 프로그램이다.

```python
dan = int(input("단을 입력하세요: "))

for i in range(1, 10):
    print(dan, "x", i, "=", dan * i)
```

예를 들어 `dan`에 3을 입력하면 3단이 출력된다.

```text
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
...
3 x 9 = 27
```

---

## 반복문 실습 6: 무한 반복 구구단

계속해서 단을 입력받고, 0을 입력하면 종료하는 구구단 프로그램이다.

```python
while True:
    dan = int(input("단을 입력하세요. 종료하려면 0 입력: "))

    if dan == 0:
        print("프로그램을 종료합니다.")
        break

    for i in range(1, 10):
        print(dan, "x", i, "=", dan * i)
```

이 코드는 `while True`로 계속 반복하다가, 사용자가 `0`을 입력하면 `break`로 반복문을 종료한다.

## 알고리즘 분석 보충

함수 단원에서는 알고리즘 분석도 함께 언급되었다. 알고리즘 분석은 여러 해결 방법 중 어떤 방법이 더 좋은지 판단하기 위한 과정이다.

### 시간 복잡도

시간 복잡도는 알고리즘을 실행하는 데 걸리는 시간을 분석하는 것이다. 보통 실제 초 단위 시간보다 **연산 횟수가 얼마나 늘어나는지**를 기준으로 생각한다.

예를 들어 1부터 `n`까지의 합을 구하는 방법은 두 가지가 있다.

### 방법 1: 반복문 사용

```python
n = int(input("n 입력: "))
total = 0

for i in range(1, n + 1):
    total += i

print(total)
```

이 방법은 `n`이 커질수록 반복 횟수도 늘어난다.

### 방법 2: 공식 사용

```python
n = int(input("n 입력: "))
total = n * (n + 1) // 2

print(total)
```

이 방법은 `n`이 커져도 계산식 한 번으로 결과를 구할 수 있다. 따라서 반복문을 사용하는 방법보다 더 효율적이다.

### 공간 복잡도

공간 복잡도는 알고리즘을 실행하는 데 필요한 메모리 사용량을 분석하는 것이다. 예를 들어 리스트에 모든 값을 저장하면 메모리를 더 많이 사용하고, 누적합 변수 하나만 사용하면 메모리를 적게 사용할 수 있다.

## 함수의 개념

함수는 **특정 기능을 수행하는 코드를 하나로 묶어 놓은 것**이다.

파이썬에는 이미 만들어져 있는 내장 함수가 있다.

```python
print("Hello")
len("Python")
int("10")
```

하지만 사용자가 직접 함수를 만들어 사용할 수도 있다.

함수를 사용하는 이유는 다음과 같다.

| 이유 | 설명 |
|---|---|
| 코드 재사용 | 같은 코드를 여러 번 작성하지 않고 함수 호출로 반복 사용 가능 |
| 모듈화 | 기능별로 코드를 나누어 관리 가능 |
| 수정 용이 | 수정이 필요할 때 함수 내부만 고치면 됨 |
| 가독성 향상 | 코드의 목적을 함수명으로 표현 가능 |

---

## 함수 정의와 호출

함수를 만들 때는 `def` 키워드를 사용한다.

```python
def 함수이름():
    실행할 문장
```

예시:

```python
def greet():
    print("안녕하세요")


greet()
```

출력 결과:

```text
안녕하세요
```

함수를 정의했다고 해서 바로 실행되는 것은 아니다. 함수는 **호출해야 실행된다.**

```python
def greet():
    print("안녕하세요")


print("함수 호출 전")
greet()
print("함수 호출 후")
```

출력 결과:

```text
함수 호출 전
안녕하세요
함수 호출 후
```

---

## 함수를 여러 번 호출하기

같은 기능을 여러 번 실행하고 싶을 때 함수 호출을 반복하면 된다.

```python
def greet():
    print("안녕하세요")


greet()
greet()
greet()
```

출력 결과:

```text
안녕하세요
안녕하세요
안녕하세요
```

함수를 사용하지 않았다면 `print("안녕하세요")`를 여러 번 작성해야 하지만, 함수를 사용하면 기능을 하나로 묶어서 재사용할 수 있다.

## 매개변수와 인수

함수는 외부에서 값을 받아서 사용할 수 있다.

| 용어 | 의미 |
|---|---|
| 인수(argument) | 함수를 호출할 때 넘겨주는 실제 값 |
| 매개변수(parameter) | 함수 정의부에서 값을 받아 저장하는 변수 |

예시:

```python
def greet(name):
    print(name, "님 안녕하세요")


greet("철수")
greet("영희")
```

여기서 `name`은 매개변수이고, `"철수"`, `"영희"`는 인수이다.

출력 결과:

```text
철수 님 안녕하세요
영희 님 안녕하세요
```

---

## 반환값

함수는 계산 결과를 다시 돌려줄 수 있다. 이때 `return`을 사용한다.

```python
def plus(a, b):
    result = a + b
    return result


answer = plus(3, 5)
print(answer)
```

출력 결과:

```text
8
```

`return`은 함수의 결과를 함수 밖으로 전달한다. 함수 안에서만 계산하고 끝나는 것이 아니라, 그 값을 다른 변수에 저장하거나 다른 계산에 사용할 수 있다.

---

## 두 개 이상의 매개변수

함수는 여러 개의 값을 받을 수도 있다.

```python
def introduce(name, age):
    print("이름:", name)
    print("나이:", age)


introduce("민수", 20)
```

출력 결과:

```text
이름: 민수
나이: 20
```

함수를 호출할 때 전달하는 인수의 개수와 순서는 함수 정의부의 매개변수와 맞아야 한다.

```python
def plus(a, b):
    return a + b


print(plus(10, 20))
```

`10`은 `a`에 들어가고, `20`은 `b`에 들어간다.

## 함수명 작성 규칙

함수명도 변수명처럼 규칙을 지켜야 한다.

| 규칙 | 예시 |
|---|---|
| 숫자로 시작할 수 없음 | `2plus()` 불가능 |
| 특수문자는 사용할 수 없음 | `my-plus()` 불가능 |
| 언더바 `_`는 사용 가능 | `my_plus()` 가능 |
| 내장 함수명과 같은 이름은 피하는 것이 좋음 | `print`, `len` 사용 지양 |
| 첫 글자는 보통 소문자로 시작 | `myCalculator()`보다 `my_calculator()` 권장 |

좋은 함수명은 함수가 하는 일을 바로 알 수 있게 만든다.

```python
def calculate_total(score_list):
    total = 0
    for score in score_list:
        total += score
    return total
```

## 반복문과 함수를 함께 사용하기

반복문과 함수를 함께 사용하면 코드를 더 깔끔하게 만들 수 있다.

예를 들어 구구단 출력 기능을 함수로 만들 수 있다.

```python
def print_gugudan(dan):
    for i in range(1, 10):
        print(dan, "x", i, "=", dan * i)


print_gugudan(2)
print_gugudan(3)
```

함수로 만들면 같은 구구단 출력 코드를 여러 번 작성하지 않아도 된다.

무한 반복 구구단도 함수로 정리할 수 있다.

```python
def print_gugudan(dan):
    for i in range(1, 10):
        print(dan, "x", i, "=", dan * i)


while True:
    dan = int(input("단을 입력하세요. 종료하려면 0 입력: "))

    if dan == 0:
        print("종료합니다.")
        break

    print_gugudan(dan)
```

이렇게 작성하면 구구단을 출력하는 기능과 입력을 반복해서 받는 기능이 분리되어 코드가 더 읽기 쉬워진다.

## 코드에서 주의할 점

- `range(1, 6)`은 1부터 6까지가 아니라 1부터 5까지이다.
- `while`문에서는 조건이 언젠가 거짓이 되도록 만들어야 한다.
- `while True`를 사용할 때는 종료 조건과 `break`를 반드시 고려해야 한다.
- 반복문 안에서 사용하는 변수는 초기값과 증가식을 확인해야 한다.
- `input()`으로 받은 값은 문자열이므로 숫자 계산을 하려면 `int()` 또는 `float()`으로 변환해야 한다.
- 함수는 정의만으로 실행되지 않고, 반드시 호출해야 실행된다.
- 함수의 인수 개수와 매개변수 개수가 맞지 않으면 오류가 발생한다.
- 함수명은 기능을 알 수 있게 작성하는 것이 좋다.

## 오늘의 정리

반복문은 같은 작업을 여러 번 수행할 때 사용하는 제어 구조이다. 반복 횟수가 정해져 있으면 `for`문을 사용하고, 조건이 만족되는 동안 반복해야 한다면 `while`문을 사용하면 좋다.

`range()`는 `for`문에서 반복 범위를 만들 때 자주 사용하며, 끝 값은 포함하지 않는다는 점을 기억해야 한다.

함수는 특정 기능을 하는 코드를 묶어 놓은 것이다. 함수를 사용하면 코드를 재사용할 수 있고, 프로그램을 기능별로 나눌 수 있으며, 수정도 쉬워진다.

반복문과 함수를 함께 사용하면 복잡한 프로그램도 더 깔끔하고 관리하기 쉬운 구조로 작성할 수 있다.
