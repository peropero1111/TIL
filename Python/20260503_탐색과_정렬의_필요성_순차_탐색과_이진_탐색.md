# TIL - 탐색과 정렬의 필요성, 순차 탐색과 이진 탐색

> 원본 자료: `-` \
> 학습 주제: 탐색 알고리즘, 정렬의 필요성, 순차 탐색, 이진 탐색, 알고리즘 분석

## 오늘 배운 내용

오늘은 리스트 안에서 원하는 값을 찾는 **탐색 알고리즘**을 배웠다.  
탐색은 일상생활에서도 자주 사용된다. 예를 들어 사전에서 단어 찾기, 전화번호 찾기, 웹에서 원하는 정보 찾기 등이 모두 탐색에 해당한다.

탐색 방법에는 여러 가지가 있다.

```text
탐색 알고리즘의 예
- 순차 탐색, 선형 탐색
- 이진 탐색
- 해싱
```

이번 수업에서는 그중에서 **순차 탐색**과 **이진 탐색**을 중심으로 정리했다.

---

## 탐색이 필요한 이유

프로그램에서는 리스트, 배열, 데이터베이스처럼 여러 데이터가 모여 있는 곳에서 특정 값을 찾아야 할 때가 많다.

예를 들어 다음 리스트에서 `33`을 찾는다고 하자.

```python
v = [17, 92, 18, 33, 58, 7, 33, 42]
```

사람은 눈으로 보면 `33`이 보일 수 있지만, 컴퓨터는 하나씩 비교하거나 정해진 알고리즘을 사용해서 값을 찾아야 한다.

탐색 알고리즘은 이런 질문에 답하기 위한 방법이다.

```text
찾는 값이 리스트 안에 있는가?
있다면 몇 번째 위치에 있는가?
없다면 어떻게 표시할 것인가?
```

일반적으로 값이 있으면 그 위치를 반환하고, 값이 없으면 `-1`을 반환하는 방식으로 작성한다.

---

## 정렬이 필요한 이유

탐색을 더 빠르게 하려면 데이터가 **정렬**되어 있는 것이 중요하다.

예를 들어 다음과 같이 정렬되지 않은 데이터가 있다고 하자.

```text
8  30  1  2
```

이 상태에서는 원하는 값을 찾기 위해 앞에서부터 하나씩 확인해야 한다.

하지만 정렬하면 다음과 같다.

```text
1  2  8  30
```

정렬된 데이터에서는 값의 크기 관계를 이용할 수 있다.  
예를 들어 `2`를 찾을 때, 현재 보고 있는 값이 `8`이라면 `2`는 `8`보다 왼쪽에 있어야 한다는 것을 알 수 있다.

즉, 정렬은 단순히 보기 좋게 나열하는 것이 아니라 **더 효율적인 탐색을 가능하게 하는 준비 작업**이다.

---

## 순차 탐색

**순차 탐색**은 리스트의 첫 번째 값부터 마지막 값까지 하나씩 차례대로 비교하면서 원하는 값을 찾는 방법이다.

영어로는 다음과 같이 부른다.

```text
Sequential Search
Linear Search
```

순차 탐색의 기본 흐름은 다음과 같다.

```text
1. 리스트의 첫 번째 값부터 확인한다.
2. 찾는 값과 현재 값을 비교한다.
3. 같으면 현재 위치를 반환한다.
4. 다르면 다음 값으로 이동한다.
5. 리스트 끝까지 찾지 못하면 -1을 반환한다.
```

---

## 순차 탐색 예시

다음 리스트에서 `33`을 찾는다고 하자.

```python
v = [17, 92, 18, 33, 58, 7, 33, 42]
```

비교 과정은 다음과 같다.

```text
index 0 → 17, 33과 다름
index 1 → 92, 33과 다름
index 2 → 18, 33과 다름
index 3 → 33, 찾음
```

따라서 결과는 `3`이다.

리스트에 `33`이 두 번 들어 있지만, 순차 탐색은 앞에서부터 찾기 때문에 **처음 발견한 위치**를 반환한다.

```text
33의 첫 번째 위치 = index 3
```

---

## 순차 탐색 코드

```python
def sequential_search(a, x):
    n = len(a)

    for i in range(n):
        if a[i] == x:
            return i

    return -1


v = [17, 92, 18, 33, 58, 7, 33, 42]

print(sequential_search(v, 58))   # 4
print(sequential_search(v, 33))   # 3
print(sequential_search(v, 900))  # -1
```

실행 결과는 다음과 같다.

```text
4
3
-1
```

여기서 `900`은 리스트 안에 없기 때문에 `-1`이 반환된다.

---

## 순차 탐색의 장점과 단점

### 장점

순차 탐색은 구현이 쉽고, 데이터가 정렬되어 있지 않아도 사용할 수 있다.

```text
정렬된 리스트   → 사용 가능
정렬되지 않은 리스트 → 사용 가능
```

### 단점

리스트가 길어질수록 탐색 시간이 오래 걸릴 수 있다.

찾는 값이 맨 앞에 있으면 한 번만 비교하면 되지만, 찾는 값이 맨 뒤에 있거나 리스트에 없다면 모든 값을 확인해야 한다.

---

## 순차 탐색의 비교 횟수

순차 탐색은 경우에 따라 비교 횟수가 달라진다.

| 경우 | 설명 | 비교 횟수 |
|---|---|---:|
| 최선의 경우 | 찾는 값이 맨 앞에 있음 | 1번 |
| 평균적인 경우 | 중간쯤에서 찾음 | 약 `n / 2`번 |
| 최악의 경우 | 맨 뒤에 있거나 없음 | `n`번 |

따라서 순차 탐색의 시간 복잡도는 보통 다음과 같이 표현한다.

```text
O(n)
```

`n`은 리스트 안에 있는 데이터 개수이다.

---

## 이진 탐색

**이진 탐색**은 정렬된 리스트에서 탐색 범위를 절반씩 줄여 가며 값을 찾는 알고리즘이다.

이진 탐색에서 가장 중요한 조건은 다음과 같다.

```text
리스트가 반드시 정렬되어 있어야 한다.
```

정렬되어 있지 않으면 중간값을 기준으로 왼쪽과 오른쪽 중 어디를 버려야 할지 판단할 수 없다.

---

## 이진 탐색의 기본 아이디어

다음 리스트에서 `36`을 찾는다고 하자.

```python
d = [1, 4, 9, 16, 25, 36, 49, 64, 81]
```

먼저 중간 위치를 확인한다.

```text
중간 위치 index 4 → 값 25
```

찾는 값은 `36`이고, 중간값은 `25`이다.

```text
36 > 25
```

따라서 `36`은 `25`보다 오른쪽에 있어야 한다.  
이제 왼쪽 절반은 더 이상 확인하지 않아도 된다.

다음 탐색 범위는 다음과 같다.

```text
[36, 49, 64, 81]
```

다시 중간값을 확인하면서 범위를 줄여 나가면 최종적으로 `36`을 찾을 수 있다.

---

## 이진 탐색 알고리즘 순서

이진 탐색의 흐름은 다음과 같다.

```text
1. 탐색 범위의 시작 위치와 끝 위치를 정한다.
2. 중간 위치를 구한다.
3. 찾는 값과 중간 위치의 값을 비교한다.
4. 같으면 중간 위치를 반환한다.
5-1. 찾는 값이 더 크면 오른쪽 절반을 다시 탐색한다.
5-2. 찾는 값이 더 작으면 왼쪽 절반을 다시 탐색한다.
6. 탐색 범위가 없어질 때까지 찾지 못하면 -1을 반환한다.
```

---

## 이진 탐색 코드

```python
def binary_search(a, x):
    start = 0
    end = len(a) - 1

    while start <= end:
        mid = (start + end) // 2

        if x == a[mid]:
            return mid
        elif x > a[mid]:
            start = mid + 1
        else:
            end = mid - 1

    return -1


d = [1, 4, 9, 16, 25, 36, 49, 64, 81]

print(binary_search(d, 36))
print(binary_search(d, 50))
```

실행 결과는 다음과 같다.

```text
5
-1
```

`36`은 index `5`에 있으므로 `5`가 출력된다.  
`50`은 리스트 안에 없으므로 `-1`이 출력된다.

---

## `start`, `end`, `mid`의 의미

이진 탐색에서는 탐색할 범위를 변수로 관리한다.

```python
start = 0
end = len(a) - 1
mid = (start + end) // 2
```

각 변수의 의미는 다음과 같다.

| 변수 | 의미 |
|---|---|
| `start` | 현재 탐색 범위의 시작 index |
| `end` | 현재 탐색 범위의 끝 index |
| `mid` | 현재 탐색 범위의 중간 index |

`//`는 몫 연산자이다.  
중간 위치는 정수 index여야 하므로 `/`가 아니라 `//`를 사용한다.

---

## 이진 탐색에서 범위를 줄이는 방법

중간값과 찾는 값을 비교한 뒤, 탐색 범위를 줄인다.

```python
if x == a[mid]:
    return mid
elif x > a[mid]:
    start = mid + 1
else:
    end = mid - 1
```

찾는 값이 중간값보다 크면 왼쪽은 볼 필요가 없다.

```text
x > a[mid] → 오른쪽 탐색
```

찾는 값이 중간값보다 작으면 오른쪽은 볼 필요가 없다.

```text
x < a[mid] → 왼쪽 탐색
```

이렇게 할 때마다 탐색 범위가 거의 절반으로 줄어든다.

---

## 이진 탐색의 시간 복잡도

이진 탐색은 비교할 때마다 탐색 범위가 절반으로 줄어든다.

예를 들어 데이터가 1,000개라면 순차 탐색은 최악의 경우 1,000번 비교해야 할 수 있다.  
하지만 이진 탐색은 대략 10번 정도의 비교로 탐색을 끝낼 수 있다.

```text
log2(1000) ≒ 9.97
```

따라서 이진 탐색의 시간 복잡도는 다음과 같다.

```text
O(log n)
```

---

## 순차 탐색과 이진 탐색 비교

| 구분 | 순차 탐색 | 이진 탐색 |
|---|---|---|
| 다른 이름 | 선형 탐색 | 이분 탐색 |
| 사용 조건 | 정렬되지 않아도 가능 | 반드시 정렬 필요 |
| 탐색 방식 | 처음부터 하나씩 비교 | 중간값 기준으로 범위를 절반씩 줄임 |
| 최선의 경우 | `O(1)` | `O(1)` |
| 최악의 경우 | `O(n)` | `O(log n)` |
| 구현 난이도 | 쉬움 | 상대적으로 조금 더 어려움 |
| 중복 값 처리 | 처음 발견한 위치 반환 | 발견 위치가 항상 첫 번째 중복값은 아닐 수 있음 |

---

## 데이터 개수에 따른 비교 횟수 느낌

정확한 비교 횟수는 구현 방식과 데이터 위치에 따라 달라질 수 있지만, 최악의 경우를 대략 비교하면 다음과 같다.

| 데이터 개수 `n` | 순차 탐색 최악 | 이진 탐색 최악 |
|---:|---:|---:|
| 10 | 10번 | 약 4번 |
| 100 | 100번 | 약 7번 |
| 1,000 | 1,000번 | 약 10번 |
| 1,000,000 | 1,000,000번 | 약 20번 |

데이터가 많아질수록 이진 탐색의 장점이 커진다.

---

## 정렬 비용도 생각해야 한다

이진 탐색이 순차 탐색보다 항상 좋은 것은 아니다.

이진 탐색을 사용하려면 먼저 데이터가 정렬되어 있어야 한다.  
만약 데이터가 정렬되어 있지 않다면 정렬하는 데에도 시간이 걸린다.

따라서 상황에 따라 선택해야 한다.

```text
데이터를 한 번만 찾는다
→ 순차 탐색이 더 간단할 수 있음

정렬된 데이터에서 여러 번 검색한다
→ 이진 탐색이 훨씬 효율적일 수 있음

데이터를 먼저 정렬한 뒤 여러 번 검색한다
→ 정렬 비용을 감수하더라도 이진 탐색이 유리할 수 있음
```

즉, 알고리즘을 고를 때는 단순히 탐색 속도만 보지 말고, **데이터가 정렬되어 있는지**, **검색을 몇 번 할 것인지**, **데이터 크기가 얼마나 큰지**를 함께 고려해야 한다.

---

## 정렬된 리스트인지 확인하는 함수

이진 탐색을 사용하기 전에는 리스트가 정렬되어 있는지 확인하는 습관이 좋다.

```python
def is_sorted(a):
    for i in range(len(a) - 1):
        if a[i] > a[i + 1]:
            return False
    return True


print(is_sorted([1, 2, 3, 4]))     # True
print(is_sorted([1, 3, 2, 4]))     # False
```

이 함수는 앞의 값이 뒤의 값보다 큰 경우가 있는지 확인한다.  
만약 그런 경우가 있다면 오름차순 정렬 상태가 아니므로 `False`를 반환한다.

## 순차 탐색과 이진 탐색을 함께 비교하는 코드

```python
def sequential_search(a, x):
    for i in range(len(a)):
        if a[i] == x:
            return i
    return -1


def binary_search(a, x):
    start = 0
    end = len(a) - 1

    while start <= end:
        mid = (start + end) // 2

        if x == a[mid]:
            return mid
        elif x > a[mid]:
            start = mid + 1
        else:
            end = mid - 1

    return -1


data = [1, 4, 9, 16, 25, 36, 49, 64, 81]

print(sequential_search(data, 36))
print(binary_search(data, 36))
```

실행 결과는 둘 다 `5`가 된다.

```text
5
5
```

하지만 내부적으로 비교하는 방식은 다르다.

```text
순차 탐색 → 앞에서부터 하나씩 확인
이진 탐색 → 중간값을 기준으로 탐색 범위를 줄임
```

## 코드 작성 시 주의할 점

### 1. 이진 탐색은 정렬된 리스트에서만 사용한다

```python
# 잘못된 예: 정렬되지 않은 리스트
numbers = [8, 30, 1, 2]
print(binary_search(numbers, 2))
```

이진 탐색은 정렬 상태를 전제로 하므로, 위와 같은 리스트에서는 올바른 결과를 보장할 수 없다.

정렬 후 사용해야 한다.

```python
numbers = [8, 30, 1, 2]
numbers.sort()

print(numbers)                 # [1, 2, 8, 30]
print(binary_search(numbers, 2)) # 1
```

### 2. `start <= end` 조건을 사용한다

```python
while start <= end:
```

탐색 범위가 남아 있는 동안 반복해야 한다.  
`start`가 `end`보다 커지면 더 이상 탐색할 범위가 없다는 뜻이다.

### 3. 범위를 줄일 때 `mid + 1`, `mid - 1`을 사용한다

```python
start = mid + 1
end = mid - 1
```

이미 `mid` 위치는 확인했기 때문에 다시 검사할 필요가 없다.  
만약 `start = mid`, `end = mid`처럼 작성하면 경우에 따라 무한 반복이 생길 수 있다.

### 4. 중복 값에서는 반환 위치를 주의한다

순차 탐색은 앞에서부터 찾기 때문에 중복 값이 있으면 첫 번째 위치를 반환한다.

```python
v = [17, 92, 18, 33, 58, 7, 33, 42]
print(sequential_search(v, 33))  # 3
```

반면 이진 탐색은 중간값을 기준으로 탐색하므로, 중복 값이 있을 때 항상 첫 번째 위치를 반환한다고 볼 수는 없다.

## 오늘의 정리

탐색은 여러 데이터 중에서 원하는 값을 찾는 과정이다.

순차 탐색은 리스트의 처음부터 끝까지 하나씩 비교하는 방법이다.  
구현이 쉽고 정렬되지 않은 데이터에도 사용할 수 있지만, 데이터가 많을수록 시간이 오래 걸릴 수 있다.

이진 탐색은 정렬된 리스트에서 중간값을 기준으로 탐색 범위를 절반씩 줄여 가는 방법이다.  
데이터가 많을수록 순차 탐색보다 훨씬 빠르지만, 반드시 정렬된 데이터에서만 사용할 수 있다.

결국 중요한 것은 상황에 맞는 탐색 방법을 선택하는 것이다.

```text
정렬되지 않은 데이터 또는 간단한 검색 → 순차 탐색
정렬된 데이터에서 빠른 검색 → 이진 탐색
여러 번 검색해야 하는 큰 데이터 → 정렬 후 이진 탐색 고려
```

오늘 배운 탐색 알고리즘은 이후 정렬 알고리즘, 자료구조, 해싱, 데이터베이스 검색을 이해하는 기초가 된다.
