# TIL - 순차구조와 입출력문 이해하기

> 원본 자료: `-`  
> 학습 주제: 제어문, 순차구조, 입력문, 출력문, 출력 서식

## 오늘 배운 내용

프로그램은 여러 명령어를 아무렇게나 실행하는 것이 아니라, 정해진 순서에 따라 실행한다.
이 실행 흐름을 조절하는 것을 **프로그램 제어**라고 하며, 이때 사용하는 구조를 **제어문**이라고 한다.

이번 수업에서는 제어문의 기본 개념 중에서 가장 먼저 이해해야 하는 **순차구조**를 배우고,
파이썬에서 값을 입력받는 `input()` 함수와 값을 출력하는 `print()` 함수의 사용법을 정리했다.

## 제어문이란?

제어문은 프로그램의 실행 순서를 조정하는 방법이다.

컴퓨터가 문제를 해결할 때는 보통 다음과 같은 흐름을 가진다.

```text
입력 → 처리 → 출력
```

예를 들어 두 수를 더하는 프로그램이라면 다음 순서로 실행된다.

```text
1. 첫 번째 수를 입력받는다.
2. 두 번째 수를 입력받는다.
3. 두 수를 더한다.
4. 결과를 출력한다.
```

이처럼 프로그램은 **정해진 순서대로 명령어를 실행**하면서 문제를 해결한다.

## 제어문의 종류

제어문은 크게 세 가지로 나눌 수 있다.

| 종류 | 의미 | 예시 |
|---|---|---|
| 순차구조 | 명령어가 위에서 아래로 순서대로 실행됨 | 라면 끓이기 순서 |
| 선택구조 | 조건에 따라 실행할 명령어가 달라짐 | 날씨가 좋으면 운동, 아니면 공부 |
| 반복구조 | 같은 명령어를 여러 번 반복함 | 라면 5그릇 끓이기 |

이번 수업의 중심은 **순차구조**이다.

## 순차구조

### 1. 순차구조란?

순차구조는 명령어들이 작성된 순서대로 실행되는 구조이다.

```text
첫 번째 명령어 실행
두 번째 명령어 실행
세 번째 명령어 실행
...
```

파이썬 코드는 기본적으로 위에서 아래로 실행된다.

```python
print("첫 번째")
print("두 번째")
print("세 번째")
```

실행 결과는 다음과 같다.

```text
첫 번째
두 번째
세 번째
```

코드의 순서를 바꾸면 실행 결과도 바뀐다.

```python
print("세 번째")
print("첫 번째")
print("두 번째")
```

```text
세 번째
첫 번째
두 번째
```

즉, 순차구조에서는 **작성 순서가 곧 실행 순서**이다.

### 2. 일상생활에서의 순차구조

라면을 끓이는 과정을 생각하면 순차구조를 쉽게 이해할 수 있다.

```text
1. 냄비에 물을 넣는다.
2. 물을 끓인다.
3. 면과 스프를 넣는다.
4. 정해진 시간 동안 끓인다.
5. 완성된 라면을 먹는다.
```

이 순서를 마음대로 바꾸면 문제가 생긴다.
예를 들어 물을 끓이기 전에 면을 먹을 수는 없다.

프로그램도 마찬가지로, 어떤 값이 필요하다면 먼저 입력받거나 계산해 두어야 한다.

## 파이썬 입력 함수 `input()`

### 1. `input()`의 기본 사용법

`input()`은 사용자에게 값을 입력받을 때 사용하는 함수이다.

```python
name = input()
print(name)
```

사용자가 `홍길동`을 입력하면 다음과 같이 출력된다.

```text
홍길동
```

입력받은 값을 변수에 저장해 두면, 이후 코드에서 다시 사용할 수 있다.

### 2. 안내문구를 함께 출력하기

`input()` 안에 문자열을 넣으면 사용자에게 안내문구를 보여줄 수 있다.

```python
name = input("이름을 입력하세요: ")
print("입력한 이름:", name)
```

실행 예시는 다음과 같다.

```text
이름을 입력하세요: 홍길동
입력한 이름: 홍길동
```

이때 `"이름을 입력하세요: "` 부분을 **프롬프트(prompt)** 라고 볼 수 있다.
사용자가 무엇을 입력해야 하는지 알려 주는 역할을 한다.

### 3. `input()`은 항상 문자열을 입력받는다

`input()`으로 입력받은 값은 숫자처럼 보여도 실제로는 문자열이다.

```python
age = input("나이를 입력하세요: ")
print(type(age))
```

사용자가 `20`을 입력해도 `age`의 자료형은 `str`이다.

```text
<class 'str'>
```

따라서 입력받은 값으로 계산을 하려면 자료형을 변환해야 한다.

```python
age = int(input("나이를 입력하세요: "))
print(age + 1)
```

실수는 `float()`을 사용한다.

```python
height = float(input("키를 입력하세요: "))
print(height)
```

정리하면 다음과 같다.

| 목적 | 코드 |
|---|---|
| 문자열 입력 | `name = input()` |
| 정수 입력 | `num = int(input())` |
| 실수 입력 | `num = float(input())` |

## 여러 값 입력받기

한 줄에 여러 값을 입력받고 싶을 때는 `split()`을 사용할 수 있다.

```python
a, b = input("두 수 입력: ").split()
print(a, b)
```

하지만 이 경우에도 `a`, `b`는 문자열이다.
계산을 하려면 정수로 변환해야 한다.

```python
a, b = input("두 수 입력: ").split()
a = int(a)
b = int(b)

print(a + b)
```

더 간단하게는 `map()`을 사용할 수 있다.

```python
a, b = map(int, input("두 수 입력: ").split())
print(a + b)
```

예를 들어 `10 20`을 입력하면 출력 결과는 다음과 같다.

```text
30
```

## 파이썬 출력 함수 `print()`

### 1. `print()`의 기본 사용법

`print()`는 값을 화면에 출력할 때 사용하는 함수이다.

```python
print("안녕하세요")
print(100)
print(3.14)
```

출력 결과는 다음과 같다.

```text
안녕하세요
100
3.14
```

문자열, 정수, 실수 등 여러 자료형을 출력할 수 있다.

### 2. 콤마로 여러 값 출력하기

`print()`에서 콤마(`,`)를 사용하면 여러 값을 한 번에 출력할 수 있다.

```python
name = "홍길동"
age = 20

print(name, age)
```

출력 결과는 다음과 같다.

```text
홍길동 20
```

콤마를 사용하면 값 사이에 기본적으로 공백이 들어간다.

### 3. 문자열 연결하기

문자열끼리는 `+`로 연결할 수 있다.

```python
print("Hello" + "Python")
```

```text
HelloPython
```

공백이 필요하면 직접 넣어야 한다.

```python
print("Hello" + " " + "Python")
```

```text
Hello Python
```

단, 문자열과 숫자를 `+`로 바로 연결할 수는 없다.

```python
age = 20
# print("나이: " + age)  # 오류 발생
```

숫자를 문자열로 바꾸거나, 콤마를 사용해야 한다.

```python
print("나이: " + str(age))
print("나이:", age)
```

## `print()`의 `sep`과 `end`

### 1. `sep`

`sep`은 여러 값을 출력할 때 값 사이에 무엇을 넣을지 정한다.

```python
print("2026", "03", "29", sep="-")
```

```text
2026-03-29
```

### 2. `end`

`end`는 출력이 끝난 뒤 무엇을 붙일지 정한다.
기본값은 줄바꿈인 `\n`이다.

```python
print("A", end=" ")
print("B", end=" ")
print("C")
```

```text
A B C
```

기본적으로 `print()`는 출력 후 줄을 바꾸지만,
`end`를 바꾸면 같은 줄에 이어서 출력할 수 있다.

## 출력 서식의 이해

출력 서식은 값을 원하는 모양으로 출력하기 위해 사용한다.

수업 자료에서는 `%`를 사용하는 오래된 방식의 출력 서식을 다룬다.
이 방식은 지금도 C 언어나 기존 파이썬 코드에서 자주 볼 수 있기 때문에 알아 두면 좋다.

### 1. 대표적인 출력 서식

| 서식 | 의미 | 예시 |
|---|---|---|
| `%d` | 정수 출력 | `100` |
| `%f` | 실수 출력 | `3.140000` |
| `%s` | 문자열 출력 | `Python` |

예제는 다음과 같다.

```python
print("%d" % 100)
print("%f" % 3.14)
print("%s" % "Python")
```

출력 결과는 다음과 같다.

```text
100
3.140000
Python
```

`%f`는 기본적으로 소수점 아래 6자리까지 출력된다.

### 2. 여러 값 출력하기

여러 값을 서식에 넣을 때는 괄호를 사용한다.

```python
print("%d / %d = %f" % (100, 200, 0.5))
```

출력 결과는 다음과 같다.

```text
100 / 200 = 0.500000
```

서식의 개수와 뒤에 전달하는 값의 개수는 맞아야 한다.

```python
# print("%d %d" % (100))      # 오류
print("%d %d" % (100, 200))   # 정상
```

## 자리수 지정하기

### 1. 정수 자리수 지정

`%5d`는 정수를 출력할 때 전체 칸을 5칸으로 맞춘다.

```python
print("%d" % 123)
print("%5d" % 123)
print("%05d" % 123)
```

출력 결과는 다음과 같다.

```text
123
  123
00123
```

정리하면 다음과 같다.

| 서식 | 의미 |
|---|---|
| `%d` | 정수를 그대로 출력 |
| `%5d` | 전체 5칸을 확보하고 오른쪽 정렬 |
| `%05d` | 전체 5칸을 확보하고 빈칸을 0으로 채움 |

### 2. 실수 자리수 지정

실수는 전체 자리수와 소수점 아래 자리수를 지정할 수 있다.

```python
print("%f" % 123.45)
print("%7.1f" % 123.45)
print("%7.3f" % 123.45)
```

출력 결과는 다음과 같다.

```text
123.450000
  123.5
123.450
```

`%7.1f`의 의미는 다음과 같다.

```text
전체 7칸을 사용하고, 소수점 아래는 1자리까지 출력
```

`123.45`를 소수점 아래 1자리까지 출력하면 `123.5`가 된다.
이때 값은 잘리는 것이 아니라 반올림되어 출력된다.

### 3. 문자열 자리수 지정

문자열도 출력 칸을 지정할 수 있다.

```python
print("%s" % "Python")
print("%10s" % "Python")
```

출력 결과는 다음과 같다.

```text
Python
    Python
```

`%10s`는 전체 10칸을 확보하고 문자열을 오른쪽에 맞춘다.

## `format()`을 사용한 출력

파이썬에서는 `%` 서식 외에도 `format()`을 사용할 수 있다.

```python
print("{0:d} {1:5d} {2:05d}".format(123, 123, 123))
```

출력 결과는 다음과 같다.

```text
123   123 00123
```

`{0:d}`는 첫 번째 값, `{1:5d}`는 두 번째 값, `{2:05d}`는 세 번째 값을 의미한다.

값의 순서를 바꿔 출력할 수도 있다.

```python
print("{2:d} {1:d} {0:d}".format(100, 200, 300))
```

```text
300 200 100
```

`format()`은 값의 위치를 번호로 지정할 수 있기 때문에,
같은 값을 여러 번 쓰거나 출력 순서를 바꿀 때 유용하다.

## f-string을 사용한 출력

현재 파이썬에서는 `f-string`도 많이 사용한다.
수업에서는 `%` 서식과 `format()`을 중심으로 다루지만,
실제 코드를 작성할 때는 f-string이 더 읽기 쉬운 경우가 많다.

```python
name = "홍길동"
age = 20
score = 95.5

print(f"이름: {name}")
print(f"나이: {age}")
print(f"점수: {score:.1f}")
```

출력 결과는 다음과 같다.

```text
이름: 홍길동
나이: 20
점수: 95.5
```

f-string에서도 자리수와 소수점 자리수를 지정할 수 있다.

```python
num = 123
pi = 3.141592

print(f"{num:5d}")
print(f"{num:05d}")
print(f"{pi:.2f}")
```

```text
  123
00123
3.14
```

## 이스케이프 문자

이스케이프 문자는 문자열 안에서 특별한 기능을 하는 문자이다.
주로 줄바꿈, 탭, 따옴표 출력 등에 사용한다.

| 이스케이프 문자 | 의미 |
|---|---|
| `\n` | 줄바꿈 |
| `\t` | 탭 간격 |
| `\b` | 백스페이스 효과 |
| `\\` | 역슬래시 출력 |
| `\'` | 작은따옴표 출력 |
| `\"` | 큰따옴표 출력 |

예제는 다음과 같다.

```python
print("줄바꿈\n연습")
print("탭\t연습")
print("큰따옴표 \"강조\" 출력")
print("작은따옴표 \'강조\' 출력")
print("역슬래시 \\ 출력")
```

출력 결과는 다음과 같다.

```text
줄바꿈
연습
탭    연습
큰따옴표 "강조" 출력
작은따옴표 '강조' 출력
역슬래시 \ 출력
```

## 실습 예제 1: 이름과 나이 출력하기

```python
name = input("이름을 입력하세요: ")
age = int(input("나이를 입력하세요: "))

print("이름:", name)
print("나이:", age)
print("내년 나이:", age + 1)
```

실행 예시는 다음과 같다.

```text
이름을 입력하세요: 홍길동
나이를 입력하세요: 20
이름: 홍길동
나이: 20
내년 나이: 21
```

이 예제에서 중요한 점은 `age`를 `int()`로 변환했다는 것이다.
만약 변환하지 않으면 `age + 1` 계산을 할 수 없다.

## 실습 예제 2: 두 수의 합과 평균 구하기

```python
a = int(input("첫 번째 수: "))
b = int(input("두 번째 수: "))

total = a + b
average = total / 2

print("합계: %d" % total)
print("평균: %.2f" % average)
```

실행 예시는 다음과 같다.

```text
첫 번째 수: 10
두 번째 수: 20
합계: 30
평균: 15.00
```

`%.2f`는 실수를 소수점 아래 2자리까지 출력한다.

## 실습 예제 3: 순차구조 확인하기

```python
print("1. 입력을 받는다")
num = int(input("정수 입력: "))

print("2. 입력값에 10을 더한다")
result = num + 10

print("3. 결과를 출력한다")
print("결과:", result)
```

이 코드는 위에서 아래로 순서대로 실행된다.
따라서 `num`을 입력받기 전에 `result = num + 10`을 먼저 실행하면 오류가 난다.

순차구조에서는 **필요한 값을 먼저 준비하고, 그 다음 계산하고, 마지막에 출력하는 순서**를 지켜야 한다.

## 코드에서 주의할 점

### 1. `input()` 결과는 문자열이다

```python
x = input("숫자 입력: ")
print(x + 10)  # 오류 발생
```

위 코드는 `x`가 문자열이기 때문에 오류가 난다.
계산하려면 정수나 실수로 변환해야 한다.

```python
x = int(input("숫자 입력: "))
print(x + 10)
```

### 2. 출력 서식과 값의 자료형을 맞춰야 한다

```python
print("%d" % 10)       # 정수
print("%f" % 3.14)     # 실수
print("%s" % "문자열") # 문자열
```

서식과 값의 개수가 맞지 않거나 자료형이 맞지 않으면 오류가 날 수 있다.

### 3. `%f`는 기본적으로 소수점 아래 6자리까지 출력된다

```python
print("%f" % 3.14)
```

```text
3.140000
```

원하는 자리수만 출력하고 싶다면 `%.2f`, `%.1f`처럼 사용한다.

```python
print("%.2f" % 3.14)
print("%.1f" % 3.14)
```

```text
3.14
3.1
```

### 4. 코드의 순서를 바꾸면 결과도 바뀐다

순차구조에서는 코드가 작성된 순서대로 실행된다.
따라서 변수를 사용하기 전에 먼저 값을 넣어야 한다.

```python
# print(result)  # result가 아직 만들어지지 않았으므로 오류
result = 10 + 20
print(result)
```

## 오늘의 정리

제어문은 프로그램의 실행 순서를 조정하는 방법이다.
그중 순차구조는 가장 기본적인 구조로, 명령어가 위에서 아래로 차례대로 실행된다.

파이썬에서 `input()`은 사용자에게 값을 입력받을 때 사용하고,
`print()`는 값을 출력할 때 사용한다.

```text
input()  → 입력
print()  → 출력
```

`input()`으로 입력받은 값은 항상 문자열이므로,
계산이 필요하다면 `int()`나 `float()`으로 변환해야 한다.

출력할 때는 `%d`, `%f`, `%s` 같은 출력 서식을 사용해 원하는 형태로 값을 보여 줄 수 있다.
또한 `format()`이나 f-string을 사용하면 더 읽기 좋은 출력문을 만들 수 있다.

```text
순차구조 = 위에서 아래로 실행
입력     = input()
출력     = print()
서식 출력 = %d, %f, %s, format(), f-string
```

프로그램을 작성할 때는 먼저 입력을 받고, 필요한 처리를 한 뒤, 마지막에 결과를 출력하는 흐름을 생각하는 것이 중요하다.
