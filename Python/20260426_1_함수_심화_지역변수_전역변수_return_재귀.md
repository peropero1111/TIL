# TIL - 함수 심화: 지역변수, 전역변수, return, 재귀

> 원본 자료: `-`  
> 학습 주제: 함수명 규칙, 지역변수와 전역변수, `global`, `return`, 재귀 호출

## 오늘 배운 내용

이번 수업에서는 함수의 기본 개념에서 더 나아가 **함수 안과 밖에서 변수가 어떻게 다르게 동작하는지**, 함수가 결과를 호출한 곳으로 돌려주는 **`return`**, 그리고 함수가 자기 자신을 다시 호출하는 **재귀 함수**를 학습했다.

함수는 단순히 코드를 묶는 도구가 아니라, 데이터를 입력받고 처리한 뒤 결과를 돌려주는 독립적인 작업 단위로 사용할 수 있다. 따라서 함수 내부에서 만들어진 변수와 함수 외부에서 만들어진 변수를 구분해서 이해하는 것이 중요하다.

## 핵심 개념

### 1. 함수 이름을 지을 때 주의할 점

파이썬에서 함수를 만들 때는 `def` 키워드 뒤에 함수 이름을 적는다.

```python
def greet():
    print("Hello")
```

함수 이름은 아무렇게나 지을 수 있는 것이 아니라, 몇 가지 규칙을 지키는 것이 좋다.

| 규칙 | 설명 | 예시 |
|---|---|---|
| 내장 함수 이름과 겹치지 않기 | `print`, `len`, `input` 같은 이름은 피한다. | `my_print`, `get_length` |
| 숫자로 시작하지 않기 | 함수 이름의 첫 글자는 숫자가 될 수 없다. | `func2`는 가능, `2func`는 불가능 |
| 특수문자 사용하지 않기 | 하이픈 `-` 같은 특수문자는 사용할 수 없다. | `my_function` |
| 언더바 사용 가능 | 단어를 구분할 때 `_`를 사용할 수 있다. | `calculate_sum` |
| 의미 있는 이름 사용 | 함수가 하는 일을 이름으로 알 수 있게 한다. | `add_score`, `print_result` |

좋은 함수 이름은 코드를 읽는 사람이 함수의 역할을 쉽게 이해할 수 있게 해 준다.

```python
# 좋지 않은 예

def a(x, y):
    return x + y

# 더 좋은 예

def add_numbers(x, y):
    return x + y
```

## 지역변수와 전역변수

### 1. 지역변수

지역변수(local variable)는 함수 내부에서 선언된 변수다. 함수 안에서 만들어졌기 때문에 함수 내부에서만 사용할 수 있다.

```python
def func1():
    a = 10
    print(a)

func1()
```

위 코드에서 `a`는 `func1()` 함수 안에서 만들어진 지역변수다. 따라서 함수 밖에서는 `a`를 사용할 수 없다.

```python
def func1():
    a = 10

func1()
print(a)   # 오류 발생
```

`a`는 함수 내부에서만 존재하므로 함수 밖에서 출력하려고 하면 오류가 발생한다.

### 2. 전역변수

전역변수(global variable)는 함수 밖에서 선언된 변수다. 함수 바깥에 있기 때문에 프로그램 전체에서 접근할 수 있다.

```python
num = 100

def func1():
    print(num)

func1()
print(num)
```

출력 결과는 다음과 같다.

```text
100
100
```

`num`은 함수 밖에서 만들어졌기 때문에 함수 안에서도 읽을 수 있고, 함수 밖에서도 사용할 수 있다.

## 같은 이름이어도 지역변수와 전역변수는 다를 수 있다

함수 안과 밖에 같은 이름의 변수가 있을 수 있다. 이 경우 함수 안에서 새로 선언된 변수는 지역변수로 취급된다.

```python
num = 100

def func1():
    num = 10
    print("함수 안:", num)

func1()
print("함수 밖:", num)
```

출력 결과는 다음과 같다.

```text
함수 안: 10
함수 밖: 100
```

함수 안의 `num`과 함수 밖의 `num`은 이름만 같을 뿐 서로 다른 변수다.

```text
함수 안 num  → 지역변수
함수 밖 num  → 전역변수
```

즉, 함수 안에서 `num = 10`을 했다고 해서 함수 밖에 있는 `num = 100`이 바뀌는 것은 아니다.

## `global` 키워드

함수 안에서 전역변수의 값을 직접 바꾸고 싶을 때는 `global` 키워드를 사용한다.

```python
num = 100

def change_num():
    global num
    num = 200

change_num()
print(num)
```

출력 결과는 다음과 같다.

```text
200
```

`global num`은 “이 함수 안에서 사용하는 `num`은 지역변수가 아니라 전역변수 `num`이다”라는 뜻이다.

### `global`을 사용하지 않으면 생기는 문제

다음 코드는 오류가 발생할 수 있다.

```python
num = 10

def add_num():
    num = num + 1
    print(num)

add_num()
```

함수 안에서 `num = num + 1`처럼 값을 수정하려고 하면, 파이썬은 `num`을 지역변수로 판단한다. 그런데 오른쪽의 `num + 1`을 계산하려는 순간 아직 지역변수 `num`에 값이 없기 때문에 오류가 발생한다.

이럴 때는 다음처럼 작성해야 한다.

```python
num = 10

def add_num():
    global num
    num = num + 1
    print(num)

add_num()
print(num)
```

출력 결과는 다음과 같다.

```text
11
11
```

다만 `global`을 너무 많이 사용하면 함수가 외부 변수에 강하게 의존하게 된다. 그래서 가능하면 함수는 필요한 값을 매개변수로 받고, 결과를 `return`으로 돌려주는 방식이 더 좋다.

## `return` 키워드

### 1. 값을 호출한 곳으로 돌려주기

함수는 작업을 수행한 뒤 결과를 호출한 곳으로 돌려줄 수 있다. 이때 사용하는 키워드가 `return`이다.

```python
def plus(a, b):
    result = a + b
    return result

answer = plus(3, 5)
print(answer)
```

출력 결과는 다음과 같다.

```text
8
```

`plus(3, 5)`를 호출하면 함수 내부에서 `3 + 5`를 계산하고, 그 결과인 `8`을 호출한 곳으로 돌려준다. 그래서 `answer`에는 `8`이 저장된다.

### 2. `print()`와 `return`의 차이

`print()`는 화면에 값을 출력하는 역할을 한다. 반면 `return`은 값을 함수 밖으로 돌려주는 역할을 한다.

```python
def print_plus(a, b):
    print(a + b)

def return_plus(a, b):
    return a + b

x = print_plus(3, 5)
y = return_plus(3, 5)

print("x:", x)
print("y:", y)
```

출력 결과는 다음과 같다.

```text
8
x: None
y: 8
```

`print_plus()`는 화면에 `8`을 출력하지만, 값을 돌려주지는 않는다. 그래서 `x`에는 `None`이 저장된다. 반면 `return_plus()`는 `8`을 함수 밖으로 돌려주기 때문에 `y`에는 `8`이 저장된다.

```text
print()  → 화면에 보여주기
return   → 호출한 곳으로 값 돌려주기
```

### 3. `return`은 함수를 종료한다

`return`은 값을 돌려주는 역할뿐만 아니라, 함수를 즉시 종료하는 역할도 한다.

```python
def check_age(age):
    if age < 0:
        return "나이는 음수가 될 수 없습니다."

    if age >= 20:
        return "성인입니다."

    return "미성년자입니다."

print(check_age(25))
print(check_age(-3))
```

출력 결과는 다음과 같다.

```text
성인입니다.
나이는 음수가 될 수 없습니다.
```

`return`을 만나면 함수는 그 즉시 끝난다. 따라서 `age < 0`인 경우에는 아래쪽 조건문을 더 이상 확인하지 않고 바로 종료된다.

## 재귀 함수

### 1. 재귀 함수란?

**재귀 함수(recursive function)**는 함수 안에서 자기 자신을 다시 호출하는 함수다.

```python
def hello():
    print("hello")
    hello()

hello()
```

이 코드는 `hello()` 함수가 자기 자신을 계속 호출하기 때문에 끝나지 않는다. 결국 함수 호출이 너무 많이 쌓이면 `RecursionError`가 발생한다.

재귀 함수가 정상적으로 동작하려면 반드시 **종료 조건**이 필요하다.

```text
재귀 함수의 핵심
1. 종료 조건이 있어야 한다.
2. 자기 자신을 다시 호출해야 한다.
3. 다시 호출할 때는 종료 조건에 가까워져야 한다.
```

### 2. 종료 조건이 있는 재귀 함수

다음은 숫자를 하나씩 줄이면서 출력하는 재귀 함수다.

```python
def countdown(n):
    if n <= 0:
        print("끝")
        return

    print(n)
    countdown(n - 1)

countdown(5)
```

출력 결과는 다음과 같다.

```text
5
4
3
2
1
끝
```

여기서 종료 조건은 `n <= 0`이다. `n`이 0 이하가 되면 더 이상 자기 자신을 호출하지 않고 `return`으로 함수를 종료한다.

```text
countdown(5)
→ countdown(4)
→ countdown(3)
→ countdown(2)
→ countdown(1)
→ countdown(0)에서 종료
```

## 재귀 함수와 호출 스택

재귀 함수는 자기 자신을 다시 호출하기 때문에 함수 호출이 메모리에 차례대로 쌓인다. 이처럼 함수 호출이 쌓이는 공간을 보통 **호출 스택(call stack)**이라고 생각할 수 있다.

예를 들어 다음 함수가 있다고 하자.

```python
def sum_to_n(n):
    if n == 1:
        return 1
    return n + sum_to_n(n - 1)

print(sum_to_n(5))
```

이 함수는 다음과 같은 흐름으로 실행된다.

```text
sum_to_n(5)
= 5 + sum_to_n(4)
= 5 + 4 + sum_to_n(3)
= 5 + 4 + 3 + sum_to_n(2)
= 5 + 4 + 3 + 2 + sum_to_n(1)
= 5 + 4 + 3 + 2 + 1
= 15
```

출력 결과는 다음과 같다.

```text
15
```

종료 조건인 `n == 1`에 도달하면 `1`을 반환하고, 그 결과가 다시 이전 함수 호출로 차례대로 돌아간다.

## 재귀 함수 예제: 팩토리얼

팩토리얼은 재귀 함수를 설명할 때 자주 사용하는 예제다.

```text
5! = 5 × 4 × 3 × 2 × 1
```

이를 재귀 함수로 작성하면 다음과 같다.

```python
def factorial(n):
    if n <= 1:
        return 1
    return n * factorial(n - 1)

print(factorial(5))
```

출력 결과는 다음과 같다.

```text
120
```

실행 흐름은 다음과 같다.

```text
factorial(5)
= 5 * factorial(4)
= 5 * 4 * factorial(3)
= 5 * 4 * 3 * factorial(2)
= 5 * 4 * 3 * 2 * factorial(1)
= 5 * 4 * 3 * 2 * 1
= 120
```

## 반복문과 재귀 함수 비교

같은 문제를 반복문으로 풀 수도 있고 재귀 함수로 풀 수도 있다.

### 반복문으로 1부터 n까지 합 구하기

```python
def sum_loop(n):
    total = 0

    for i in range(1, n + 1):
        total += i

    return total

print(sum_loop(5))
```

### 재귀 함수로 1부터 n까지 합 구하기

```python
def sum_recursive(n):
    if n == 1:
        return 1
    return n + sum_recursive(n - 1)

print(sum_recursive(5))
```

두 코드 모두 결과는 `15`다. 하지만 동작 방식은 다르다.

| 구분 | 반복문 | 재귀 함수 |
|---|---|---|
| 방식 | 같은 코드를 반복 실행 | 함수가 자기 자신을 호출 |
| 종료 | 반복 조건이 거짓이 되면 종료 | 종료 조건에 도달하면 종료 |
| 장점 | 이해하기 쉽고 메모리 사용이 적은 편 | 문제 구조가 재귀적일 때 표현이 간결함 |
| 주의점 | 반복 조건과 증감식을 잘 작성해야 함 | 종료 조건이 없으면 `RecursionError` 발생 |

처음 프로그래밍을 배울 때는 반복문이 더 직관적일 수 있다. 하지만 트리 구조, 하위 문제로 나눌 수 있는 문제, 팩토리얼 같은 수학적 정의에서는 재귀 함수가 자연스럽게 사용된다.

## 함수 작성 연습

### 1. 값을 입력받아 처리하고 반환하는 함수

```python
def get_average(score1, score2, score3):
    total = score1 + score2 + score3
    average = total / 3
    return average

avg = get_average(90, 80, 70)
print(avg)
```

출력 결과는 다음과 같다.

```text
80.0
```

이 함수는 세 점수를 입력받아 평균을 계산한 뒤 `return`으로 결과를 돌려준다.

### 2. 전역변수보다 매개변수와 return 사용하기

전역변수를 사용하면 코드를 짧게 쓸 수 있지만, 함수가 외부 상태에 의존하게 되어 코드를 이해하기 어려워질 수 있다.

```python
# 전역변수에 의존하는 방식

total = 0

def add_score(score):
    global total
    total += score

add_score(90)
add_score(80)
print(total)
```

가능하면 다음처럼 매개변수와 `return`을 사용하는 편이 더 좋다.

```python
def add_score(total, score):
    total += score
    return total

total = 0
total = add_score(total, 90)
total = add_score(total, 80)
print(total)
```

이 방식은 함수가 어떤 값을 입력받고 어떤 값을 돌려주는지 더 명확하다.

## 코드에서 주의할 점

- 함수 이름은 함수의 역할이 드러나도록 짓는다.
- `print`, `len`, `input` 같은 내장 함수 이름을 함수명으로 사용하지 않는다.
- 함수 안에서 만든 지역변수는 함수 밖에서 사용할 수 없다.
- 함수 안과 밖에 같은 이름의 변수가 있으면 서로 다른 변수일 수 있다.
- 전역변수의 값을 함수 안에서 바꾸려면 `global` 키워드가 필요하다.
- 하지만 `global`은 꼭 필요한 경우에만 사용하는 것이 좋다.
- `print()`는 화면 출력이고, `return`은 값을 함수 밖으로 돌려주는 것이다.
- `return`을 만나면 함수는 즉시 종료된다.
- 재귀 함수에는 반드시 종료 조건이 있어야 한다.
- 재귀 호출이 너무 깊어지면 `RecursionError`가 발생할 수 있다.

## 오늘의 정리

함수는 코드를 묶어 재사용하기 위한 도구이면서, 입력값을 처리하고 결과를 돌려주는 독립적인 작업 단위다.

지역변수는 함수 내부에서만 사용할 수 있고, 전역변수는 함수 밖에서 선언되어 여러 곳에서 사용할 수 있다. 하지만 전역변수에 지나치게 의존하면 코드가 복잡해질 수 있으므로, 가능하면 매개변수와 `return`을 이용해 데이터를 주고받는 방식이 좋다.

`return`은 함수의 결과를 호출한 곳으로 돌려주는 역할을 하며, 동시에 함수를 종료하는 역할도 한다.

재귀 함수는 자기 자신을 다시 호출하는 함수이며, 반드시 종료 조건을 가져야 한다. 종료 조건이 없으면 함수 호출이 끝없이 반복되어 오류가 발생할 수 있다.

```text
지역변수  → 함수 안에서만 사용
전역변수  → 함수 밖에서 선언되어 전체에서 사용 가능
global    → 함수 안에서 전역변수를 수정할 때 사용
return    → 결과 반환 및 함수 종료
```
