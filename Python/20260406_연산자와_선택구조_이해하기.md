# TIL - 연산자와 선택구조 이해하기

> 원본 자료: `-`  
> 학습 주제: 연산자, 조건식, 선택구조, `if`, `if~else`, `elif`, 블록문, 선택문 실습

## 오늘 배운 내용

이번 수업에서는 **연산자**와 **선택구조**를 배웠다.
연산자는 값을 계산하거나 비교하거나 조건을 판단할 때 사용하는 기호이다.
선택구조는 조건의 결과가 참인지 거짓인지에 따라 프로그램이 실행할 문장을 고르는 구조이다.

같은 날 함께 진행한 실습에서는 선택문을 실제 문제에 적용했다.
대표 예제로는 홀짝 맞추기 게임, 영화 나이 제한 검사, 좌표 평면 사분면 판별, 학점 계산기가 있다.

```text
조건이 참이면 → A 실행
조건이 거짓이면 → B 실행 또는 다음 조건 검사
```

즉, 선택구조를 이해하려면 먼저 **조건식이 어떻게 만들어지는지** 알아야 하고,
조건식을 만들기 위해서는 **산술 연산자, 관계 연산자, 논리 연산자**를 이해해야 한다.

## 연산이란?

연산은 일정한 규칙에 따라 어떤 결과를 만들어 내는 작업이다.

```python
a = 3
z = x + y
```

위 코드에서 `=`는 값을 변수에 저장하는 데 사용되고,
`+`는 두 값을 더하는 데 사용된다.

여기서 `+`, `-`, `*`, `/`, `==`, `>`, `<`, `and`, `or` 같은 기호나 단어를 **연산자**라고 한다.

## 연산자의 종류

연산자는 크게 다음과 같이 나눌 수 있다.

| 종류 | 의미 | 예시 |
|---|---|---|
| 산술 연산자 | 숫자를 계산함 | `+`, `-`, `*`, `/`, `%`, `//`, `**` |
| 관계 연산자 | 두 값을 비교함 | `==`, `!=`, `>`, `<`, `>=`, `<=` |
| 논리 연산자 | 여러 조건을 조합함 | `and`, `or`, `not` |

## 산술 연산자

산술 연산자는 숫자 계산에 사용하는 연산자이다.

| 연산자 | 의미 | 예시 | 결과 |
|---|---|---|---|
| `+` | 더하기 | `3 + 2` | `5` |
| `-` | 빼기 | `3 - 2` | `1` |
| `*` | 곱하기 | `3 * 2` | `6` |
| `/` | 나누기 | `5 / 2` | `2.5` |
| `%` | 나머지 | `5 % 2` | `1` |
| `//` | 몫 | `5 // 2` | `2` |
| `**` | 거듭제곱 | `2 ** 3` | `8` |

### 산술 연산자 예제

```python
a = 10
b = 3

print(a + b)   # 13
print(a - b)   # 7
print(a * b)   # 30
print(a / b)   # 3.3333333333333335
print(a % b)   # 1
print(a // b)  # 3
print(a ** b)  # 1000
```

`/`는 나눗셈 결과를 실수로 만든다.
`//`는 나눈 결과에서 몫만 구하고, `%`는 나머지를 구한다.

예를 들어 홀수와 짝수를 구분할 때는 `%`를 자주 사용한다.

```python
num = 7

if num % 2 == 0:
    print("짝수")
else:
    print("홀수")
```

## 관계 연산자

관계 연산자는 두 값을 비교할 때 사용한다.
결과는 항상 `True` 또는 `False`가 된다.

| 연산자 | 의미 | 예시 | 결과 |
|---|---|---|---|
| `==` | 같다 | `3 == 3` | `True` |
| `!=` | 같지 않다 | `3 != 5` | `True` |
| `>` | 크다 | `5 > 3` | `True` |
| `<` | 작다 | `5 < 3` | `False` |
| `>=` | 크거나 같다 | `5 >= 5` | `True` |
| `<=` | 작거나 같다 | `3 <= 5` | `True` |

### 관계 연산자 예제

```python
score = 90

print(score >= 90)  # True
print(score < 60)   # False
```

관계 연산자는 주로 `if`문이나 반복문의 조건식에서 사용된다.

```python
score = 95

if score >= 90:
    print("통과")
```

여기서 `score >= 90`이 조건식이다.
조건식의 결과가 `True`이면 `print("통과")`가 실행된다.

## 논리 연산자

논리 연산자는 여러 조건을 연결하거나 조건의 결과를 반대로 바꿀 때 사용한다.

| 연산자 | 의미 | 설명 |
|---|---|---|
| `and` | 그리고 | 두 조건이 모두 참이면 참 |
| `or` | 또는 | 두 조건 중 하나라도 참이면 참 |
| `not` | 아니다 | 참을 거짓으로, 거짓을 참으로 바꿈 |

### `and`

```python
score = 85
attendance = 90

if score >= 80 and attendance >= 80:
    print("수료")
```

`and`는 두 조건이 모두 참이어야 전체 조건이 참이 된다.

```text
score >= 80       → True
attendance >= 80  → True
전체 조건          → True
```

### `or`

```python
coupon = True
point = 5000

if coupon == True or point >= 10000:
    print("할인 가능")
```

`or`는 두 조건 중 하나만 참이어도 전체 조건이 참이 된다.

### `not`

```python
is_raining = False

if not is_raining:
    print("운동하러 간다")
```

`not`은 조건의 결과를 반대로 만든다.
`is_raining`이 `False`이므로 `not is_raining`은 `True`가 된다.

## 선택구조란?

선택구조는 조건에 따라 실행할 문장을 선택하는 구조이다.

일상생활 예시는 다음과 같다.

```text
날씨가 좋으면 운동을 한다.
그렇지 않으면 공부를 한다.
```

프로그램에서는 이런 상황을 조건식으로 표현한다.

```python
weather = "sunny"

if weather == "sunny":
    print("운동을 한다")
else:
    print("공부를 한다")
```

선택구조에서 중요한 것은 **조건이 참일 때와 거짓일 때를 정확히 구별하는 것**이다.

## `if`문

`if`문은 조건이 참일 때만 특정 문장을 실행한다.

```python
if 조건식:
    실행할 문장
```

예를 들어 중간고사 점수가 90점 이상이면 통과라고 출력할 수 있다.

```python
midterm_score = 95

if midterm_score >= 90:
    print("통과")
```

조건식 `midterm_score >= 90`의 결과가 `True`이면 `print("통과")`가 실행된다.
조건식이 `False`이면 들여쓰기 된 문장은 실행되지 않고 다음 문장으로 넘어간다.

## `if~else`문

`if~else`문은 조건이 참일 때와 거짓일 때의 처리를 나누고 싶을 때 사용한다.

```python
if 조건식:
    조건이 참일 때 실행할 문장
else:
    조건이 거짓일 때 실행할 문장
```

예를 들어 중간고사 점수가 90점 이상이면 통과,
그렇지 않으면 재시험이라고 출력할 수 있다.

```python
midterm_score = 75

if midterm_score >= 90:
    print("통과")
else:
    print("재시험")
```

위 코드에서는 `midterm_score >= 90`이 `False`이므로 `else` 아래의 문장이 실행된다.

```text
재시험
```

## `if~elif~else`문

조건이 여러 개일 때는 `elif`를 함께 사용할 수 있다.

```python
if 조건식1:
    조건식1이 참일 때 실행
elif 조건식2:
    조건식1은 거짓이고 조건식2가 참일 때 실행
else:
    모든 조건이 거짓일 때 실행
```

예를 들어 점수에 따라 등급을 출력할 수 있다.

```python
score = 83

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
else:
    print("F")
```

위 코드의 결과는 다음과 같다.

```text
B
```

`score`가 83이므로 `score >= 90`은 거짓이고,
`score >= 80`은 참이기 때문에 `B`가 출력된다.

## 입력값을 이용한 선택문

`input()`으로 입력받은 값은 기본적으로 문자열이다.
숫자로 비교하려면 `int()`나 `float()`로 변환해야 한다.

```python
score = int(input("점수 입력: "))

if score >= 90:
    print("통과")
else:
    print("재시험")
```

만약 `int()`를 사용하지 않으면 `score`는 문자열이기 때문에 숫자와 비교할 수 없다.

```python
score = input("점수 입력: ")

# 잘못된 예시
# if score >= 90:
#     print("통과")
```

문자열과 정수를 직접 비교하면 오류가 발생할 수 있다.

## 예제 1: 두 수 중 큰 수 출력하기

```python
a = int(input("첫 번째 수: "))
b = int(input("두 번째 수: "))

if a > b:
    print("큰 수:", a)
else:
    print("큰 수:", b)
```

입력 예시는 다음과 같다.

```text
첫 번째 수: 7
두 번째 수: 12
```

실행 결과는 다음과 같다.

```text
큰 수: 12
```

## 예제 2: 짝수와 홀수 판별하기

```python
num = int(input("정수 입력: "))

if num % 2 == 0:
    print("짝수")
else:
    print("홀수")
```

`num % 2`의 결과가 `0`이면 2로 나누어떨어진다는 뜻이므로 짝수이다.
그렇지 않으면 홀수이다.

## 예제 3: 범위 검사하기

여러 조건을 동시에 검사할 때는 `and`를 사용할 수 있다.

```python
age = int(input("나이 입력: "))

if age >= 13 and age <= 19:
    print("청소년")
else:
    print("청소년이 아님")
```



## 같은 날 추가 수업: 선택구조 실습 예제

선택문을 사용하여 조금 더 복잡한 프로그램을 개발하는 실습을 진행했다.
핵심은 사용자가 입력한 값을 조건식으로 검사하고, 조건에 따라 다른 결과를 출력하는 것이다.

```text
입력 받기 → 조건식 만들기 → 조건에 맞는 결과 출력하기
```

### 1. 블록문과 들여쓰기

파이썬에서는 조건에 해당될 때 실행되어야 하는 문장들을 들여쓰기로 묶는다.
이렇게 묶인 문장들을 하나의 **블록**이라고 볼 수 있다.

```python
age = int(input("나이 입력: "))

if age >= 15:
    print("관람 가능")
    print("영화표 가격은 12000원입니다")
else:
    print("관람 불가")
```

위 코드에서 `age >= 15`가 참이면 들여쓰기 된 두 문장이 함께 실행된다.
반대로 조건이 거짓이면 `else` 아래의 블록이 실행된다.

잘못된 들여쓰기는 코드가 의도와 다르게 실행되는 원인이 된다.

```python
age = int(input("나이 입력: "))

if age >= 15:
    print("관람 가능")
print("영화표 가격은 12000원입니다")  # if문 밖이므로 항상 실행됨
```

이 경우 두 번째 `print()`는 `if`문 밖에 있으므로 나이와 상관없이 항상 실행된다.

### 2. 홀짝 맞추기 게임

입력받은 숫자가 홀수인지 짝수인지 알려주는 프로그램이다.
짝수와 홀수는 나머지 연산자 `%`를 사용해서 구분할 수 있다.

```python
num = int(input("숫자 입력: "))

if num % 2 == 0:
    print("짝수입니다")
else:
    print("홀수입니다")
```

`num % 2`는 `num`을 2로 나눈 나머지를 뜻한다.

```text
나머지가 0이면 → 짝수
나머지가 1이면 → 홀수
```

이 예제에서 중요한 점은 `input()`으로 받은 값은 문자열이므로,
나머지 연산을 하기 전에 `int()`로 정수 변환을 해야 한다는 것이다.

### 3. 영화 나이 제한 검사

영화 관람 가능 여부를 나이에 따라 판단하는 예제이다.
예를 들어 제한 연령이 15세라면, 입력받은 나이가 15세 이상인지 검사하면 된다.

```python
age = int(input("나이 입력: "))

if age >= 15:
    print("영화를 관람할 수 있습니다")
else:
    print("영화를 관람할 수 없습니다")
```

여기에 영화표 가격까지 함께 출력하려면 `if` 블록 안에 문장을 여러 개 넣으면 된다.

```python
age = int(input("나이 입력: "))

if age >= 15:
    print("영화를 관람할 수 있습니다")
    print("영화표 가격은 12000원입니다")
else:
    print("영화를 관람할 수 없습니다")
```

이 예제에서 중요한 점은 관람 가능 안내와 가격 안내가 같은 들여쓰기 수준에 있어야 한다는 것이다.
그래야 조건이 참일 때 두 문장이 함께 실행된다.

### 4. 좌표 평면의 사분면 판별

`x`, `y` 값을 입력받아 좌표가 몇 사분면에 있는지 출력하는 프로그램이다.
사분면은 `x`와 `y`의 부호에 따라 결정된다.

| 조건 | 결과 |
|---|---|
| `x > 0` 그리고 `y > 0` | 1사분면 |
| `x < 0` 그리고 `y > 0` | 2사분면 |
| `x < 0` 그리고 `y < 0` | 3사분면 |
| `x > 0` 그리고 `y < 0` | 4사분면 |
| `x == 0` 그리고 `y == 0` | 종료 |

```python
while True:
    x = int(input("x 입력: "))
    y = int(input("y 입력: "))

    if x == 0 and y == 0:
        print("프로그램을 종료합니다")
        break
    elif x > 0 and y > 0:
        print("1사분면")
    elif x < 0 and y > 0:
        print("2사분면")
    elif x < 0 and y < 0:
        print("3사분면")
    elif x > 0 and y < 0:
        print("4사분면")
    else:
        print("x축 또는 y축 위의 점입니다")
```

여기서는 조건이 여러 개이므로 `if~elif~else` 구조를 사용하는 것이 적절하다.
각 조건은 서로 다른 경우를 처리한다.

```text
if      : 첫 번째 조건 검사
elif    : 앞 조건이 거짓일 때 다음 조건 검사
else    : 모든 조건이 거짓일 때 실행
```

### 5. 학점 계산기

점수를 입력받아 학점을 출력하는 프로그램이다.
처음에는 여러 개의 `if`를 따로 사용해서 작성할 수 있다.
하지만 조건의 범위가 겹치면 예상하지 못한 결과가 나올 수 있다.

#### 잘못 작성하기 쉬운 코드

```python
score = int(input("점수 입력: "))

if score >= 90:
    print("A")
if score >= 80:
    print("B")
if score >= 70:
    print("C")
if score >= 60:
    print("D")
else:
    print("F")
```

이 코드는 `score`가 `97`일 때 문제가 생긴다.
`97 >= 90`, `97 >= 80`, `97 >= 70`, `97 >= 60`이 모두 참이기 때문이다.
따라서 `A`, `B`, `C`, `D`가 모두 출력될 수 있다.

```text
점수 입력: 97
A
B
C
D
```

이런 상황에서는 각각의 조건을 독립적인 `if`로 쓰면 안 되고,
한 번 결정되면 다음 조건을 검사하지 않는 `elif`를 사용해야 한다.

#### `elif`를 사용한 올바른 코드

```python
score = int(input("점수 입력: "))

if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
elif score >= 60:
    print("D")
else:
    print("F")
```

이 코드에서는 `score >= 90`이 참이면 `A`를 출력하고,
그 아래의 `elif` 조건들은 더 이상 검사하지 않는다.
그래서 점수가 97이면 결과는 `A` 하나만 나온다.

```text
점수 입력: 97
A
```

#### 범위를 더 명확하게 표현한 코드

조건 범위를 더 자세히 쓰고 싶다면 다음처럼 작성할 수도 있다.

```python
score = int(input("점수 입력: "))

if 90 <= score <= 100:
    print("A")
elif 80 <= score < 90:
    print("B")
elif 70 <= score < 80:
    print("C")
elif 60 <= score < 70:
    print("D")
elif 0 <= score < 60:
    print("F")
else:
    print("잘못된 점수입니다")
```

이 방식은 입력값이 `0`부터 `100` 사이가 아닐 때도 처리할 수 있다.

### 6. 선택문 작성 순서

선택문 문제를 풀 때는 바로 코드를 쓰기보다 조건을 먼저 정리하면 좋다.

```text
1. 입력값 정하기
2. 조건식 만들기
3. 조건이 참일 때 실행할 문장 작성하기
4. 조건이 거짓일 때 실행할 문장 작성하기
5. 조건이 여러 개라면 if~elif~else로 정리하기
```

예를 들어 학점 계산기는 다음처럼 생각할 수 있다.

```text
입력값: score
조건 1: score >= 90 → A
조건 2: score >= 80 → B
조건 3: score >= 70 → C
조건 4: score >= 60 → D
그 외: F
```

이렇게 조건을 글로 정리한 뒤 코드로 바꾸면 실수를 줄일 수 있다.

### 독립적인 `if`와 `elif`의 차이

여러 조건 중 하나만 실행되어야 한다면 `elif`를 사용해야 한다.
반대로 여러 조건을 각각 따로 검사해야 한다면 독립적인 `if`를 사용할 수 있다.

| 구조 | 의미 | 사용 상황 |
|---|---|---|
| 여러 개의 `if` | 조건을 각각 모두 검사 | 여러 결과가 동시에 나와도 되는 경우 |
| `if~elif~else` | 조건 중 하나만 선택 | 학점, 등급, 사분면처럼 결과가 하나여야 하는 경우 |

예를 들어 학점 계산기는 한 학생에게 하나의 학점만 나와야 하므로 `if~elif~else`가 적합하다.
사분면 판별도 한 좌표가 동시에 여러 사분면에 속할 수 없으므로 `if~elif~else`가 적합하다.

## 코드에서 주의할 점

### 1. `=`와 `==`를 구분하기

`=`는 값을 저장하는 대입 연산자이다.
`==`는 두 값이 같은지 비교하는 관계 연산자이다.

```python
score = 90      # score에 90 저장
score == 90     # score가 90과 같은지 비교
```

조건식에서 같은지 비교할 때는 `==`를 사용한다.

### 2. 들여쓰기를 정확히 하기

파이썬은 들여쓰기로 코드 블록을 구분한다.

```python
if score >= 90:
    print("통과")
    print("축하합니다")
```

위 코드에서 두 개의 `print()`는 모두 `if`문 안에 포함된다.

잘못된 들여쓰기는 오류를 만들거나 실행 흐름을 다르게 만든다.

```python
if score >= 90:
    print("통과")
print("프로그램 종료")
```

이 경우 `print("프로그램 종료")`는 `if`문 밖에 있으므로 조건과 상관없이 항상 실행된다.

### 3. 조건식의 결과는 `True` 또는 `False`

조건식은 반드시 참 또는 거짓으로 판단될 수 있어야 한다.

```python
print(10 > 5)       # True
print(10 == 5)      # False
print(10 != 5)      # True
```

파이썬에서 `True`와 `False`는 첫 글자가 대문자이다.

### 4. 복잡한 조건은 괄호로 묶으면 읽기 쉽다

```python
score = 85
attendance = 90

if (score >= 80) and (attendance >= 80):
    print("수료")
```

괄호가 없어도 동작할 수 있지만,
조건이 길어질수록 괄호를 사용하면 의미를 더 명확하게 볼 수 있다.

### 5. 입력값은 필요한 자료형으로 변환하기

`input()`으로 받은 값은 문자열이다.
따라서 숫자 계산이나 숫자 비교를 하려면 `int()` 또는 `float()`로 변환해야 한다.

```python
age = int(input("나이 입력: "))
score = float(input("점수 입력: "))
```

### 6. 결과가 하나만 나와야 하면 `elif` 사용하기

학점 계산기처럼 하나의 결과만 출력되어야 하는 문제에서 여러 개의 `if`문을 따로 사용하면 여러 조건이 동시에 참이 될 수 있다.

```python
score = 97

if score >= 90:
    print("A")
if score >= 80:
    print("B")
```

위 코드는 `A`와 `B`가 모두 출력될 수 있다.
이런 경우에는 `elif`를 사용한다.

```python
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
```

## 오늘의 정리

연산자는 값을 계산하거나 비교하거나 조건을 판단할 때 사용한다.
산술 연산자는 계산을 수행하고, 관계 연산자는 두 값을 비교하며,
논리 연산자는 여러 조건을 연결한다.

선택구조는 조건식의 결과에 따라 실행할 문장을 선택하는 구조이다.
`if`문은 조건이 참일 때만 실행하고,
`if~else`문은 조건이 참일 때와 거짓일 때를 나누어 처리한다.
조건이 여러 개이고 결과가 하나만 나와야 한다면 `if~elif~else` 구조를 사용하는 것이 좋다.

파이썬에서 선택문을 사용할 때는 `:`와 들여쓰기를 정확히 작성해야 하며,
입력값을 숫자로 비교하려면 `int()`나 `float()`로 자료형을 변환해야 한다.

같은 날 진행한 선택구조 실습에서는 홀짝 판별, 영화 나이 제한 검사, 좌표 평면 사분면 판별, 학점 계산기를 작성했다.
이 예제들은 모두 입력값을 조건식으로 검사하고, 조건에 맞는 결과를 출력한다는 공통점을 가진다.
특히 학점 계산기처럼 여러 조건 중 하나만 선택해야 하는 경우에는 독립적인 `if`를 여러 번 쓰기보다 `elif`를 사용하는 것이 더 안전하다.
