# TIL - 선택 정렬 알고리즘

> 원본 자료: `-`  
> 학습 주제: 선택 정렬 알고리즘, 최솟값 탐색, swap, 시간 복잡도

## 오늘 배운 내용

선택 정렬은 리스트에서 **가장 작은 값을 선택해서 앞쪽부터 차례대로 배치하는 정렬 알고리즘**이다.

운동장에 학생들이 서 있을 때, 선생님이 남아 있는 학생들 중 키가 가장 작은 학생을 한 명씩 골라 앞에서부터 줄 세우는 방식과 비슷하다.

즉 선택 정렬의 핵심은 다음과 같다.

```text
남은 데이터 중 최솟값을 찾는다.
그 최솟값을 현재 위치로 옮긴다.
이 과정을 끝까지 반복한다.
```

## 선택 정렬의 기본 아이디어

예를 들어 다음 리스트가 있다고 하자.

```python
data = [2, 4, 5, 1, 3]
```

선택 정렬은 **가장 앞 위치부터 값을 하나씩 확정**한다.  
즉, `i = 0`부터 시작해서 `i` 위치에 들어갈 최솟값을 남은 구간에서 찾고, 그 값을 `i` 위치와 바꾼다.

```text
[ 정렬 완료 구간 | 아직 정렬되지 않은 구간 ]
```

아래 표에서 `|` 왼쪽은 이미 정렬이 끝난 구간이고, `|` 오른쪽은 아직 최솟값을 찾아야 하는 구간이다.

| 단계 | 이번에 확정할 위치 `i` | 확정 전 상태 | 최솟값을 찾는 구간 | 선택한 최솟값 | 바꾸는 위치 | 확정 후 상태 |
|---:|---:|---|---|---:|---|---|
| 1 | `0` | `[2, 4, 5, 1, 3]` | `0~4` → `[2, 4, 5, 1, 3]` | `1` | `idx 0 ↔ idx 3` | `[1 \| 4, 5, 2, 3]` |
| 2 | `1` | `[1 \| 4, 5, 2, 3]` | `1~4` → `[4, 5, 2, 3]` | `2` | `idx 1 ↔ idx 3` | `[1, 2 \| 5, 4, 3]` |
| 3 | `2` | `[1, 2 \| 5, 4, 3]` | `2~4` → `[5, 4, 3]` | `3` | `idx 2 ↔ idx 4` | `[1, 2, 3 \| 4, 5]` |
| 4 | `3` | `[1, 2, 3 \| 4, 5]` | `3~4` → `[4, 5]` | `4` | 변경 없음 | `[1, 2, 3, 4 \| 5]` |

값이 조정되는 시작점은 항상 `i` 위치이다.  
1단계에서는 `0번 위치`, 2단계에서는 `1번 위치`, 3단계에서는 `2번 위치`처럼 앞에서 뒤로 이동하면서 값을 확정한다.

```text
1단계: i = 0
[2, 4, 5, 1, 3]
 ↑        ↑
 i      최솟값

swap 후
[1 | 4, 5, 2, 3]

2단계: i = 1
[1 | 4, 5, 2, 3]
     ↑     ↑
     i   최솟값

swap 후
[1, 2 | 5, 4, 3]

3단계: i = 2
[1, 2 | 5, 4, 3]
        ↑     ↑
        i   최솟값

swap 후
[1, 2, 3 | 4, 5]
```

정리하면 선택 정렬의 위치 조정 흐름은 다음과 같다.

```text
현재 위치 i를 정한다.
남은 구간 i~끝에서 최솟값을 찾는다.
최솟값을 i 위치와 바꾼다.
i를 한 칸 뒤로 옮긴다.
```

## 쉽게 설명한 선택 정렬

먼저 이해하기 쉬운 방식으로 선택 정렬을 작성할 수 있다.  
이 방식은 원래 리스트에서 최솟값을 하나씩 꺼내 새로운 리스트에 넣는다.

### 최솟값 위치 찾기

```python
def find_min_idx(a):
    n = len(a)
    min_idx = 0

    for i in range(1, n):
        if a[i] < a[min_idx]:
            min_idx = i

    return min_idx
```

`min_idx`는 현재까지 찾은 최솟값의 위치를 저장한다.

```python
if a[i] < a[min_idx]:
    min_idx = i
```

위 조건이 참이면 더 작은 값을 찾은 것이므로 최솟값의 위치를 갱신한다.

### 새 리스트에 정렬 결과 저장하기

```python
def sel_sort(a):
    result = []

    while a:
        min_idx = find_min_idx(a)
        value = a.pop(min_idx)
        result.append(value)

    return result


d = [2, 4, 5, 1, 3]
print(sel_sort(d))
```

실행 결과는 다음과 같다.

```text
[1, 2, 3, 4, 5]
```

이 코드는 선택 정렬의 원리를 이해하기 좋다.

```text
1. 남은 리스트에서 최솟값의 위치를 찾는다.
2. 그 값을 pop()으로 꺼낸다.
3. result 리스트 뒤에 붙인다.
4. 원래 리스트가 빌 때까지 반복한다.
```

다만 이 방식은 `pop()`을 사용하므로 원래 리스트 `a`의 값이 사라진다.

```python
d = [2, 4, 5, 1, 3]
answer = sel_sort(d)

print(answer)  # [1, 2, 3, 4, 5]
print(d)       # []
```

원본 리스트를 유지하고 싶다면 복사본을 넘기면 된다.

```python
d = [2, 4, 5, 1, 3]
answer = sel_sort(d[:])

print(answer)
print(d)
```

## 일반적인 선택 정렬 알고리즘

실제로 더 자주 사용하는 선택 정렬은 새 리스트를 만들지 않고, 입력 리스트 안에서 직접 값을 교환한다.

```python
def selection_sort(a):
    n = len(a)

    for i in range(0, n - 1):
        min_idx = i

        for j in range(i + 1, n):
            if a[j] < a[min_idx]:
                min_idx = j

        a[i], a[min_idx] = a[min_idx], a[i]
```

사용 예시는 다음과 같다.

```python
d = [2, 4, 5, 1, 3]
selection_sort(d)
print(d)
```

실행 결과는 다음과 같다.

```text
[1, 2, 3, 4, 5]
```

이 함수는 값을 `return`하지 않아도 된다.  
리스트 `a` 자체를 직접 수정하기 때문이다.

## 코드 흐름 자세히 보기

```python
for i in range(0, n - 1):
```

`i`는 현재 최솟값을 넣을 위치이다.  
마지막 원소는 앞의 원소들이 모두 정렬되면 자동으로 정렬되므로 `n - 1`번까지만 반복해도 된다.

```python
min_idx = i
```

처음에는 현재 위치 `i`에 있는 값이 가장 작다고 가정한다.

```python
for j in range(i + 1, n):
```

`i + 1`부터 끝까지 보면서 더 작은 값이 있는지 찾는다.

```python
if a[j] < a[min_idx]:
    min_idx = j
```

더 작은 값을 찾으면 최솟값의 위치를 바꾼다.

```python
a[i], a[min_idx] = a[min_idx], a[i]
```

최솟값을 현재 위치 `i`로 이동시킨다.

## swap

선택 정렬에서는 최솟값을 찾은 뒤 현재 위치와 자리를 바꿔야 한다.  
이 과정을 `swap`이라고 한다.

파이썬에서는 다음처럼 간단하게 두 변수의 값을 바꿀 수 있다.

```python
a[i], a[min_idx] = a[min_idx], a[i]
```

## 내림차순 선택 정렬

오름차순에서는 남은 값 중 최솟값을 찾는다.  
내림차순에서는 남은 값 중 최댓값을 찾으면 된다.

```python
def selection_sort_desc(a):
    n = len(a)

    for i in range(0, n - 1):
        max_idx = i

        for j in range(i + 1, n):
            if a[j] > a[max_idx]:
                max_idx = j

        a[i], a[max_idx] = a[max_idx], a[i]


d = [2, 4, 5, 1, 3]
selection_sort_desc(d)
print(d)
```

실행 결과는 다음과 같다.

```text
[5, 4, 3, 2, 1]
```

## 선택 정렬을 함수로 만들 때 생각할 점

정렬 함수를 만들 때는 먼저 함수가 어떤 방식으로 동작할지 정해야 한다.

### 1. 원본 리스트를 직접 바꾸는 함수

```python
def selection_sort(a):
    n = len(a)

    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if a[j] < a[min_idx]:
                min_idx = j
        a[i], a[min_idx] = a[min_idx], a[i]
```

이 방식은 원본 리스트가 바뀐다.

```python
data = [5, 3, 1]
selection_sort(data)
print(data)  # [1, 3, 5]
```

### 2. 정렬된 새 리스트를 반환하는 함수

```python
def selection_sorted(a):
    copied = a[:]
    n = len(copied)

    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if copied[j] < copied[min_idx]:
                min_idx = j
        copied[i], copied[min_idx] = copied[min_idx], copied[i]

    return copied
```

이 방식은 원본 리스트를 유지한다.

```python
data = [5, 3, 1]
result = selection_sorted(data)

print(result)  # [1, 3, 5]
print(data)    # [5, 3, 1]
```

## 시간 복잡도

선택 정렬은 남은 구간에서 최솟값을 찾기 위해 반복해서 비교한다.

데이터 개수가 `n`개라면 비교 횟수는 다음과 같다.

```text
첫 번째 단계: n - 1번 비교
두 번째 단계: n - 2번 비교
세 번째 단계: n - 3번 비교
...
마지막 단계: 1번 비교
```

따라서 전체 비교 횟수는 다음과 같다.

```text
(n - 1) + (n - 2) + ... + 1 = n(n - 1) / 2
```

그래서 선택 정렬의 시간 복잡도는 다음과 같다.

```text
O(n²)
```

선택 정렬은 리스트가 이미 정렬되어 있어도 최솟값을 찾기 위해 계속 비교한다.  
따라서 비교 횟수 기준으로는 최선, 평균, 최악의 경우가 모두 `O(n²)`이다.

| 경우 | 시간 복잡도 |
|---|---|
| 최선 | `O(n²)` |
| 평균 | `O(n²)` |
| 최악 | `O(n²)` |

## 공간 복잡도

일반적인 선택 정렬은 리스트 안에서 직접 swap을 하므로 추가 리스트가 필요하지 않다.

```text
공간 복잡도: O(1)
```

하지만 `result = []`를 만들어 정렬 결과를 저장하는 쉬운 방식은 새 리스트를 사용하므로 추가 공간이 필요하다.

```text
새 리스트를 사용하는 방식: O(n)
제자리에서 정렬하는 방식: O(1)
```

## 선택 정렬과 버블 정렬 비교

선택 정렬과 버블 정렬은 모두 기본적인 정렬 알고리즘이며 시간 복잡도는 `O(n²)`이다.

| 구분 | 선택 정렬 | 버블 정렬 |
|---|---|---|
| 기본 방식 | 남은 값 중 최솟값을 선택 | 이웃한 값을 계속 비교하고 교환 |
| 비교 횟수 | 많음 | 많음 |
| 교환 횟수 | 비교적 적음 | 많을 수 있음 |
| 구현 난이도 | 쉬움 | 쉬움 |
| 시간 복잡도 | `O(n²)` | `O(n²)` |

선택 정렬은 매 단계에서 최솟값을 한 번만 현재 위치로 옮기므로, 버블 정렬보다 교환 횟수가 적을 수 있다.

## 안정 정렬 여부

일반적인 선택 정렬은 보통 **안정 정렬이 아니다**.

안정 정렬은 같은 값을 가진 데이터들의 기존 순서가 유지되는 정렬을 말한다.

예를 들어 다음과 같은 데이터가 있다고 하자.

```text
[(2, 'A'), (2, 'B'), (1, 'C')]
```

값 `2`를 가진 `A`와 `B`의 순서가 정렬 후에도 그대로 유지되면 안정 정렬이다.  
하지만 선택 정렬은 swap 과정에서 같은 값들의 순서가 바뀔 수 있다.

일반적인 숫자 정렬만 할 때는 크게 문제가 되지 않지만, 점수와 이름처럼 여러 정보를 함께 정렬할 때는 안정성도 생각해야 한다.

## 실행 시간 측정 예제

정렬 알고리즘의 속도를 비교하려면 `time.perf_counter()`를 사용할 수 있다.

```python
import random
import time


def selection_sort(a):
    n = len(a)

    for i in range(n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if a[j] < a[min_idx]:
                min_idx = j
        a[i], a[min_idx] = a[min_idx], a[i]


data = [random.randint(1, 10000) for _ in range(1000)]

start = time.perf_counter()
selection_sort(data)
end = time.perf_counter()

print("선택 정렬 실행 시간:", end - start)
```

데이터 개수가 커질수록 `O(n²)` 알고리즘은 실행 시간이 빠르게 증가한다.

## 파이썬의 기본 정렬과 비교

파이썬에서는 실제 프로그램을 만들 때 보통 직접 선택 정렬을 사용하지 않고 `sorted()` 또는 `list.sort()`를 사용한다.

```python
data = [2, 4, 5, 1, 3]

print(sorted(data))
print(data)
```

`sorted()`는 정렬된 새 리스트를 반환하고 원본 리스트는 유지한다.

```python
data = [2, 4, 5, 1, 3]

data.sort()
print(data)
```

`list.sort()`는 원본 리스트를 직접 정렬한다.

선택 정렬은 실무에서 쓰기보다는 **정렬 알고리즘의 원리, 최솟값 탐색, swap, 시간 복잡도 분석을 이해하기 위한 학습용 알고리즘**으로 보는 것이 좋다.

## 코드에서 주의할 점

- `min_idx`는 바깥쪽 반복문이 한 번 돌 때마다 다시 `i`로 초기화해야 한다.
- `for i in range(n - 1)`까지만 반복해도 마지막 값은 자동으로 정렬된다.
- 쉬운 방식의 선택 정렬에서 `pop()`을 사용하면 원본 리스트가 비게 된다.
- 원본 리스트를 유지하고 싶다면 `a[:]`처럼 복사본을 사용한다.
- 일반적인 선택 정렬은 새 리스트를 만들지 않고 원본 리스트 내부에서 swap한다.
- 선택 정렬은 구현은 쉽지만 시간 복잡도가 `O(n²)`이라 큰 데이터에는 비효율적이다.
- 파이썬에서 실제 정렬이 필요할 때는 보통 `sorted()`나 `list.sort()`를 사용한다.

## 오늘의 정리

선택 정렬은 남은 데이터 중에서 가장 작은 값을 선택하여 앞쪽부터 정렬하는 알고리즘이다.

핵심 흐름은 다음과 같다.

```text
최솟값 위치 찾기 → 현재 위치와 swap → 다음 위치로 이동
```

선택 정렬은 구조가 단순해서 정렬 알고리즘을 처음 배울 때 이해하기 좋다.  
하지만 매번 남은 구간 전체를 비교해야 하므로 시간 복잡도는 `O(n²)`이다.

따라서 선택 정렬은 실제 성능보다는 **정렬 과정, swap, 반복문, 시간 복잡도 분석을 연습하기 위한 알고리즘**으로 중요하다.
