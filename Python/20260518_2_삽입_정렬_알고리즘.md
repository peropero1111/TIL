# TIL - 삽입 정렬 알고리즘

> 원본 PPT: `-`

## 오늘 배운 내용

오늘 배운 삽입 정렬은 이미 정렬된 구간에 새로운 값을 알맞은 위치로 끼워 넣는 정렬 알고리즘이다.

선택 정렬은 남은 값 중 최솟값을 찾아 앞쪽 위치를 확정하고, 버블 정렬은 이웃한 값을 비교하여 큰 값을 뒤쪽으로 보내는 방식이었다. 삽입 정렬은 이 둘과 다르게 **현재 보고 있는 값을 정렬된 구간 안의 알맞은 위치에 삽입한다**는 점이 핵심이다.

---

## 1. 삽입 정렬이란?

삽입 정렬은 영어로 **Insertion Sort**라고 한다.

삽입 정렬의 기본 생각은 다음과 같다.

```text
왼쪽에는 이미 정렬된 구간이 있다.
오른쪽에서 값을 하나 가져온다.
그 값을 왼쪽 정렬 구간의 알맞은 위치에 끼워 넣는다.
```

예를 들어 학생들을 키 순서대로 줄 세운다고 생각하면 이해하기 쉽다.

처음 한 명은 그냥 줄을 선다. 그다음 학생부터는 이미 줄 서 있는 학생들과 키를 비교해서 자신이 들어갈 위치를 찾는다. 위치를 찾으면 그 사이에 끼워 넣는다. 이 과정을 마지막 학생까지 반복하면 전체가 정렬된다.

---

## 2. 삽입 정렬의 핵심 구조

삽입 정렬에서는 리스트를 두 구간으로 나누어 생각한다.

```text
[ 이미 정렬된 구간 | 아직 정렬되지 않은 구간 ]
```

처음에는 0번 위치의 값 하나만 정렬된 상태라고 본다.

```text
[ 2 | 4, 5, 1, 3 ]
```

그다음부터는 `i` 위치의 값을 `key`로 잡고, 
</br>
</br>
( `key`는 문자열 을 저장하는 변수 이름임 굳이 `key` 로 쓸 필요 없음  )
</br>
</br>
`key`를 왼쪽 정렬 구간 안에 끼워 넣는다.

```text
key = 현재 삽입할 값
j   = key의 왼쪽 값을 확인하기 위한 위치
```

중요한 점은 **값을 조정하는 시작점은 항상 현재 key가 있는 위치 `i`**라는 것이다.

---

## 3. `[2, 4, 5, 1, 3]` 삽입 정렬 과정

아래 표에서 `|` 왼쪽은 현재까지 정렬된 구간이고, `|` 오른쪽은 아직 정렬되지 않은 구간이다.

| 단계 | 현재 `i` | 삽입할 값 `key` | 삽입 전 상태 | 이동되는 값 | 삽입 후 상태 |
|---:|---:|---:|---|---|---|
| 1 | `1` | `4` | `[2 | 4, 5, 1, 3]` | 없음 | `[2, 4 | 5, 1, 3]` |
| 2 | `2` | `5` | `[2, 4 | 5, 1, 3]` | 없음 | `[2, 4, 5 | 1, 3]` |
| 3 | `3` | `1` | `[2, 4, 5 | 1, 3]` | `5 →`, `4 →`, `2 →` | `[1, 2, 4, 5 | 3]` |
| 4 | `4` | `3` | `[1, 2, 4, 5 | 3]` | `5 →`, `4 →` | `[1, 2, 3, 4, 5]` |

3단계를 자세히 보면 다음과 같다.

```text
삽입 전: [2, 4, 5, 1, 3]
key = 1

1보다 큰 5를 오른쪽으로 이동
[2, 4, 5, 5, 3]

1보다 큰 4를 오른쪽으로 이동
[2, 4, 4, 5, 3]

1보다 큰 2를 오른쪽으로 이동
[2, 2, 4, 5, 3]

비어 있는 0번 위치에 key 삽입
[1, 2, 4, 5, 3]
```

즉, 삽입 정렬은 `key`보다 큰 값들을 오른쪽으로 한 칸씩 밀고, 마지막으로 빈자리에 `key`를 넣는다.

## 4. 쉽게 설명한 삽입 정렬

PPT에서는 먼저 새 리스트 `result`를 만들어 정렬하는 방식을 사용했다.

이 방식은 원리를 이해하기 쉽다.

```python
# 리스트 r에서 v가 들어갈 위치를 찾는 함수

def find_ins_idx(r, v):
    for i in range(0, len(r)):
        if v < r[i]:
            return i
    return len(r)


def ins_sort(a):
    result = []

    while a:
        value = a.pop(0)
        ins_idx = find_ins_idx(result, value)
        result.insert(ins_idx, value)

    return result


d = [2, 4, 5, 1, 3]
print(ins_sort(d))
```

실행 결과는 다음과 같다.

```text
[1, 2, 3, 4, 5]
```

이 코드의 흐름은 다음과 같다.

```text
1. 기존 리스트에서 맨 앞 값을 하나 꺼낸다.
2. result 안에서 그 값이 들어갈 위치를 찾는다.
3. 찾은 위치에 값을 삽입한다.
4. 기존 리스트가 빌 때까지 반복한다.
```

다만 이 방식은 `pop(0)`과 `insert()` 때문에 실제 효율은 좋지 않다. `pop(0)`은 맨 앞 값을 꺼낸 뒤 나머지 값을 앞으로 당겨야 하고, `insert()`도 중간에 값을 넣으면서 뒤쪽 값을 밀어야 하기 때문이다.

따라서 이 코드는 **정렬 원리를 이해하기 위한 코드**로 보는 것이 좋다.

## 5. 일반적인 삽입 정렬 코드

일반적인 삽입 정렬은 입력 리스트 안에서 직접 값을 옮기며 정렬한다.

```python
# 삽입 정렬
# 입력: 리스트 a
# 출력: 없음. 입력 리스트 a 자체가 정렬됨.

def ins_sort(a):
    n = len(a)

    for i in range(1, n):
        key = a[i]
        j = i - 1

        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1

        a[j + 1] = key


d = [2, 4, 5, 1, 3]
ins_sort(d)
print(d)
```

실행 결과는 다음과 같다.

```text
[1, 2, 3, 4, 5]
```

### 코드 해석

```python
for i in range(1, n):
```

0번 위치는 이미 정렬된 구간으로 보고, 1번 위치부터 삽입할 값을 고른다.

```python
key = a[i]
j = i - 1
```

`key`는 현재 삽입할 값이고, `j`는 `key`의 왼쪽 값을 확인하기 위한 인덱스이다.

```python
while j >= 0 and a[j] > key:
    a[j + 1] = a[j]
    j -= 1
```

왼쪽 값이 `key`보다 크면 오른쪽으로 한 칸 이동시킨다.

```python
a[j + 1] = key
```

더 이상 이동할 값이 없으면 빈 위치에 `key`를 넣는다.

## 6. 삽입 정렬에서 `>`를 사용하는 이유

삽입 정렬의 조건문은 보통 다음처럼 작성한다.

```python
while j >= 0 and a[j] > key:
```

여기서 `>`를 사용하면 같은 값의 순서가 유지된다.

예를 들어 같은 점수 80점이 두 개 있을 때, 먼저 있던 80점이 뒤에 있던 80점보다 앞에 남는다. 이런 성질을 **안정 정렬(stable sort)**이라고 한다.

만약 `>=`를 사용하면 같은 값도 이동될 수 있어서 기존 순서가 바뀔 수 있다.

```python
# 같은 값의 기존 순서를 유지하려면 > 사용
while j >= 0 and a[j] > key:
    a[j + 1] = a[j]
    j -= 1
```

## 7. 내림차순 삽입 정렬

오름차순에서는 `key`보다 큰 값을 오른쪽으로 밀었다.

내림차순에서는 반대로 `key`보다 작은 값을 오른쪽으로 밀면 된다.

```python
def ins_sort_desc(a):
    n = len(a)

    for i in range(1, n):
        key = a[i]
        j = i - 1

        while j >= 0 and a[j] < key:
            a[j + 1] = a[j]
            j -= 1

        a[j + 1] = key


d = [2, 4, 5, 1, 3]
ins_sort_desc(d)
print(d)
```

실행 결과는 다음과 같다.

```text
[5, 4, 3, 2, 1]
```

## 8. 선택 정렬, 버블 정렬과 비교

삽입 정렬을 이해할 때는 이전에 배운 선택 정렬, 버블 정렬과 비교하면 차이가 더 잘 보인다.

### 8-1. 선택 정렬

선택 정렬은 남은 구간에서 최솟값을 찾아 가장 앞 위치와 바꾼다.

```text
남은 값 중 최솟값을 선택한다.
선택한 최솟값을 현재 위치 i와 바꾼다.
앞에서부터 한 자리씩 확정한다.
```

예를 들어 `[2, 4, 5, 1, 3]`에서 첫 번째 단계는 다음과 같다.

```text
남은 전체 구간: [2, 4, 5, 1, 3]
최솟값: 1
0번 위치의 2와 1을 swap
결과: [1, 4, 5, 2, 3]
```

선택 정렬은 **앞쪽 위치를 하나씩 최종 확정**하는 느낌이 강하다.

### 8-2. 버블 정렬

버블 정렬은 이웃한 두 값을 비교하면서 순서가 잘못되어 있으면 바꾼다.

```text
앞에서부터 이웃한 두 값을 비교한다.
큰 값이 뒤로 가도록 swap한다.
한 번의 pass가 끝나면 가장 큰 값이 맨 뒤에 확정된다.
```

예를 들어 `[2, 4, 5, 1, 3]`에서 첫 번째 pass는 다음과 같이 진행된다.

```text
[2, 4, 5, 1, 3]
2와 4 비교 → 그대로
4와 5 비교 → 그대로
5와 1 비교 → swap → [2, 4, 1, 5, 3]
5와 3 비교 → swap → [2, 4, 1, 3, 5]
```

버블 정렬은 **큰 값이 뒤로 밀려나면서 마지막 위치부터 확정**되는 느낌이 강하다.

### 8-3. 삽입 정렬

삽입 정렬은 현재 값을 왼쪽의 정렬된 구간에 끼워 넣는다.

```text
현재 위치 i의 값을 key로 저장한다.
왼쪽 정렬 구간에서 key보다 큰 값을 오른쪽으로 민다.
빈 위치에 key를 삽입한다.
```

삽입 정렬은 선택 정렬처럼 매번 최솟값을 찾지 않고, 버블 정렬처럼 계속 이웃한 값을 swap하지도 않는다. 대신 **현재 값이 들어갈 위치를 찾아 삽입**한다.

## 9. 세 정렬 알고리즘 비교표

| 구분 | 삽입 정렬 | 선택 정렬 | 버블 정렬 |
|---|---|---|---|
| 핵심 아이디어 | 현재 값을 정렬된 구간에 삽입 | 남은 구간의 최솟값을 선택 | 이웃한 값을 비교하고 swap |
| 정렬 방향 | 왼쪽 정렬 구간을 확장 | 앞쪽 자리부터 확정 | 뒤쪽 자리부터 확정 |
| 한 단계에서 하는 일 | `key`보다 큰 값을 오른쪽으로 이동 | 최솟값 위치를 찾고 현재 위치와 교환 | 인접한 두 값을 비교하여 필요하면 교환 |
| 이미 정렬된 데이터 | 매우 빠름 | 여전히 많이 비교함 | 개선 코드가 있으면 빠름 |
| 평균 시간 복잡도 | `O(n²)` | `O(n²)` | `O(n²)` |
| 최선 시간 복잡도 | `O(n)` | `O(n²)` | 기본형 `O(n²)`, 개선형 `O(n)` |
| 최악 시간 복잡도 | `O(n²)` | `O(n²)` | `O(n²)` |
| 공간 복잡도 | `O(1)` | `O(1)` | `O(1)` |
| 안정 정렬 여부 | 안정 정렬 | 기본 구현은 불안정 가능 | 안정 정렬 |
| swap/이동 특징 | 값을 한 칸씩 이동 | swap 횟수가 적음 | swap 횟수가 많을 수 있음 |
| 어울리는 경우 | 데이터가 작거나 거의 정렬된 경우 | swap 비용을 줄이고 싶은 경우 | 원리 이해용, 간단한 구현 |

## 10. 삽입 정렬이 선택 정렬보다 유리한 경우

삽입 정렬은 데이터가 거의 정렬되어 있을 때 좋다.

예를 들어 다음 리스트는 거의 정렬되어 있다.

```python
a = [1, 2, 3, 4, 6, 5]
```

삽입 정렬은 `6`과 `5` 근처만 조금 조정하면 된다.

하지만 선택 정렬은 매 단계마다 남은 구간에서 최솟값을 찾아야 한다. 이미 정렬되어 있어도 비교 횟수가 크게 줄지 않는다.

```text
삽입 정렬: 이미 정렬된 부분이 많으면 이동이 적다.
선택 정렬: 이미 정렬되어 있어도 최솟값 찾기는 계속 한다.
```

---

## 11. 삽입 정렬이 버블 정렬보다 유리한 경우

버블 정렬은 이웃한 값끼리 계속 swap한다. 그래서 값 하나가 멀리 이동해야 하면 swap이 여러 번 발생할 수 있다.

삽입 정렬은 `key`를 따로 저장해 두고, 필요한 값들을 한 칸씩 밀어낸 뒤 한 번에 넣는다.

```text
버블 정렬: swap을 반복해서 값을 이동시킴
삽입 정렬: key를 저장하고 값들을 이동시킨 뒤 key를 삽입함
```

따라서 일반적으로는 삽입 정렬이 버블 정렬보다 실제 실행에서 더 나은 경우가 많다. 특히 데이터가 작거나 거의 정렬되어 있을 때 삽입 정렬이 유리하다.

## 12. 시간 복잡도

삽입 정렬의 시간 복잡도는 입력 상태에 따라 달라진다.

### 최선의 경우

이미 정렬되어 있는 경우이다.

```python
a = [1, 2, 3, 4, 5]
```

이때는 `a[j] > key` 조건이 거의 바로 거짓이 되므로 이동이 거의 없다.

```text
최선 시간 복잡도: O(n)
```

### 최악의 경우

내림차순으로 되어 있는 리스트를 오름차순으로 정렬하는 경우이다.

```python
a = [5, 4, 3, 2, 1]
```

이때는 매번 왼쪽의 값들을 대부분 오른쪽으로 밀어야 한다.

```text
최악 시간 복잡도: O(n²)
```

### 평균적인 경우

일반적인 무작위 데이터에서는 평균적으로도 중첩 반복이 발생한다.

```text
평균 시간 복잡도: O(n²)
```

## 13. 실행 시간 비교 예제

아래 코드는 삽입 정렬, 선택 정렬, 버블 정렬의 실행 시간을 비교하는 예제이다.

```python
from random import randint
from time import perf_counter


def ins_sort(a):
    n = len(a)
    for i in range(1, n):
        key = a[i]
        j = i - 1
        while j >= 0 and a[j] > key:
            a[j + 1] = a[j]
            j -= 1
        a[j + 1] = key


def sel_sort(a):
    n = len(a)
    for i in range(0, n - 1):
        min_idx = i
        for j in range(i + 1, n):
            if a[j] < a[min_idx]:
                min_idx = j
        a[i], a[min_idx] = a[min_idx], a[i]


def bubble_sort(a):
    n = len(a)
    for i in range(0, n - 1):
        for j in range(0, n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]


origin = [randint(1, 10000) for _ in range(2000)]

for name, func in [
    ("insertion", ins_sort),
    ("selection", sel_sort),
    ("bubble", bubble_sort),
]:
    data = origin.copy()
    start = perf_counter()
    func(data)
    end = perf_counter()
    print(name, end - start)
```

정확한 실행 시간은 컴퓨터 성능과 데이터 상태에 따라 달라진다. 하지만 세 알고리즘 모두 평균적으로 `O(n²)`이기 때문에 입력 크기가 커지면 시간이 빠르게 증가한다.

## 14. 개선된 버블 정렬과의 비교

버블 정렬은 한 번의 pass에서 swap이 한 번도 일어나지 않으면 이미 정렬이 끝난 것으로 볼 수 있다.

```python
def bubble_sort_improved(a):
    n = len(a)

    for i in range(0, n - 1):
        swapped = False

        for j in range(0, n - 1 - i):
            if a[j] > a[j + 1]:
                a[j], a[j + 1] = a[j + 1], a[j]
                swapped = True

        if not swapped:
            break
```

개선된 버블 정렬은 이미 정렬된 데이터에서 빠르게 끝날 수 있다.

하지만 삽입 정렬도 이미 정렬된 데이터에서는 자연스럽게 `O(n)`에 가깝게 동작한다. 그래서 실제로는 작은 데이터나 거의 정렬된 데이터에서 삽입 정렬이 더 자주 활용된다.

## 15. 코드에서 주의할 점

### 1. `pop(0)`은 원본 리스트를 바꾼다

쉽게 설명한 삽입 정렬에서는 다음 코드를 사용한다.

```python
value = a.pop(0)
```

이 코드는 리스트 `a`에서 값을 실제로 제거한다.

원본 리스트를 유지하고 싶다면 복사본을 사용해야 한다.

```python
d = [2, 4, 5, 1, 3]
result = ins_sort(d.copy())
```

### 2. `while` 조건의 순서가 중요하다

```python
while j >= 0 and a[j] > key:
```

먼저 `j >= 0`을 확인하고 나서 `a[j]`를 확인해야 한다.

파이썬에서는 `a[-1]`처럼 음수 인덱스가 가능하기 때문에 조건 순서를 잘못 쓰면 의도와 다른 값이 비교될 수 있다.

### 3. 삽입 위치는 `j + 1`이다

반복문이 끝나면 `j`는 `key`보다 작거나 같은 값의 위치를 가리킨다. 따라서 `key`가 들어갈 위치는 그 다음 칸인 `j + 1`이다.

```python
a[j + 1] = key
```

### 4. 리스트가 커지면 삽입 정렬도 느려진다

삽입 정렬은 작은 데이터나 거의 정렬된 데이터에는 좋지만, 무작위로 섞인 큰 데이터에는 적합하지 않다.

실무에서는 보통 `sorted()`나 `list.sort()`를 사용한다.

```python
a = [2, 4, 5, 1, 3]
print(sorted(a))

# 원본 리스트 자체를 정렬하고 싶다면
a.sort()
print(a)
```

## 오늘의 정리

삽입 정렬은 현재 값을 왼쪽의 정렬된 구간에 알맞게 끼워 넣는 알고리즘이다.

선택 정렬은 남은 값 중 최솟값을 골라 앞쪽 위치를 확정하고, 버블 정렬은 이웃한 값을 비교하며 큰 값을 뒤쪽으로 보낸다.

세 정렬 모두 평균적으로는 `O(n²)`이지만, 삽입 정렬은 이미 정렬된 데이터나 거의 정렬된 데이터에서 특히 효율적이다.

```text
선택 정렬: 남은 구간에서 최솟값을 선택한다.
버블 정렬: 이웃한 값을 비교해서 큰 값을 뒤로 보낸다.
삽입 정렬: 현재 값을 정렬된 구간의 알맞은 위치에 삽입한다.
```
