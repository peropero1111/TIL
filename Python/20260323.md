# TIL - 파이썬 변수와 리스트

> 원본 자료: `- `  
> 학습 주제: 기억장치, 변수, 데이터 타입, 변수명 규칙, 리스트와 인덱스

## 오늘 배운 내용

컴퓨터 프로그램에서 데이터를 저장하기 위해 **기억장치**가 필요하고, 이 데이터를 효율적으로 다루기 위해 **변수**와 **리스트**를 사용한다.  
파이썬에서는 값을 변수에 대입하는 순간 자료형이 결정되며, 여러 개의 데이터를 하나의 이름으로 관리할 때는 리스트를 사용할 수 있다.

---

## 1. 기억장치가 필요한 이유

프로그램은 입력받은 값을 바로 처리하기도 하지만, 대부분은 중간 결과나 입력값을 잠시 저장해야 한다.

예를 들어 계산기 프로그램을 생각하면 다음과 같은 값이 필요하다.

```text
입력 값 1
입력 값 2
계산 결과
```

날씨 프로그램도 마찬가지로 여러 정보를 저장해야 한다.

```text
온도
습도
미세먼지
```

이처럼 프로그램이 실행되는 동안 데이터를 저장하는 공간이 필요하며, 이 공간을 보통 **메모리(memory)** 라고 부른다.

---

## 2. 컴퓨터 프로그램의 구성

컴퓨터 프로그램은 크게 두 가지로 구성된다.

```text
1. 데이터
2. 기능
```

데이터는 프로그램에서 다루는 값이고, 기능은 그 값을 입력받고 처리하고 출력하는 동작이다.

```text
컴퓨터 프로그램
├─ 데이터
│  ├─ 변수
│  └─ 상수
└─ 기능
   ├─ 입력 기능
   ├─ 처리 기능
   └─ 출력 기능
```

예를 들어 월급 계산 프로그램이라면 다음처럼 볼 수 있다.

```text
데이터: 일한 시간, 시급, 월급
기능: 입력받기, 곱셈 계산하기, 결과 출력하기
```

---

## 3. 변수란?

수학에서의 변수는 아직 정해지지 않은 값을 나타내는 문자이다.

```text
x, y, z
```

컴퓨터에서의 변수는 **데이터를 저장할 수 있는 메모리 공간**이다.

쉽게 말하면 변수는 값을 담는 그릇이다.

```python
age = 20
name = "Kim"
height = 175.5
```

위 코드에서 `age`, `name`, `height`는 변수이고, 각각의 변수는 값을 저장한다.

| 변수명 | 저장된 값 | 의미 |
|---|---:|---|
| `age` | `20` | 나이 |
| `name` | `"Kim"` | 이름 |
| `height` | `175.5` | 키 |

변수를 사용하면 값에 이름을 붙일 수 있기 때문에 프로그램을 더 이해하기 쉽게 만들 수 있다.

---

## 4. 파이썬에서 변수 선언

C언어나 Java에서는 변수를 사용하기 전에 자료형을 먼저 적는 경우가 많다.

```c
int age = 20;
float height = 175.5;
```

하지만 파이썬은 변수를 따로 선언하지 않아도 된다.  
값을 대입하는 순간 변수의 자료형이 결정된다.

```python
age = 20          # int
height = 175.5    # float
name = "Kim"      # str
is_student = True # bool
```

자료형은 `type()` 함수로 확인할 수 있다.

```python
print(type(age))
print(type(height))
print(type(name))
print(type(is_student))
```

실행 결과는 다음과 비슷하게 나온다.

```text
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

## 5. 기본 데이터 타입

### 5.1 정수형 `int`

정수형은 소수점이 없는 숫자이다.

```python
count = 10
year = 2026
score = -5
```

파이썬의 `int`는 크기 제한이 거의 없어서 매우 큰 정수도 저장할 수 있다.

```python
big_number = 123456789012345678901234567890
print(big_number)
```

---

### 5.2 실수형 `float`

실수형은 소수점이 있는 숫자이다.

```python
temperature = 23.5
height = 175.8
```

정수와 실수는 사칙 연산에 사용할 수 있다.

```python
a = 10
b = 3

print(a + b)  # 더하기
print(a - b)  # 빼기
print(a * b)  # 곱하기
print(a / b)  # 나누기
```

파이썬에서는 추가로 다음 연산자도 자주 사용한다.

| 연산자 | 의미 | 예시 | 결과 |
|---|---|---|---:|
| `**` | 제곱 | `2 ** 3` | `8` |
| `%` | 나머지 | `10 % 3` | `1` |
| `//` | 몫 | `10 // 3` | `3` |

```python
print(2 ** 3)   # 8
print(10 % 3)   # 1
print(10 // 3)  # 3
```

---

### 5.3 불형 `bool`

불형은 참 또는 거짓만 저장한다.

```python
is_student = True
is_adult = False
```

비교 연산의 결과도 불형이 된다.

```python
age = 20

print(age >= 20)  # True
print(age < 20)   # False
```

조건문에서 자주 사용된다.

```python
if age >= 20:
    print("성인입니다")
else:
    print("미성년자입니다")
```

---

### 5.4 문자열 `str`

문자열은 문자들의 모음이다.

```python
name = "홍길동"
message = 'Python 공부 중'
number_text = "1"
```

문자열은 큰따옴표나 작은따옴표로 감싼다.

```python
text1 = "hello"
text2 = 'hello'
```

문자열 안에 작은따옴표를 넣고 싶다면 큰따옴표로 감싸면 된다.

```python
sentence = "I'm learning Python"
print(sentence)
```

문자열 안에 큰따옴표를 넣고 싶다면 작은따옴표로 감싸면 된다.

```python
sentence = 'He said "hello"'
print(sentence)
```

## 6. 주석문

주석은 프로그램 실행에 영향을 주지 않는 설명이다.  
파이썬에서는 `#` 기호 뒤에 주석을 작성한다.

```python
# 사용자의 나이를 저장한다
age = 20

# 나이를 출력한다
print(age)
```

주석을 사용하면 코드의 의도를 설명할 수 있어 나중에 코드를 다시 볼 때 이해하기 쉽다.

## 7. 변수명 규칙

변수명은 아무렇게나 지을 수 없다. 파이썬 변수명에는 규칙이 있다.

### 7.1 대소문자를 구분한다

```python
myVar = 10
MyVar = 20

print(myVar)  # 10
print(MyVar)  # 20
```

`myVar`와 `MyVar`는 서로 다른 변수이다.

---

### 7.2 문자, 숫자, 언더바를 사용할 수 있다

가능한 변수명 예시:

```python
var2 = 10
_var = 20
var_2 = 30
```

하지만 숫자로 시작할 수는 없다.

```python
# 잘못된 변수명
# 2var = 10
```

---

### 7.3 예약어는 변수명으로 사용할 수 없다

파이썬에서 이미 특별한 의미로 쓰이는 단어는 변수명으로 사용할 수 없다.

예를 들어 다음 단어들은 변수명으로 쓰면 안 된다.

```text
True, False, None, and, or, not,
if, else, elif, for, while,
break, continue, return,
import, try, except, finally, global
```

잘못된 예:

```python
# if = 10      # 오류
# True = 1     # 오류
```

## 8. 좋은 변수명 짓기

변수명은 변수의 역할을 잘 설명하는 이름으로 짓는 것이 좋다.

좋지 않은 예:

```python
a = 40
b = 10000
c = a * b
```

좋은 예:

```python
work_hours = 40
hourly_wage = 10000
salary = work_hours * hourly_wage
```

두 코드는 같은 결과를 만들지만, 두 번째 코드가 훨씬 이해하기 쉽다.

```python
print(salary)
```

## 9. 변수의 사용

변수는 값을 대입하면 사용할 수 있다.

```python
score = 80
print(score)
```

변수에 새 값을 다시 넣으면 기존 값은 사라지고 새 값으로 바뀐다.

```python
score = 80
score = 95

print(score)  # 95
```

변수에는 계산 결과를 저장할 수도 있다.

```python
a = 10
b = 20
result = a + b

print(result)  # 30
```

자기 자신의 값을 이용해서 다시 대입할 수도 있다.

```python
count = 0
count = count + 1
count = count + 1

print(count)  # 2
```

위 코드는 보통 다음처럼 줄여 쓸 수 있다.

```python
count = 0
count += 1
count += 1

print(count)  # 2
```

## 10. 리스트가 필요한 이유

변수 하나에는 보통 하나의 값을 저장한다.

```python
score1 = 90
score2 = 80
score3 = 70
score4 = 60
```

값이 4개 정도라면 이렇게 쓸 수도 있지만, 값이 100개라면 변수를 100개 만들어야 한다.  
이런 경우에는 리스트를 사용하면 훨씬 편하다.

```python
scores = [90, 80, 70, 60]
```

리스트는 여러 값을 하나의 이름으로 관리하는 자료형이다.

---

## 11. 리스트와 인덱스

리스트는 순서가 있는 데이터 모음이다.

```python
song_list = ["라일락", "롤린", "Celebrity", "Coin", "On The Ground"]
```

리스트의 각 항목은 인덱스로 접근한다.  
파이썬의 인덱스는 `1`이 아니라 `0`부터 시작한다.

| 순서 | 노래 제목 | 인덱스 |
|---:|---|---:|
| 1 | 라일락 | 0 |
| 2 | 롤린 | 1 |
| 3 | Celebrity | 2 |
| 4 | Coin | 3 |
| 5 | On The Ground | 4 |

```python
print(song_list[0])  # 라일락
print(song_list[1])  # 롤린
```

헷갈리기 쉬운 점은 다음과 같다.

```text
첫 번째 항목의 인덱스는 0
두 번째 항목의 인덱스는 1
세 번째 항목의 인덱스는 2
```

---

## 12. 리스트 생성과 사용

리스트는 대괄호 `[]`를 사용해 만든다.

```python
numbers = [1, 2, 3, 4]
names = ["Kim", "Lee", "Park"]
days = ["일요일", "월요일", "화요일", "수요일", "목요일", "금요일", "토요일"]
```

리스트 항목은 인덱스로 가져올 수 있다.

```python
print(numbers[0])  # 1
print(names[2])    # Park
print(days[6])     # 토요일
```

리스트의 값을 바꿀 수도 있다.

```python
numbers = [1, 2, 3, 4]
numbers[0] = 10

print(numbers)  # [10, 2, 3, 4]
```

## 13. 리스트를 사용한 합계 계산

리스트를 사용하지 않으면 여러 변수를 따로 만들어야 한다.

```python
a = 10
b = 20
c = 30
d = 40

total = a + b + c + d
print(total)
```

리스트를 사용하면 반복문으로 처리할 수 있다.

```python
numbers = [10, 20, 30, 40]

total = 0
for number in numbers:
    total += number

print(total)  # 100
```

파이썬에는 합계를 구하는 `sum()` 함수도 있다.

```python
numbers = [10, 20, 30, 40]
print(sum(numbers))  # 100
```

## 14. 리스트에서 자주 쓰는 기능

PPT에서는 리스트의 기본 개념과 인덱스를 중심으로 다루지만, 실제 파이썬에서는 다음 기능도 자주 사용한다.

### 14.1 항목 추가하기

```python
fruits = ["사과", "바나나"]
fruits.append("포도")

print(fruits)  # ['사과', '바나나', '포도']
```

### 14.2 항목 개수 확인하기

```python
fruits = ["사과", "바나나", "포도"]
print(len(fruits))  # 3
```

### 14.3 리스트 안에 값이 있는지 확인하기

```python
fruits = ["딸기", "바나나", "포도", "사과"]

if "사과" in fruits:
    print("사과가 있습니다")
```

## 15. 실습 예제

### 예제 1. 시급과 일한 시간으로 월급 계산하기

```python
work_hours = 40
hourly_wage = 10000
salary = work_hours * hourly_wage

print("월급:", salary)
```

출력:

```text
월급: 400000
```

---

### 예제 2. 리스트에서 첫 번째 값과 마지막 값 출력하기

```python
scores = [90, 80, 70, 60]

print(scores[0])
print(scores[3])
```

출력:

```text
90
60
```

`len()`을 사용하면 마지막 인덱스를 직접 외우지 않아도 된다.

```python
scores = [90, 80, 70, 60]

last_index = len(scores) - 1
print(scores[last_index])
```

---

### 예제 3. 리스트의 평균 구하기

```python
scores = [90, 80, 70, 60]

total = sum(scores)
average = total / len(scores)

print("합계:", total)
print("평균:", average)
```

출력:

```text
합계: 300
평균: 75.0
```

## 16. 주의할 점

- 파이썬의 리스트 인덱스는 `0`부터 시작한다.
- 변수명은 숫자로 시작할 수 없다.
- `if`, `for`, `while`, `True`, `False` 같은 예약어는 변수명으로 사용할 수 없다.
- 파이썬은 변수를 미리 선언하지 않아도 되지만, 어떤 변수를 사용할지 미리 계획하면 코드가 더 깔끔해진다.
- 변수에 새 값을 대입하면 이전 값은 덮어써진다.
- 문자열 숫자 `"1"`과 정수 숫자 `1`은 서로 다른 자료형이다.

```python
print("1" + "1")  # 11
print(1 + 1)      # 2
```

## 오늘의 정리

변수는 데이터를 저장하는 메모리 공간이고, 리스트는 여러 데이터를 하나의 이름으로 관리하기 위한 자료형이다.  
파이썬에서는 값을 대입하는 순간 변수의 자료형이 결정되며, 리스트는 `0`부터 시작하는 인덱스를 사용한다.

```text
변수 = 하나의 값을 저장하는 공간
리스트 = 여러 값을 순서대로 저장하는 공간
인덱스 = 리스트 안의 위치 번호, 0부터 시작
```

이번 학습에서 가장 중요한 점은 **데이터를 어떻게 저장하고, 이름을 붙이고, 다시 사용하는가**이다.  
프로그램은 결국 데이터를 입력받고, 변수나 리스트에 저장한 뒤, 필요한 계산을 수행하고 결과를 출력하는 흐름으로 이루어진다.
