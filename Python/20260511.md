# TIL - 버블 정렬 알고리즘
  
> 원본 자료: `-`  
> 학습 주제: 버블 정렬, swap, 시간 복잡도, 함수 구현, 문자 정렬, 시간 비교

## 오늘 배운 내용

오늘은 **버블 정렬(Bubble Sort)** 의 동작 방식, `swap`, 시간 복잡도, 일반 코드, 함수 코드, 문자 정렬, 시간 비교를 정리했다.

버블 정렬은 서로 이웃한 두 값을 비교하면서, 순서가 맞지 않으면 두 값을 교환하는 방식으로 동작한다.  
한 번의 반복이 끝날 때마다 가장 큰 값이 리스트의 뒤쪽으로 이동한다.

## 버블 정렬이란?

버블 정렬은 이웃한 두 값을 비교해서 작은 값을 앞으로, 큰 값을 뒤로 보내는 과정을 반복하는 정렬 알고리즘이다.

```text
[8, 3, 1, 6]
```

위 리스트를 오름차순으로 정렬한다고 하면, 먼저 앞에서부터 이웃한 값을 비교한다.

```text
8과 3 비교 → 8이 더 크므로 교환
[3, 8, 1, 6]

8과 1 비교 → 8이 더 크므로 교환
[3, 1, 8, 6]

8과 6 비교 → 8이 더 크므로 교환
[3, 1, 6, 8]
```

첫 번째 패스가 끝나면 가장 큰 값인 `8`이 맨 뒤로 이동한다.

```text
[3, 1, 6, 8]
```

이제 맨 뒤의 `8`은 이미 정렬된 위치에 있으므로 다시 비교할 필요가 없다.

## 버블 정렬의 수행 과정

예제 리스트를 하나 더 살펴보자.

```python
arr = [5, 1, 4, 2]
```

### 1번째 패스

```text
[5, 1, 4, 2]
5와 1 비교 → 교환
[1, 5, 4, 2]

5와 4 비교 → 교환
[1, 4, 5, 2]

5와 2 비교 → 교환
[1, 4, 2, 5]
```

1번째 패스가 끝나면 가장 큰 값 `5`가 마지막 위치에 고정된다.

### 2번째 패스

```text
[1, 4, 2, 5]
1과 4 비교 → 그대로
[1, 4, 2, 5]

4와 2 비교 → 교환
[1, 2, 4, 5]
```

2번째 패스가 끝나면 `4`가 자신의 위치에 고정된다.

### 3번째 패스

```text
[1, 2, 4, 5]
1과 2 비교 → 그대로
[1, 2, 4, 5]
```

최종 결과는 다음과 같다.

```python
[1, 2, 4, 5]
```

## swap이란?

`swap`은 두 변수의 값을 서로 바꾸는 작업이다.

버블 정렬은 이웃한 두 값을 비교한 뒤, 순서가 맞지 않으면 반드시 `swap`을 해야 한다.

### 1. 임시 변수 사용

다른 언어나 C언어에서는 보통 임시 변수를 사용해서 값을 바꾼다.

```c
int a = 10;
int b = 20;
int temp = 0;

temp = a;
a = b;
b = temp;

printf(a, b);  # 20 10
```

흐름은 다음과 같다.

```text
temp = a  → a 값을 잠시 temp에 저장
a = b     → b 값을 a에 대입
b = temp  → temp에 저장해 둔 원래 a 값을 b에 대입
```

### 2. 파이썬 방식

파이썬에서는 더 간단하게 한 줄로 두 값을 바꿀 수 있다.

```python
a = 10
b = 20

a, b = b, a

print(a, b)  # 20 10
```

버블 정렬에서는 이 방식을 자주 사용한다.

```python
arr[i], arr[i + 1] = arr[i + 1], arr[i]
```

## 버블 정렬 일반 코드

다음은 리스트를 오름차순으로 정렬하는 가장 기본적인 버블 정렬 코드이다.

```python
arr = [5, 1, 4, 2, 8]

n = len(arr)

for pass_num in range(n - 1):
    for i in range(0, n - 1 - pass_num):
        if arr[i] > arr[i + 1]:
            arr[i], arr[i + 1] = arr[i + 1], arr[i]

print(arr)
```

실행 결과는 다음과 같다.

```text
[1, 2, 4, 5, 8]
```

여기서 중요한 부분은 안쪽 반복문의 범위이다.

```python
range(0, n - 1 - pass_num)
```

각 패스가 끝날 때마다 가장 큰 값이 뒤쪽에 고정되므로, 이미 정렬된 마지막 부분은 다시 비교하지 않아도 된다.

## 버블 정렬 함수 만들기

정렬 코드를 함수로 만들면 여러 리스트에 재사용할 수 있다.

```python
def bubble_sort(data):
    arr = data[:]
    n = len(arr)

    for pass_num in range(n - 1):
        for i in range(0, n - 1 - pass_num):
            if arr[i] > arr[i + 1]:
                arr[i], arr[i + 1] = arr[i + 1], arr[i]

    return arr

numbers = [5, 1, 4, 2, 8]
result = bubble_sort(numbers)

print("원본:", numbers)
print("정렬:", result)
```

실행 결과는 다음과 같다.

```text
원본: [5, 1, 4, 2, 8]
정렬: [1, 2, 4, 5, 8]
```

여기서 `arr = data[:]`를 사용한 이유는 원본 리스트를 직접 바꾸지 않기 위해서이다.

만약 원본 리스트 자체를 정렬하고 싶다면 다음처럼 작성할 수도 있다.

```python
def bubble_sort_in_place(arr):
    n = len(arr)

    for pass_num in range(n - 1):
        for i in range(0, n - 1 - pass_num):
            if arr[i] > arr[i + 1]:
                arr[i], arr[i + 1] = arr[i + 1], arr[i]

numbers = [5, 1, 4, 2, 8]
bubble_sort_in_place(numbers)
print(numbers)
```

## 내림차순 버블 정렬

오름차순에서는 앞의 값이 뒤의 값보다 크면 교환한다.

```python
if arr[i] > arr[i + 1]:
```

내림차순에서는 반대로 앞의 값이 뒤의 값보다 작으면 교환하면 된다.

```python
def bubble_sort_desc(data):
    arr = data[:]
    n = len(arr)

    for pass_num in range(n - 1):
        for i in range(0, n - 1 - pass_num):
            if arr[i] < arr[i + 1]:
                arr[i], arr[i + 1] = arr[i + 1], arr[i]

    return arr

print(bubble_sort_desc([5, 1, 4, 2, 8]))
```

실행 결과는 다음과 같다.

```text
[8, 5, 4, 2, 1]
```

## 문자도 정렬할 수 있다

버블 정렬은 숫자뿐만 아니라 문자에도 적용할 수 있다.

```python
def bubble_sort(data):
    arr = data[:]
    n = len(arr)

    for pass_num in range(n - 1):
        for i in range(0, n - 1 - pass_num):
            if arr[i] > arr[i + 1]:
                arr[i], arr[i + 1] = arr[i + 1], arr[i]

    return arr

chars = list("mikudayo")
result = bubble_sort(chars)

print(result)
print("".join(result))

```

실행 결과는 다음과 같다.

```text
['a', 'd', 'i', 'k', 'm', 'o', 'u', 'y']
adikmouy
```

문자는 내부적으로 문자 코드 값을 기준으로 비교된다.  
따라서 대문자와 소문자가 섞여 있으면 사람이 생각하는 사전 순서와 다르게 보일 수 있다.

```python
print("A" < "a")  # True
```

대소문자 구분 없이 정렬하고 싶다면 `lower()`를 활용할 수 있다.

```python
chars = list("Python")
chars.sort(key=str.lower)
print(chars)
```

## 시간 복잡도

버블 정렬은 반복문 안에 반복문이 있는 구조이다.

데이터가 `n`개일 때 비교 횟수는 다음과 같다.

```text
1번째 패스: n - 1번 비교
2번째 패스: n - 2번 비교
3번째 패스: n - 3번 비교
...
n-1번째 패스: 1번 비교
```

따라서 전체 비교 횟수는 다음과 같다.

```text
(n - 1) + (n - 2) + ... + 1
= n(n - 1) / 2
```

예를 들어 데이터가 5개라면 비교 횟수는 다음과 같다.

```text
4 + 3 + 2 + 1 = 10
```

시간 복잡도는 다음과 같이 정리할 수 있다.

| 경우 | 시간 복잡도 | 설명 |
|---|---:|---|
| 최선 | O(n²) | 기본 버블 정렬은 이미 정렬되어 있어도 반복을 계속함 |
| 평균 | O(n²) | 일반적인 경우 |
| 최악 | O(n²) | 역순으로 정렬된 경우 |

버블 정렬은 구현은 쉽지만, 데이터가 많아질수록 매우 느려진다.

## 개선된 버블 정렬

기본 버블 정렬은 리스트가 이미 정렬되어 있어도 끝까지 반복한다.  
이를 개선하려면 한 패스 동안 한 번도 교환이 일어나지 않았을 때 반복을 멈추면 된다.

```python
def bubble_sort_optimized(data):
    arr = data[:]
    n = len(arr)

    for pass_num in range(n - 1):
        swapped = False

        for i in range(0, n - 1 - pass_num):
            if arr[i] > arr[i + 1]:
                arr[i], arr[i + 1] = arr[i + 1], arr[i]
                swapped = True

        if not swapped:
            break

    return arr

print(bubble_sort_optimized([1, 2, 3, 4, 5]))
```

이 방식은 이미 정렬된 리스트에서 한 번만 확인하고 종료할 수 있다.

| 경우 | 시간 복잡도 |
|---|---:|
| 이미 정렬된 경우 | O(n) |
| 평균적인 경우 | O(n²) |
| 역순인 경우 | O(n²) |

## 버블 정렬의 특징

### 장점

- 구현이 단순하다.
- 정렬 과정을 눈으로 이해하기 쉽다.
- 인접한 두 값만 비교하므로 알고리즘 학습용으로 좋다.
- 추가 리스트 없이 제자리 정렬이 가능하다.

### 단점

- 비교 횟수가 많다.
- 교환 작업이 많이 발생할 수 있다.
- 데이터가 많아지면 속도가 느리다.
- 실제 프로그램에서는 보통 `sorted()`나 `list.sort()`를 사용하는 것이 더 좋다.

## 안정 정렬 여부

버블 정렬은 보통 **안정 정렬(stable sort)** 로 볼 수 있다.

안정 정렬이란 같은 값을 가진 데이터들의 기존 순서가 유지되는 정렬이다.

예를 들어 다음과 같은 데이터가 있다고 하자.

```python
students = [
    ("A", 90),
    ("B", 80),
    ("C", 90),
]
```

점수 기준으로 정렬할 때 `A`와 `C`는 둘 다 90점이다.  
안정 정렬에서는 두 학생의 상대적 순서가 유지된다.

버블 정렬에서 다음 조건을 사용하면 같은 값은 교환하지 않는다.

```python
if arr[i] > arr[i + 1]:
```

따라서 같은 값의 순서가 유지된다.  
하지만 다음처럼 `>=`를 사용하면 같은 값도 교환될 수 있으므로 안정성이 깨질 수 있다.

```python
if arr[i] >= arr[i + 1]:
```

## 정렬 시간 비교 예제

정렬 알고리즘은 데이터가 커질수록 성능 차이가 크게 나타난다.  
다음 코드는 버블 정렬과 파이썬 기본 정렬의 실행 시간을 비교하는 예제이다.

```python
import random
import time


def bubble_sort(data):
    arr = data[:]
    n = len(arr)

    for pass_num in range(n - 1):
        for i in range(0, n - 1 - pass_num):
            if arr[i] > arr[i + 1]:
                arr[i], arr[i + 1] = arr[i + 1], arr[i]

    return arr


def measure_time(func, data):
    start = time.perf_counter()
    func(data)
    end = time.perf_counter()
    return end - start


for size in [100, 500, 1000]:
    data = [random.randint(1, 10000) for _ in range(size)]

    bubble_time = measure_time(bubble_sort, data)
    sorted_time = measure_time(sorted, data)

    print(f"데이터 {size}개")
    print(f"버블 정렬: {bubble_time:.6f}초")
    print(f"기본 정렬: {sorted_time:.6f}초")
    print()
```

버블 정렬은 원리를 이해하기에는 좋지만, 실제로 많은 데이터를 정렬할 때는 파이썬의 `sorted()`나 리스트의 `.sort()`를 사용하는 것이 더 적합하다.

## 코드에서 주의할 점

### 1. `i + 1` 때문에 반복 범위를 조심해야 한다

버블 정렬은 항상 `arr[i]`와 `arr[i + 1]`을 비교한다.

```python
if arr[i] > arr[i + 1]:
```

따라서 `i`가 마지막 인덱스까지 가면 `arr[i + 1]`에서 오류가 발생한다.  
그래서 안쪽 반복문은 보통 다음처럼 작성한다.

```python
for i in range(0, n - 1 - pass_num):
```

### 2. 원본 리스트를 바꿀지 말지 정해야 한다

```python
arr = data[:]
```

이 코드는 리스트를 복사한다.  
원본을 유지하고 싶다면 복사본을 정렬하고, 원본 자체를 정렬하고 싶다면 복사하지 않아도 된다.

### 3. 이미 정렬된 뒤쪽은 다시 비교하지 않는다

한 패스가 끝날 때마다 가장 큰 값이 뒤로 이동한다.  
따라서 다음과 같이 뒤쪽 범위를 줄여야 한다.

```python
n - 1 - pass_num
```

### 4. 실제 개발에서는 기본 정렬을 사용하는 것이 좋다

버블 정렬은 학습용으로 좋지만 성능은 좋지 않다.  
실제 개발에서는 다음과 같은 기본 정렬을 주로 사용한다.

```python
numbers = [5, 1, 4, 2, 8]

print(sorted(numbers))

numbers.sort()
print(numbers)
```


## 오늘의 정리

버블 정렬은 이웃한 두 값을 비교하고, 순서가 맞지 않으면 교환하는 방식으로 동작한다.

한 번의 패스가 끝날 때마다 가장 큰 값이 뒤쪽에 고정된다.

버블 정렬의 비교 횟수는 다음과 같다.

```text
(n - 1) + (n - 2) + ... + 1 = n(n - 1) / 2
```

따라서 시간 복잡도는 일반적으로 `O(n²)`이다.

버블 정렬은 구현이 쉽고 정렬 과정을 이해하기 좋지만, 데이터가 많을 때는 비효율적이다.  
실제 프로그램에서는 `sorted()`나 `list.sort()`를 사용하는 것이 좋고, 버블 정렬은 정렬 알고리즘의 기본 원리를 이해하기 위한 예제로 생각하면 된다.
