# TIL - 문자열과 직접 구현하는 strlen, strcpy, strcat

> 원본 파일: `20260513.c`  
> 학습 주제: 문자열, 널 문자, 문자 배열, 직접 만든 문자열 함수

## 오늘 배운 내용

C 문자열은 문자 배열이며, 문자열의 끝은 널 문자 `\0`으로 표시된다는 점을 배웠다. 직접 `mystrlen`, `mystrcpy`, `mystrcat`을 구현하면서 문자열 길이 계산, 복사, 이어 붙이기의 원리를 확인했다.

## 핵심 개념

### 1. 문자열은 `\0`에서 끝난다

```c
char ar2[10] = {'8', '\0', '9', '0', '\0'};
```

`printf("%s", ar2)`를 하면 첫 번째 `\0`을 만나는 순간 문자열이 끝난 것으로 판단한다. 따라서 위 배열은 문자열로 출력하면 `8`만 출력된다.

반대로 `&ar2[2]`를 문자열로 출력하면 세 번째 요소부터 읽기 시작하므로 `90`이 출력된다.

### 2. 문자열 길이 구하기

```c
int mystrlen(char* p) {
    int i = 0;
    for (i = 0; p[i] != '\0'; i++) {
    }
    return i;
}
```

문자열 길이는 `\0`을 만나기 전까지의 문자 개수이다. `\0` 자체는 길이에 포함하지 않는다.

### 3. 문자열 복사

```c
void mystrcpy(char* a, char* b) {
    int i;
    for (i = 0; b[i] != '\0'; i++) {
        a[i] = b[i];
    }
    a[i] = '\0';
}
```

문자열 복사에서는 마지막에 반드시 `\0`을 넣어야 한다. 그렇지 않으면 복사된 배열이 문자열의 끝을 알 수 없다.

### 4. 문자열 이어 붙이기

```c
char* mystrcat(char* p, char* q) {
    int i, j;

    for (i = 0; p[i] != '\0'; i++);

    for (j = 0; q[j] != '\0'; j++) {
        p[i + j] = q[j];
    }

    p[i + j] = '\0';
    return p;
}
```

먼저 첫 번째 문자열의 끝을 찾고, 그 위치부터 두 번째 문자열을 복사한다.

## 입력 받을 때 주의할 점

```c
scanf("%[^\n]s", ar1);
```

`%[^\n]`은 줄바꿈 전까지 입력받는 형식이다. 하지만 뒤에 붙은 `s`는 일반 문자처럼 해석될 수 있으므로, 더 안전하게는 다음처럼 쓰는 것이 좋다.

```c
scanf("%9[^\n]", ar1);
```

`ar1`의 크기가 10이라면 마지막 `\0`을 위해 최대 9글자까지만 입력받는 것이 안전하다.

## 코드에서 주의할 점

- `char a1 = 8;`은 숫자 8을 저장하는 것이고, `char a = '8';`은 문자 `'8'`을 저장하는 것이다.
- `mystrcat(ar1, ar2)`를 호출할 때 `ar1` 배열이 충분히 크지 않으면 버퍼 오버플로우가 발생할 수 있다.
- 영문자 판별은 `('A' <= c && c <= 'Z') || ('a' <= c && c <= 'z')`처럼 대문자와 소문자를 나누어 확인하는 것이 안전하다.

## 오늘의 정리

C 문자열은 결국 `\0`으로 끝나는 문자 배열이다. 문자열 함수를 직접 만들어 보면 `strlen`, `strcpy`, `strcat`이 모두 “어디까지 읽을 것인가”와 “마지막에 `\0`을 넣는가”가 핵심임을 알 수 있다.
