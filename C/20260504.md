# TIL - 전역변수, 지역변수, static 변수, 재귀함수

> 원본 파일: `20260504.c`  
> 학습 주제: 변수 범위, 생명주기, static, 재귀

## 오늘 배운 내용

변수가 선언된 위치에 따라 접근 범위와 생명주기가 달라지는 것을 배웠다. 전역변수, 지역변수, `static` 지역변수의 차이를 확인하고, 재귀함수로 1부터 `n`까지의 합을 구했다.

## 핵심 개념

### 1. 전역변수

```c
int g_variable = 123456;
```

함수 밖에 선언된 변수는 전역변수이다. 여러 함수에서 접근할 수 있으며, 프로그램이 끝날 때까지 유지된다.

### 2. 지역변수

```c
int func1(int a, double b) {
    int r;
    r = a + b;
    return r;
}
```

함수 안 ( main 도 포함 ) 에서 선언된 변수와 매개변수는 지역변수이다. 함수가 호출될 때 생성되고, 함수가 끝나면 사라진다.

### 3. 같은 이름이면 지역변수가 우선된다

```c
int k = 0;

if (k == 0) {
    int k = 99;
    printf("%d\n", k); // 99
}

printf("%d\n", k); // 0
```

안쪽 블록에서 같은 이름의 변수를 다시 선언하면, 그 블록 안에서는 안쪽 변수가 우선된다. 이를 변수 가림 또는 섀도잉이라고 볼 수 있다.

### 4. `static` 지역변수

```c
static int st_v = 0;
st_v += 1;
```

`static` 지역변수는 함수 안에서 선언되지만 함수가 끝나도 값이 사라지지 않는다. 초기화는 한 번만 이루어지고, 다음 호출 때 이전 값을 유지한다.

반면 일반 지역변수는 함수가 호출될 때마다 새로 만들어진다.

```c
int local = 0;
local += 1; // 매번 1이 됨
```

## 재귀함수

```c
int sum(int n) {
    if (n == 1) {
        return 1;
    } else {
        return n + sum(n - 1);
    }
}
```

재귀함수는 자기 자신을 다시 호출하는 함수이다. 반드시 멈추는 조건이 있어야 한다. 여기서는 `n == 1`이 종료 조건이다.

```text
sum(5) = 5 + 4 + 3 + 2 + 1
```

## 코드에서 주의할 점

- 전역변수는 어디서든 바뀔 수 있으므로 값 추적이 어려워질 수 있다.
- 함수 매개변수는 기본적으로 값이 복사되어 전달된다. 함수 안에서 `a = 999;`를 해도 호출한 쪽의 변수 자체가 바뀌지는 않는다.
- `int r = a + b;`처럼 `double`이 포함된 계산 결과를 `int`에 넣으면 소수점 아래가 버려진다.
- 재귀함수는 종료 조건이 없으면 무한 호출될 수 있다.

## 오늘의 정리

변수는 “어디에 선언되었는가”에 따라 사용할 수 있는 범위와 유지 시간이 달라진다. 일반 지역변수는 매번 새로 만들어지고, `static` 지역변수는 함수 안에 있어도 값을 유지한다. 재귀함수는 종료 조건을 명확히 두는 것이 가장 중요하다.
