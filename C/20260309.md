# TIL - C 프로그램 기본 구조와 중괄호 블록

> 원본 파일: `20260309.c`  
> 학습 주제: `main()`, `printf()`, 중괄호 블록, 들여쓰기

## 오늘 배운 내용

C 프로그램은 보통 `main()` 함수에서 실행을 시작한다. `#include <stdio.h>`는 `printf()` 같은 표준 입출력 함수를 사용하기 위해 포함한다.

이번 파일에서는 `printf()`를 여러 번 사용하면서 문자열 출력, 줄바꿈 문자 `\n`, 그리고 중괄호 `{}`로 만든 블록 구조를 연습했다.

## 핵심 개념

### 1. `main()`은 프로그램의 시작점이다

```c
int main() {
    printf("Hello World!\n");
    return 0;
}
```

`return 0;`은 프로그램이 정상적으로 끝났다는 의미로 자주 사용한다.

### 2. 주석은 실행되지 않는다

`//` 뒤에 작성한 내용은 설명용 메모이며 컴파일되는 코드가 아니다. 코드의 의도를 남기거나, 아직 완성하지 않은 부분을 표시할 때 사용할 수 있다.

### 3. 중괄호 `{}`는 블록을 만든다

`main()` 안에서도 다시 `{}`를 열 수 있다. 중괄호 안쪽의 코드는 바깥 코드보다 한 단계 더 안쪽 블록에 속한다.

```c
{
    printf("inside block\n");
}
```

들여쓰기는 컴파일러가 실행 순서를 정하는 기준은 아니지만, 사람이 코드를 읽기 쉽게 만들어 준다. 블록이 깊어질수록 탭 또는 공백을 한 단계씩 추가하면 구조를 파악하기 쉽다.

## 코드에서 확인한 점

`printf("A")`, `printf("B")`, `printf("c")`처럼 줄바꿈 없이 출력하면 결과가 이어 붙어서 나온다.

```c
printf("A");
printf("B");
printf("c");
```

위 코드는 화면에 `ABc`처럼 이어서 출력된다. 줄을 바꾸고 싶으면 문자열 안에 `\n`을 넣어야 한다.

## 주의할 점

- `{}`가 많아질수록 들여쓰기를 맞추지 않으면 코드 흐름을 읽기 어렵다.
- `printf()` 문장 끝에는 세미콜론 `;`을 붙여야 한다.
- 줄바꿈이 필요한 출력에는 `\n`을 넣어야 한다.

## 오늘의 정리

C의 가장 기본 구조는 `include`, `main`, `{}` 블록, `printf`, `return`으로 이루어진다. 코드 자체는 짧지만, 들여쓰기와 블록 구조를 습관화하는 것이 이후 조건문, 반복문, 함수 학습의 기초가 된다.
