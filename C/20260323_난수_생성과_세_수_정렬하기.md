# TIL - 난수 생성과 세 수 정렬하기

> 원본 파일: `20260323.c`  
> 학습 주제: 난수, 최솟값/최댓값, 조건문 정렬

## 오늘 배운 내용

`rand()`로 난수를 만들고, 세 개의 정수 중 가장 작은 값, 중간값, 큰 값을 구해 정렬하는 흐름을 연습했다. 이후 새 값 `k`를 기존 정렬 결과에 끼워 넣는 조건문도 작성했다.

## 핵심 개념

### 1. 난수 생성

```c
srand(time(NULL));

x = rand() % 100;
y = rand() % 100;
z = rand() % 100;
```

`rand() % 100`은 `0`부터 `99`까지의 정수를 만든다. 실행할 때마다 다른 값을 얻고 싶다면 `srand(time(NULL))`로 난수 시드를 설정한다.

`time()`을 사용하려면 다음 헤더가 필요하다.

```c
#include <time.h>
```


### 2. `rand() % 100`의 모듈러 편향

`rand() % 100`은 간단하게 `0`부터 `99`까지의 수를 만들 수 있지만, 모든 숫자가 완전히 같은 확률로 나오지 않을 수 있다. 이유는 `rand()`가 만들 수 있는 값의 개수, 즉 `RAND_MAX + 1`이 100으로 딱 나누어떨어지지 않을 수 있기 때문이다.

예를 들어 `RAND_MAX`가 `32767`이라면 `rand()`는 `0`부터 `32767`까지 총 `32768`개의 값을 만들 수 있다.

```text
32768 = 100 * 327 + 68
```

이때 `rand() % 100`을 사용하면 `0`부터 `67`까지는 한 번씩 더 나올 수 있고, `68`부터 `99`까지는 상대적으로 덜 나올 수 있다. 이런 차이를 **모듈러 편향(modulo bias)** 이라고 한다.

### 3. 모듈러 편향을 줄이는 방법: 거절 샘플링

해결 방법은 `100`으로 나누어떨어지는 구간 안의 난수만 사용하고, 남는 구간의 값은 버리고 다시 뽑는 것이다.

```c
#include <stdlib.h>
#include <time.h>

int rand_range(int n)
{
    unsigned long r;
    unsigned long range = (unsigned long)RAND_MAX + 1UL;
    unsigned long limit;

    if (n <= 0 || (unsigned long)n > range) {
        return -1;
    }

    limit = range - (range % (unsigned long)n);

    do {
        r = (unsigned long)rand();
    } while (r >= limit);

    return (int)(r % (unsigned long)n);
}
```

위 함수를 사용하고 `rand() % 100` 대신 다음처럼 작성한 

```c
srand(time(NULL));

x = rand_range(100);
y = rand_range(100);
z = rand_range(100);
```

이 방식은 남는 난수 구간을 버리기 때문에 `0`부터 `99`까지의 값이 더 균등하게 나온다.

### 4. 최솟값 구하기

```c
smallest = x;

if (smallest > y) smallest = y;
if (smallest > z) smallest = z;
```

처음 값을 기준으로 잡은 뒤, 다른 값과 비교하면서 더 작은 값이 나오면 갱신한다.

### 5. 최댓값과 중간값 구하기

```c
largest = x;

if (largest < y) largest = y;
if (largest < z) largest = z;

mid = x + y + z - smallest - largest;
```

최솟값과 최댓값을 모두 구하면 중간값을 계산하기 쉬워진다.

## 새 값 끼워 넣기

이미 `smallest <= mid <= largest` 순서가 만들어졌다면, 새 값 `k`는 조건문으로 위치를 정할 수 있다.

```c
if (k <= smallest) {
    printf("%d %d %d %d\n", k, smallest, mid, largest);
} else if (k <= mid) {
    printf("%d %d %d %d\n", smallest, k, mid, largest);
} else if (k <= largest) {
    printf("%d %d %d %d\n", smallest, mid, k, largest);
} else {
    printf("%d %d %d %d\n", smallest, mid, largest, k);
}
```

## 코드에서 주의할 점

- `largest`가 선언만 되고 초기화되지 않은 상태에서 비교에 사용되면 예측할 수 없는 결과가 나온다.
- `time(NULL)`을 쓰려면 `#include <time.h>`가 필요하다.
- `rand() % 100`은 간단하지만 모듈러 편향이 생길 수 있으므로, 더 균등한 난수가 필요하면 `rand_range(100)`처럼 거절 샘플링을 사용한다.

## 오늘의 정리

정렬 문제는 “기준값을 정하고 비교해서 갱신하기”가 핵심이다. 최솟값과 최댓값을 먼저 구하면 중간값과 추가 값 삽입 문제도 훨씬 단순해진다.
