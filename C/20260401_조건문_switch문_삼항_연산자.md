# TIL - 조건문, switch문, 삼항 연산자

> 원본 파일: `20260401.c`  
> 학습 주제: `if-else`, `switch`, `?:`, 월별 일수 계산

## 오늘 배운 내용

정수 입력을 받아 홀수와 짝수를 구분하는 `if-else`, `switch`, 삼항 연산자를 연습했다. 또한 월을 입력받아 해당 월의 일수를 구하는 코드를 작성했다.

## 핵심 개념

### 1. `if-else`로 조건 분기하기

```c
if (n % 2 == 1) {
    printf("홀수\n");
} else {
    printf("짝수\n");
}
```

조건식이 참이면 `if` 블록이 실행되고, 거짓이면 `else` 블록이 실행된다.

### 2. `switch`문으로 값에 따라 분기하기

```c
switch (n % 2) {
    case 0:
        printf("짝수\n");
        break;
    case 1:
        printf("홀수\n");
        break;
    default:
        printf("default here\n");
        break;
}
```

`break`를 쓰지 않으면 다음 `case`까지 이어서 실행될 수 있으므로 주의해야 한다.

### 3. 삼항 연산자

삼항 연산자의 기본 형태는 다음과 같다.

```c
변수 = 조건식 ? 참일_때_값 : 거짓일_때_값;
```

예시는 다음과 같다.

```c
int x;
x = (n % 2 == 0) ? 500 : -500;
```

## 월별 일수 구하기

월을 입력받아 일수를 구하는 로직은 다음처럼 작성할 수 있다.

```c
if (month == 2) {
    days = 28;
} else if (month == 4 || month == 6 || month == 9 || month == 11) {
    days = 30;
} else {
    days = 31;
}
```

삼항 연산자로 줄이면 다음과 같다.

```c
days = (month == 2) ? 28 :
       (month == 4 || month == 6 || month == 9 || month == 11) ? 30 : 31;
```

## 코드에서 주의할 점

기존 코드에는 삼항 연산자의 대입과 구분자가 빠진 형태가 있었다.

```c
// 잘못된 형태
days month==2 ? 28 : days;
```

다음처럼 `=`을 사용해 결과를 변수에 대입해야 한다.

```c
days = (month == 2) ? 28 : days;
```

월별 일수처럼 여러 경우를 나눌 때는 `switch`문이 더 읽기 쉬울 수 있다.

```c
switch (month) {
    case 2:
        days = 28;
        break;
    case 4:
    case 6:
    case 9:
    case 11:
        days = 30;
        break;
    default:
        days = 31;
        break;
}
```

## 오늘의 정리

조건 분기는 `if-else`, `switch`, 삼항 연산자로 작성할 수 있다. 삼항 연산자는 짧게 표현할 수 있지만, 조건이 많아지면 가독성이 떨어질 수 있으므로 상황에 맞게 선택해야 한다.
