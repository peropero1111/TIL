# TIL - printf 서식 지정자와 자료형 출력

> 원본 파일: `20260316.c`  
> 학습 주제: 정수/실수/문자 출력, `sizeof`, 형변환

## 오늘 배운 내용

`printf()`에서 자료형에 맞는 서식 지정자를 사용하는 방법을 연습했다. 정수, 실수, 문자, 진법 출력, `sizeof` 결과 출력, 문자와 문자열의 차이를 확인했다.

## 핵심 개념

### 1. 정수 출력 서식

```c
int i = 78;
printf("%d %i %x %X %o\n", i, i, i, i, i);
```

- `%d`, `%i`: 10진수 정수 출력
- `%x`: 16진수 소문자 출력
- `%X`: 16진수 대문자 출력
- `%o`: 8진수 출력

### 2. `sizeof`는 자료형 또는 변수의 크기를 알려준다

```c
printf("%zu bytes\n", sizeof(i));
```

`sizeof`의 결과 타입은 `size_t`이므로, 표준적으로는 `%zu`를 사용하는 것이 좋다.

### 3. 실수 출력과 자릿수 지정

```c
double d = 9.876543;
printf("%f %.1f %.2f %.4f\n", d, d, d, d);
```

`%.1f`, `%.2f`처럼 쓰면 소수점 아래 출력 자릿수를 지정할 수 있다. 출력할 때는 지정한 자릿수에 맞게 반올림되어 보인다.

### 4. 문자와 문자열은 다르다

```c
char c = 'A';
// char c = "A"; // 잘못된 코드
```

- `'A'`는 문자 하나이다.
- `"A"`는 `'A'`와 문자열 끝을 뜻하는 `\0`이 들어간 문자열이다.

문자는 내부적으로 정수 코드값을 가지므로 다음과 같은 출력도 가능하다.

```c
printf("char %c %d\n", c, c);
```

## 코드에서 확인한 점

`double` 값을 `int`에 대입하면 소수점 아래가 버려진다.

```c
double d = 9.876543;
int i = d;   // i는 9가 됨
```

이는 반올림이 아니라 형변환에 따른 절삭이다.

## 주의할 점

- `printf("%d", d);`처럼 자료형과 서식 지정자가 맞지 않으면 경고가 발생하거나 잘못된 값이 출력될 수 있다.
- `sizeof` 출력에는 `%d`보다 `%zu`가 더 적절하다.
- 문자 하나는 작은따옴표, 문자열은 큰따옴표를 사용한다.

## 오늘의 정리

`printf()`는 출력하려는 값의 자료형과 서식 지정자가 정확히 맞아야 한다. 정수, 실수, 문자, 문자열은 메모리에 저장되는 방식과 출력 방식이 다르기 때문에, 서식 지정자를 습관적으로 확인하는 것이 중요하다.
