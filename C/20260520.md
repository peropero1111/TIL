# TIL - 구조체와 함수 만들기

> 원본 파일: `20260520.c`  
> 학습 주제: 구조체, 구조체 포인터, 함수 정의와 호출, `typedef`, `union`, `enum`

## 오늘 배운 내용

C언어에서는 여러 값을 하나로 묶어서 관리할 때 `struct`를 사용할 수 있다.  
또한 반복해서 사용해야 하는 기능은 함수로 따로 만들어 두면 코드가 더 짧고 읽기 쉬워진다.

이번 코드에서는 `struct point`, `struct triangle`, `struct grade`를 만들고, 구조체 값을 함수에 전달하거나 구조체 포인터를 이용해 함수 안에서 값을 수정하는 방식을 연습했다.

## 1. 구조체란?

구조체는 여러 자료형의 변수를 하나의 새로운 자료형처럼 묶어 주는 문법이다.

```c
struct point
{
    int x, y;
    char c, d, e;
    double f[8];
};
```

위 코드는 `point`라는 구조체를 정의한 것이다.

```text
struct point
├── int x
├── int y
├── char c
├── char d
├── char e
└── double f[8]
```

즉, `struct point`는 좌표값 `x`, `y`와 문자값, 그리고 `double` 배열을 함께 저장할 수 있는 새로운 자료형이다.

구조체 변수를 만들 때는 다음처럼 쓴다.

```c
struct point pt1;
```

이후 멤버에 접근할 때는 `.` 연산자를 사용한다.

```c
pt1.x = 8;
pt1.y = 99;
pt1.c = 'K';
```

## 2. 구조체 안에 구조체 넣기

구조체 멤버로 다른 구조체를 사용할 수도 있다.

```c
struct triangle
{
    struct point a, b, c;
};
```

이 구조체는 삼각형의 세 점을 저장하는 구조라고 볼 수 있다.

```c
struct triangle r;

r.a.x = 3;
r.b.y = 7;
r.c.c = 'K';
```

여기서 `r.a.x`는 다음 순서로 접근한다.

```text
r      → triangle 구조체 변수
r.a    → triangle 안의 point a
r.a.x  → point a 안의 x
```

## 3. 구조체 포인터와 `->` 연산자

구조체도 포인터로 다룰 수 있다.

```c
struct point pt1;
struct point* ptr;

ptr = &pt1;
```

포인터가 구조체를 가리킬 때 멤버에 접근하는 방법은 두 가지다.

```c
(*ptr).x = 10;
ptr->y = 20;
```

두 문법은 같은 의미다.

```text
(*ptr).x  ==  ptr->x
```

하지만 `ptr->x`가 더 간단해서 구조체 포인터에서는 보통 `->`를 많이 사용한다.

## 4. 함수를 만드는 법

함수는 특정 기능을 하는 코드를 하나로 묶은 것이다.  
C언어에서 함수는 보통 다음 형식으로 만든다.

```c
반환형 함수이름(매개변수 목록)
{
    실행할 코드
    return 반환값;
}
```

예를 들어 두 정수를 더하는 함수는 이렇게 만들 수 있다.

```c
int add(int a, int b)
{
    int result;
    result = a + b;
    return result;
}
```

이 함수의 구성은 다음과 같다.

```text
int          → 반환형, 함수가 int 값을 돌려준다는 뜻
add          → 함수 이름
int a, int b → 매개변수, 함수가 입력받는 값
return result → 계산 결과를 함수 밖으로 돌려줌
```

사용할 때는 함수 이름을 호출한다.

```c
int x;
x = add(3, 5);
printf("%d\n", x);   // 8
```

## 5. 함수를 만들 때 생각할 순서

함수를 만들 때는 아래 순서로 생각하면 쉽다.

```text
1. 이 함수가 무슨 일을 할지 정한다.
2. 함수에 필요한 입력값이 있는지 정한다.
3. 함수가 결과값을 return 해야 하는지 정한다.
4. 원본 변수를 수정해야 한다면 포인터를 사용할지 정한다.
5. 함수 이름을 기능에 맞게 짓는다.
```

예를 들어 점의 좌표를 입력받는 함수를 만든다면 다음처럼 생각할 수 있다.

```text
기능: x, y 좌표 입력받기
입력값: 없음
반환값: 입력받은 struct point
함수 이름: scan_point
```

코드는 이렇게 작성할 수 있다.

```c
struct point scan_point(void)
{
    struct point v;

    printf("enter x, y: ");
    scanf("%d %d", &v.x, &v.y);

    return v;
}
```

이 함수는 구조체 변수 `v`에 값을 입력받고, 완성된 구조체를 반환한다.

```c
struct point pt2;
pt2 = scan_point();
```

## 6. 값을 반환하는 함수와 포인터로 수정하는 함수

함수는 값을 `return`할 수도 있고, 포인터를 이용해 원본 값을 직접 수정할 수도 있다.

### 값을 반환하는 함수

```c
struct point scan_point(void)
{
    struct point v;

    scanf("%d %d", &v.x, &v.y);

    return v;
}
```

이 방식은 함수가 새로운 구조체 값을 만들어서 돌려준다.

```c
struct point p;
p = scan_point();
```

### 포인터로 원본을 수정하는 함수

```c
void scan_grade(struct grade* ptr)
{
    printf("Enter math, english, programming grades: ");
    scanf("%d %d %d", &ptr->math, &ptr->english, &ptr->programming);
}
```

이 함수는 반환값이 없기 때문에 `void`를 사용한다.  
대신 `struct grade* ptr`을 통해 구조체의 주소를 받아서 원본 구조체 값을 직접 수정한다.

```c
struct grade kim;
scan_grade(&kim);
```

여기서 `&kim`은 `kim`의 주소이다.  
함수 안에서 `ptr->math`를 수정하면 `kim.math`가 바뀐다.

## 7. 구조체 출력 함수 만들기

구조체 값을 출력하는 함수는 보통 구조체 값을 매개변수로 받으면 된다.

```c
void print_grade(struct grade v)
{
    printf("math: %d\n", v.math);
    printf("english: %d\n", v.english);
    printf("programming: %d\n", v.programming);
    printf("avg: %.2f\n", v.avg);
}
```

이 함수도 출력만 하고 값을 돌려줄 필요가 없으므로 반환형이 `void`이다.

```c
print_grade(kim);
```

## 8. 평균을 계산하는 함수

성적 구조체가 다음과 같다고 하자.

```c
struct grade
{
    int math;
    int english;
    int programming;
    float avg;
};
```

평균을 계산해서 구조체 안의 `avg` 값을 바꾸려면 포인터를 사용하는 것이 좋다.

```c
void update_avg(struct grade* ptr)
{
    ptr->avg = (ptr->math + ptr->english + ptr->programming) / 3.0f;
}
```

`3`으로 나누면 정수 나눗셈이 될 수 있으므로 `3.0f`를 사용해서 실수 결과가 나오게 한다.

## 9. `typedef`로 자료형 이름 줄이기

구조체를 사용할 때 매번 `struct point`라고 쓰는 것이 길게 느껴질 수 있다.

```c
struct point pt1;
```

이때 `typedef`를 사용하면 더 짧은 이름을 만들 수 있다.

```c
typedef struct point point;
```

이후에는 다음처럼 쓸 수 있다.

```c
point mypt;
```

즉, 아래 두 문장은 같은 의미다.

```c
struct point mypt;
point mypt;
```

기본 자료형에도 별명을 붙일 수 있다.

```c
typedef int int32;

int32 i;   // int i; 와 같은 의미
```

구조체를 정의하면서 동시에 별명을 붙일 수도 있다.

```c
typedef struct
{
    float h;
    float w;
} rect;
```

이후에는 바로 `rect`를 자료형처럼 사용할 수 있다.

```c
rect box;
box.h = 10.5f;
box.w = 20.0f;
```

## 10. `union` 이해하기

`union`은 구조체와 비슷하게 여러 멤버를 가질 수 있지만, 모든 멤버가 같은 메모리 공간을 공유한다.

```c
union number
{
    float f;
    int i;
};
```

사용 예시는 다음과 같다.

```c
union number n;

n.f = 33.7f;
n.i = 99;
```

주의할 점은 `n.f`와 `n.i`가 동시에 각각의 값을 독립적으로 저장하는 것이 아니라는 점이다.  
같은 공간을 공유하기 때문에 마지막에 저장한 값이 중요하다.

```text
struct → 멤버들이 각각 자기 공간을 가짐
union  → 멤버들이 같은 공간을 공유함
```

## 11. `enum` 이해하기

`enum`은 정수값에 이름을 붙여서 코드의 의미를 더 쉽게 만드는 문법이다.

```c
enum levels { low = 1, medium, high };
```

위 코드에서 값은 다음과 같다.

```text
low    = 1
medium = 2
high   = 3
```

그래서 다음 코드를 실행하면 보통 `1 2 3`이 출력된다.

```c
printf("%d %d %d\n", low, medium, high);
```

숫자 `1`, `2`, `3`을 직접 쓰는 것보다 `low`, `medium`, `high`라고 쓰면 의미를 이해하기 쉽다.


## 12. 원본 코드에서 주의할 점



### 값을 대입하지 않은 문장은 의미가 없다

```c
ptr->programming;
```

이 코드는 값을 읽기만 하고 아무 일도 하지 않는다.  
입력받은 프로그래밍 점수를 저장하려면 이렇게 써야 한다.

```c
ptr->programming = pr;
```


### `scanf()`와 `printf()`를 구분해야 한다

출력만 할 때는 `printf()`를 사용한다.

```c
printf("sizeof(pt1.x) is %zu\n", sizeof(pt1.x));
```

입력을 받을 때는 `scanf()`를 사용하고, 변수의 주소를 넘긴다.

```c
scanf("%d %d", &pt1.x, &pt1.y);
```

### 구조체 전체 대입은 가능하다

같은 구조체 자료형끼리는 전체 대입이 가능하다.

```c
pt1 = pt2;
```

이렇게 하면 `pt2`의 멤버 값들이 `pt1`에 복사된다.  
단, 구조체 안에 동적 할당된 포인터가 있다면 얕은 복사와 깊은 복사를 구분해서 생각해야 한다.

## 오늘의 정리

구조체는 여러 값을 하나로 묶어 새로운 자료형처럼 사용할 수 있게 해 준다.  
함수는 특정 기능을 하는 코드를 묶어서 재사용할 수 있게 해 준다.

특히 구조체를 함수에서 다룰 때는 두 가지 방식을 구분해야 한다.

```text
구조체 값 전달     → 복사본을 함수에 넘김
구조체 포인터 전달 → 원본 주소를 함수에 넘김
```

원본 구조체 값을 직접 바꾸고 싶다면 `struct grade* ptr`처럼 포인터를 매개변수로 받고, 함수 안에서는 `ptr->math`처럼 `->` 연산자를 사용하면 된다.
