# TIL - C 함수 호출과 scanf 입력 방식

> 학습 주제: 함수 정의, 함수 호출, 매개변수와 인자, `scanf()` 입력, 반환값 사용

## 오늘 배운 내용

이번 내용에서는 C언어에서 **함수를 어떻게 만들고, `main()`에서 어떻게 호출하는지**를 중심으로 정리했다.

특히 함수가 여러 개의 값을 사용할 때 `main()`에서 어떤 방식으로 값을 넘기는지, 그리고 함수 안에서 직접 `scanf()`로 입력받는 경우에는 코드를 어떻게 작성하는지 복습했다.

핵심은 다음과 같다.

- 함수는 필요한 값을 매개변수로 받을 수 있다.
- `main()`에서 함수를 부를 때 괄호 안에 넣는 값이 함수로 전달된다.
- 함수에 여러 값을 넘길 때는 **순서가 중요하다**.
- 함수 안에서 직접 `scanf()`를 사용할 수도 있다.
- 함수가 계산 결과를 돌려주려면 `return`을 사용한다.
- 반환값을 사용하려면 `main()`에서 변수에 저장하면 된다.

## 1. 함수 정의와 함수 호출

함수를 만든다는 것은 특정 기능을 따로 분리해서 이름을 붙이는 것이다.

예를 들어 정수 두 개를 더하는 함수를 만들면 다음과 같다.

```c
int add(int x, int y)
{
    return x + y;
}
```

이 코드는 `add`라는 함수를 정의한 것이다.

```text
int add(int x, int y)
```

이 부분의 의미는 다음과 같다.

```text
int    → 함수가 int 값을 돌려준다.
add    → 함수 이름이다.
int x  → 첫 번째로 받을 정수 값이다.
int y  → 두 번째로 받을 정수 값이다.
```

이렇게 만든 함수는 `main()` 안에서 호출해서 사용할 수 있다.

```c
int main(void)
{
    int result;

    result = add(3, 5);

    printf("%d\n", result);

    return 0;
}
```

여기서 함수 호출 부분은 다음 코드다.

```c
add(3, 5)
```

이 코드는 `add` 함수를 실행하면서 첫 번째 값으로 `3`, 두 번째 값으로 `5`를 넘긴다는 뜻이다.

함수 안에서는 다음과 같이 대응된다고 생각하면 된다.

```text
x = 3
y = 5
```

그래서 함수 안의 계산은 다음처럼 이루어진다.

```text
return x + y;
return 3 + 5;
return 8;
```

그 결과 `8`이 `main()`으로 돌아오고, `result`에 저장된다.

## 2. 매개변수와 인자

함수를 공부할 때 헷갈리기 쉬운 단어가 있다.

```c
int add(int x, int y)
```

여기서 `x`, `y`는 **매개변수**라고 한다.

매개변수는 함수가 값을 받기 위해 준비해 둔 변수다.

반면에 다음 코드에서 `3`, `5`는 **인자**라고 한다.

```c
add(3, 5);
```

인자는 함수를 호출할 때 실제로 넣어 주는 값이다.

정리하면 다음과 같다.

| 구분 | 위치 | 예시 |
|---|---|---|
| 매개변수 | 함수 정의 부분 | `int x`, `int y` |
| 인자 | 함수 호출 부분 | `3`, `5` |

쉽게 말하면 다음과 같다.

```text
매개변수: 함수가 값을 받기 위해 준비한 변수
인자: 함수를 호출할 때 실제로 넣는 값
```

## 3. 여러 값을 함수에 넘기는 방식

함수는 값을 하나만 받을 수도 있고, 여러 개 받을 수도 있다.

예를 들어 정수 두 개를 받아서 합과 곱을 출력하는 함수를 만들 수 있다.

```c
void print_calc(int a, int b)
{
    printf("합: %d\n", a + b);
    printf("곱: %d\n", a * b);
}
```

이 함수는 `int a`, `int b` 두 개의 값을 받는다.

`main()`에서는 다음처럼 호출한다.

```c
int main(void)
{
    print_calc(4, 7);

    return 0;
}
```

호출 부분은 다음 코드다.

```c
print_calc(4, 7);
```

이때 함수 안에서는 다음처럼 값이 들어간다.

```text
a = 4
b = 7
```

따라서 출력 결과는 다음과 같다.

```text
합: 11
곱: 28
```

중요한 점은 **함수 호출 시 넣은 값들이 함수의 매개변수에 순서대로 들어간다**는 것이다.

```c
print_calc(4, 7);
```

위 코드는 다음 의미다.

```text
첫 번째 인자 4 → 첫 번째 매개변수 a
두 번째 인자 7 → 두 번째 매개변수 b
```

## 4. 변수에 저장된 값을 함수에 넘기기

함수 호출할 때 직접 숫자를 넣을 수도 있지만, 변수에 저장된 값을 넣을 수도 있다.

```c
#include <stdio.h>

void print_calc(int a, int b)
{
    printf("합: %d\n", a + b);
    printf("곱: %d\n", a * b);
}

int main(void)
{
    int x = 10;
    int y = 20;

    print_calc(x, y);

    return 0;
}
```

이 코드에서 함수 호출 부분은 다음과 같다.

```c
print_calc(x, y);
```

이때 `x`의 값은 `10`, `y`의 값은 `20`이다.

따라서 함수 안에서는 다음처럼 들어간다고 볼 수 있다.

```text
a = 10 = x
b = 20 =
```

여기서 중요한 점은 `main()`의 변수 이름과 함수의 매개변수 이름이 같을 필요는 없다는 것이다.

```c
int x = 10;
int y = 20;

print_calc(x, y);
```

함수 정의는 다음처럼 되어 있다.

```c
void print_calc(int a, int b)
```

`main()`에서는 `x`, `y`라는 이름을 쓰고, 함수 안에서는 `a`, `b`라는 이름을 쓴다.

이름이 달라도 상관없다.

중요한 것은 **값이 순서대로 전달된다**는 점이다.

```text
x의 값 → a로 전달
y의 값 → b로 전달
```

## 5. 함수가 결과를 반환하는 경우

함수 안에서 계산한 결과를 `main()`에서 사용하려면 `return`을 사용한다.

```c
int add(int a, int b)
{
    return a + b;
}
```

이 함수는 두 정수를 더한 결과를 반환한다.

`main()`에서는 반환값을 변수에 저장할 수 있다.

```c
int main(void)
{
    int result;

    result = add(10, 20);

    printf("결과: %d\n", result);

    return 0;
}
```

여기서 핵심 코드는 다음과 같다.

```c
result = add(10, 20);
```

이 코드는 다음 순서로 이해하면 된다.

```text
1. add(10, 20)을 실행한다.
2. 함수 안에서 10 + 20을 계산한다.
3. return을 통해 30이 main으로 돌아온다.
4. 돌아온 값 30이 result에 저장된다.
```

즉, 다음 코드와 비슷한 흐름이다.

```c
result = 30;
```



## 6. 함수 안에서 scanf로 직접 입력받기

이제까지는 함수에서 입력받는 값을 입력할 수 없었지만 함수 안에 직접 `scanf()` 를 사용 하면 직접 값을 입력할 수 있다.

예를 들어 정수 두 개를 입력받아 더하는 함수를 만들면 다음과 같다.

```c
#include <stdio.h>

int add_input(void)
{
    int a, b;

    printf("정수 2개 입력: ");
    scanf("%d %d", &a, &b);

    return a + b;
}

int main(void)
{
    int result;

    result = add_input();

    printf("합계: %d\n", result);

    return 0;
}
```

여기서 함수 정의는 다음과 같다.

```c
int add_input(void)
```

이 뜻은 다음과 같다.

```text
main에서 따로 값을 받지 않는다.
함수 안에서 직접 입력받는다.
계산 결과는 int로 반환한다.
```

그래서 `main()`에서 호출할 때는 괄호 안에 값을 넣지 않는다.

```c
result = add_input();
```

괄호 안이 비어 있는 이유는 입력을 함수 안에서 직접 받기 때문이다.

실제 입력은 함수 안의 다음 코드에서 이루어진다.

```c
scanf("%d %d", &a, &b);
```

## 8. scanf에서 &를 붙이는 이유

`scanf()`는 입력받은 값을 저장할 위치가 필요하다.

그래서 일반 변수에 입력받을 때는 변수 앞에 `&`를 붙인다.

```c
int a;
scanf("%d", &a);
```

여기서 `&a`는 `a`의 주소를 뜻한다.

즉, 다음 의미다.

```text
입력받은 값을 a라는 변수의 위치에 저장해라.
```

정수 두 개를 입력받을 때도 마찬가지다.

```c
int a, b;
scanf("%d %d", &a, &b);
```

첫 번째 입력값은 `a`에 저장되고, 두 번째 입력값은 `b`에 저장된다.

```text
첫 번째 입력값 → a
두 번째 입력값 → b
```

예를 들어 사용자가 다음처럼 입력하면:

```text
3 5
```

변수에는 다음처럼 저장된다.

```text
a = 3
b = 5
```

## 9. main에서 입력받고 함수에 넘기는 방식

입력을 꼭 함수 안에서만 받을 필요는 없다.

`main()`에서 입력받고, 그 값을 함수에 넘길 수도 있다.

```c
#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int x, y;
    int result;

    printf("정수 2개 입력: ");
    scanf("%d %d", &x, &y);

    result = add(x, y);

    printf("합계: %d\n", result);

    return 0;
}
```

이 방식에서는 입력이 `main()`에서 이루어진다.

```c
scanf("%d %d", &x, &y);
```

그리고 입력받은 값을 함수에 넘긴다.

```c
result = add(x, y);
```

함수 안에서는 다음처럼 값이 들어간다.

```text
a = x의 값
b = y의 값
```

예를 들어 `x = 3`, `y = 5`라면 다음과 같다.

```text
a = 3
b = 5
```

## 10. 함수 안에서 입력받는 방식과 main에서 입력받는 방식 비교

같은 기능이라도 입력을 어디에서 받느냐에 따라 코드 구조가 달라진다.

### 1) main에서 입력받고 함수에 넘기는 방식

```c
int add(int a, int b)
{
    return a + b;
}

int main(void)
{
    int x, y;

    scanf("%d %d", &x, &y);

    printf("%d\n", add(x, y));

    return 0;
}
```

이 방식은 함수가 계산만 담당한다.

입력은 `main()`이 맡고, 계산은 `add()`가 맡는다.

### 2) 함수 안에서 직접 입력받는 방식

```c
int add_input(void)
{
    int a, b;

    scanf("%d %d", &a, &b);

    return a + b;
}

int main(void)
{
    printf("%d\n", add_input());

    return 0;
}
```

이 방식은 함수가 입력과 계산을 모두 담당한다.

두 방식 모두 가능하지만, 공부할 때는 차이를 이해하는 것이 중요하다.

| 방식 | 입력 위치 | 함수 호출 형태 | 특징 |
|---|---|---|---|
| main에서 입력 | `main()` | `add(x, y)` | 함수가 계산만 담당 |
| 함수 안에서 입력 | 함수 내부 | `add_input()` | 함수가 입력과 계산을 모두 담당 |

## 11. 함수 안에서 여러 값을 모두 사용하는 예시

여러 값을 입력받은 뒤, 그 값을 모두 사용하는 함수도 만들 수 있다.

예를 들어 이름, 국어 점수, 영어 점수를 입력받아 평균을 출력하는 함수를 만들 수 있다.

```c
#include <stdio.h>

void print_average(void)
{
    char name[20];
    int kor, eng;
    double avg;

    printf("이름 입력: ");
    scanf("%19s", name);

    printf("국어 영어 점수 입력: ");
    scanf("%d %d", &kor, &eng);

    avg = (kor + eng) / 2.0;

    printf("%s의 평균: %.2f\n", name, avg);
}

int main(void)
{
    print_average();

    return 0;
}
```

이 함수는 외부에서 값을 받지 않는다.

대신 함수 안에서 직접 입력받는다.

```c
scanf("%19s", name);
scanf("%d %d", &kor, &eng);
```

입력받은 값은 모두 사용된다.

```c
avg = (kor + eng) / 2.0;
printf("%s의 평균: %.2f\n", name, avg);
```

여기서 `name`은 출력에 사용되고, `kor`, `eng`는 평균 계산에 사용된다.

## 12. 문자열 입력에서 &를 붙이지 않는 경우

정수 변수에는 `scanf()`에서 `&`를 붙였다.

```c
int age;
scanf("%d", &age);
```

하지만 문자 배열로 문자열을 입력받을 때는 보통 `&`를 붙이지 않는다.

```c
char name[20];
scanf("%19s", name);
```

`name`은 배열 이름이고, 배열 이름은 배열의 시작 주소처럼 사용된다.

그래서 `scanf()`에 `name`만 써도 입력값을 저장할 위치를 전달할 수 있다.

또한 다음처럼 `%19s`를 사용하면 최대 19글자까지만 입력받는다.

```c
scanf("%19s", name);
```

배열 크기가 20이면 마지막 한 칸은 문자열의 끝을 나타내는 `\0`을 위해 남겨 둬야 한다.

따라서 `char name[20]`에는 `%19s`처럼 폭을 제한하는 것이 안전하다.

## 13. 함수를 나누면 코드가 더 읽기 쉬워진다

입력, 계산, 출력을 한 함수에 모두 넣을 수도 있지만, 역할별로 나누면 더 이해하기 쉽다.

```c
#include <stdio.h>

int add(int a, int b)
{
    return a + b;
}

void print_result(int result)
{
    printf("결과: %d\n", result);
}

int main(void)
{
    int x, y;
    int result;

    printf("정수 2개 입력: ");
    scanf("%d %d", &x, &y);

    result = add(x, y);
    print_result(result);

    return 0;
}
```

위 코드는 역할이 나뉘어 있다.

```text
main()        → 전체 흐름 담당
add()         → 계산 담당
print_result() → 출력 담당
```

이렇게 함수를 나누면 나중에 코드가 길어졌을 때 수정하기 쉬워진다.

## 14. 함수 호출에서 자주 하는 실수

### 1. 매개변수가 있는데 호출할 때 값을 안 넣는 경우

다음 함수는 정수 두 개를 받아야 한다.

```c
int add(int a, int b)
{
    return a + b;
}
```

그런데 이렇게 호출하면 잘못된 코드다.

```c
add();
```

`add` 함수는 `a`, `b`에 들어갈 값이 필요하기 때문이다.

올바른 호출은 다음과 같다.

```c
add(3, 5);
```

또는 변수로 넘길 수도 있다.

```c
int x = 3;
int y = 5;

add(x, y);
```

### 2. 매개변수가 없는데 호출할 때 값을 넣는 경우

다음 함수는 외부에서 값을 받지 않는다.

```c
int add_input(void)
{
    int a, b;

    scanf("%d %d", &a, &b);

    return a + b;
}
```

이 함수는 함수 안에서 직접 입력받으므로 호출할 때 값을 넣지 않는다.

```c
add_input();
```

다음처럼 호출하면 함수 정의와 맞지 않는다.

```c
add_input(3, 5);  // 잘못된 호출
```

### 3. 반환값을 사용하지 않는 경우

다음 함수는 결과를 반환한다.

```c
int add(int a, int b)
{
    return a + b;
}
```

그런데 이렇게만 호출하면 반환된 값을 저장하지 않는다.

```c
add(3, 5);
```

계산은 되지만 결과를 따로 사용하지 않는다.

결과를 사용하려면 변수에 저장하거나 바로 출력하면 된다.

```c
int result = add(3, 5);
printf("%d\n", result);
```

또는 다음처럼 바로 출력할 수도 있다.

```c
printf("%d\n", add(3, 5));
```



## 16. 오늘의 정리

함수는 코드를 기능별로 나누기 위해 사용한다.

함수를 호출할 때는 함수 이름 뒤에 괄호를 붙이고, 필요한 값이 있다면 괄호 안에 넣는다.

```c
add(3, 5);
```

함수 정의에 매개변수가 있으면 호출할 때 인자를 넣어야 한다.

```c
int add(int a, int b)
```

위 함수는 정수 두 개를 필요로 하므로 다음처럼 호출한다.

```c
add(10, 20);
```

함수 안에서 직접 입력을 받을 수도 있다.

```c
int add_input(void)
{
    int a, b;
    scanf("%d %d", &a, &b);
    return a + b;
}
```

이 경우에는 `main()`에서 값을 넘기지 않고 함수만 호출한다.

```c
add_input();
```

한 줄로 정리하면 다음과 같다.

```text
함수에 값을 넘길 때는 main에서 인자를 넣어 호출하고,
함수 안에서 직접 입력받을 때는 매개변수 없이 scanf를 사용하면 된다.
```
