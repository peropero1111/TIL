# TIL - 문자열 가공 함수와 포인터 기초

> 원본 파일: `20260518.c`  
> 학습 주제: 문자열 입력, 문자열 역순 복사, 알파벳만 복사, 대문자 변환, 포인터 기초

## 오늘 배운 내용

C에서 문자열은 `char` 배열이며, 문자열의 끝은 항상 널 문자 `\0`으로 표시된다. 이번 코드에서는 입력받은 문자열을 다른 배열에 복사하면서 역순으로 만들거나, 알파벳만 골라 복사하거나, 소문자를 대문자로 바꾸는 함수를 작성했다.

또한 `char*`, `int*`, `float*`처럼 자료형에 맞는 포인터 변수를 선언하면서 포인터가 “값”이 아니라 “메모리 주소”를 저장하는 변수라는 점도 확인했다.

## 핵심 개념

### 1. 문자열 입력과 `\0`

```c
char str1[128];
scanf("%[^\n]s", str1);
printf("%s\n", str1);
```

`%[^\n]`은 줄바꿈 문자를 만나기 전까지 입력을 받는 형식이다. 문자열은 배열에 저장되며, 문자열의 끝에는 `\0`이 들어가야 한다.

다만 위 코드는 입력 길이를 제한하지 않으므로 배열 크기보다 긴 문자열이 들어오면 위험하다. 더 안전하게는 다음처럼 최대 길이를 지정하는 것이 좋다.

```c
scanf("%127[^\n]", str1);
```

`str1`의 크기가 128이므로 실제 문자 127개까지 받고, 마지막 한 칸은 `\0`을 위해 남겨 둔다.

### 2. 문자열을 거꾸로 복사하기

```c
void cpybackward(char* p, char* q)
{
    int i = 0;
    while (q[i] != 0) {
        p[i] = q[i];
        i++;
    }
    p[i] = '\0';

    int k = 0;
    i -= 1;
    while (i >= 0) {
        p[k] = q[i];
        k++;
        i--;
    }
    p[k] = '\0';
}
```

`cpybackward`라는 함수를 선언 한 후 원본 문자열 `q`의 끝 위치를 찾은 뒤, 마지막 문자부터 앞으로 읽으면서 `p`에 저장한다. 예를 들어 `hello`를 입력하면 `olleh`가 된다.

조금 더 간단하게 정리하면 다음과 같이 쓸 수 있다.

```c
void cpybackward(char* p, const char* q)
{
    int len = 0;
    int i;

    while (q[len] != '\0') {
        len++;
    }

    for (i = 0; i < len; i++) {
        p[i] = q[len - 1 - i];
    }

    p[len] = '\0';
}
```

문자열을 새로 만들 때는 마지막에 반드시 `\0`을 넣어야 한다.

### 3. 알파벳만 복사하기

```c
void cpyalpha(char* a, char* b)
{
    int i = 0;
    int k = 0;

    while (b[i] != 0) {
        if (b[i] >= 'A' && b[i] <= 'z') {
            a[k] = b[i];
            k++;
        }
        i++;
    }

    a[k] = '\0';
}
```

이 함수는 원본 문자열 `b`를 훑으면서 조건에 맞는 문자만 결과 배열 `a`에 저장한다. 여기서 중요한 점은 읽는 위치 `i`와 쓰는 위치 `k`를 따로 둔다는 것이다.

하지만 `'A' <= 문자 <= 'z'` 범위에는 알파벳이 아닌 문자도 포함된다. ASCII 코드에서 대문자와 소문자 사이에는 `[`, `\`, `]`, `^`, `_`, `` ` `` 같은 문자가 있기 때문이다. 따라서 알파벳만 정확히 고르려면 대문자와 소문자를 나누어 검사하는 것이 안전하다.

```c
if (('A' <= b[i] && b[i] <= 'Z') || ('a' <= b[i] && b[i] <= 'z')) {
    a[k] = b[i];
    k++;
}
```

### 4. 소문자를 대문자로 바꾸기

```c
void cpycaptial(char* c, char* d)
{
    int i = 0;
    while (d[i] != 0) {
        if (d[i] >= 'a' && d[i] <= 'z') {
            c[i] = 'A' + 'A' - 'a';
        }
        else {
            c[i] = d[i];
        }
        i++;
    }
}
```

의도는 소문자를 대문자로 변환하는 것이지만, 현재 코드는 모든 소문자에 같은 값을 넣는다. `'A' + 'A' - 'a'`는 원본 문자 `d[i]`를 사용하지 않기 때문에 대문자 변환이 되지 않는다.


소문자를 대문자로 바꾸려면 원본 문자에서 대소문자 차이를 빼야 한다.

```c
c[i] = d[i] - ('a' - 'A');
```

또는 다음처럼 쓸 수도 있다.

```c
c[i] = d[i] + ('A' - 'a');
```

수정한 함수는 다음과 같다.

```c
void cpycapital(char* c, const char* d)
{
    int i = 0;

    while (d[i] != '\0') {
        if ('a' <= d[i] && d[i] <= 'z') {
            c[i] = d[i] - ('a' - 'A');
        }
        else {
            c[i] = d[i];
        }
        i++;
    }

    c[i] = '\0';
}
```

이 함수에서도 마지막에 `c[i] = '\0';`을 넣어야 결과 배열이 올바른 문자열이 된다.

혹은 ASCII 값 +26을 하여도 된다.

## 포인터 기초 정리

```c
float fv;
int iv;
char cv;

float* fp;
int* ip;
char* cp;
```

포인터는 메모리 주소를 저장하는 변수이다.

- `float* fp`는 `float`형 변수의 주소를 저장할 수 있다.
- `int* ip`는 `int`형 변수의 주소를 저장할 수 있다.
- `char* cp`는 `char`형 변수 또는 문자열의 시작 주소를 저장할 수 있다.

문자열 배열 이름은 첫 번째 원소의 주소처럼 사용할 수 있다.

```c
char str1[128];
```

위 코드에서 `str1`은 대부분의 상황에서 `&str1[0]`처럼 동작한다. 그래서 `scanf`에 문자열을 입력받을 때 `&str1`이 아니라 `str1`을 넘긴다.

## 코드에서 주의할 점

- `cpycaptial`은 오타로 보이며, 의미상 `cpycapital`이 더 자연스럽다.
- `c[i] = 'A' + 'A' - 'a';`는 소문자를 대문자로 변환하지 못한다.
- `cpycaptial` 함수 끝에도 `c[i] = '\0';`을 넣어야 한다.
- `b[i] >= 'A' && b[i] <= 'z'`는 알파벳만 검사하는 조건이 아니다.
- `scanf("%[^\n]s", str1)`보다는 `scanf("%127[^\n]", str1)`처럼 입력 길이를 제한하는 것이 안전하다.

## 실행 예시


## 오늘의 정리

문자열을 직접 다룰 때는 `\0`을 기준으로 어디까지 읽을지 결정하고, 결과 문자열에도 마지막에 반드시 `\0`을 넣어야 한다. 또한 문자를 필터링할 때는 읽는 인덱스와 쓰는 인덱스를 분리하면 좋다. ASCII 값을 이용해 대소문자를 변환할 수 있지만, 변환할 때는 반드시 원본 문자 값을 기준으로 계산해야 한다.
