# TIL - 중첩 반복문으로 문자 패턴 출력하기

> 원본 파일: `20260408.c`  
> 학습 주제: 행/열 반복, 좌표 조건, 문자 패턴 출력

## 오늘 배운 내용

행과 열을 의미하는 `i`, `j`를 사용해 2차원 문자 패턴을 출력하는 방법을 연습했다. 입력받은 `n`, `m`에 따라 `n`행 `m`열의 형태를 만들고, 특정 위치에만 다른 문자를 출력했다.

## 핵심 개념

### 1. 행과 열을 만드는 중첩 반복문

```c
for (i = 0; i < n; i++) {
    for (j = 0; j < m; j++) {
        printf("X");
    }
    printf("\n");
}
```

바깥 반복문은 행을 담당하고, 안쪽 반복문은 열을 담당한다. 한 행을 모두 출력한 뒤 `printf("\n")`으로 줄을 바꾼다.

### 2. 특정 좌표에만 다른 문자 출력하기

```c
if (i + j == n - 1) {
    printf("/");
} else {
    printf("X");
}
```

`i + j == n - 1` 조건은 정사각형에서 오른쪽 위에서 왼쪽 아래로 내려가는 대각선 위치를 의미한다.

예를 들어 `n = 3`, `m = 3`이면 다음과 같은 형태가 된다.

```text
XX/
X/X
/XX
```

## 다른 패턴으로 확장하기

주석에 있던 테두리 패턴은 첫 줄, 마지막 줄, 첫 열, 마지막 열을 조건으로 구분하면 만들 수 있다.

```c
if (i == 0 || i == n - 1 || j == 0 || j == m - 1) {
    printf("0");
} else {
    printf("*");
}
```

예를 들어 `3 5`를 입력하면 다음 형태를 만들 수 있다.

```text
00000
0***0
00000
```

## 코드에서 주의할 점

- `n x m` 직사각형에서 대각선 조건을 만들 때는 어떤 기준을 쓸지 명확히 해야 한다.
- `i + j == n - 1`은 `n x n` 정사각형에서 가장 자연스럽다.
- `m`이 `n`과 다르면 대각선이 기대한 위치와 다르게 보일 수 있다.
- `printf("\n")`은 안쪽 반복문이 끝난 뒤 실행해야 한다.

## 오늘의 정리

문자 패턴 문제는 좌표 조건을 찾는 문제이다. `i`는 행, `j`는 열이라고 생각하고, 출력할 위치의 규칙을 `if` 조건으로 표현하면 다양한 모양을 만들 수 있다.
