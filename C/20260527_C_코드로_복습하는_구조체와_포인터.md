## 1. 구조체란 무엇인가

구조체는 서로 다른 자료형의 변수를 하나로 묶어 새로운 자료형처럼 사용할 수 있게 해 준다.

예를 들어 학생 한 명의 정보를 저장하려면 이름, 학번, 성적이 필요하다.

```c
char name[32];
int id;
float grade;
```

이 세 변수를 따로 관리할 수도 있지만, 하나의 학생 정보로 묶는 것이 더 편하다.

```c
typedef struct
{
    char name[32];
    int id;
    float grade;
} student;
```

위 코드는 `student`라는 새로운 자료형을 만든다.

이제 다음처럼 학생 변수를 선언할 수 있다.

```c
student a;
student b;
```

`typedef`를 사용하지 않았다면 보통 이렇게 써야 한다.

```c
struct student a;
```

하지만 `typedef`를 사용하면 `student a;`처럼 더 짧고 편하게 쓸 수 있다.

## 2. 구조체 멤버 접근: `.` 연산자

구조체 변수에서 멤버에 접근할 때는 `.` 연산자를 사용한다.

```c
student a;

a.id = 20260527;
a.grade = 95.5f;
```

출력할 때도 마찬가지다.

```c
printf("%d %.2f\n", a.id, a.grade);
```

정리하면 다음과 같다.

```text
구조체 변수.멤버이름
```

예를 들면 다음과 같다.

```c
a.name
a.id
a.grade
```

## 3. 구조체 포인터와 `->` 연산자

구조체 포인터는 구조체 변수의 주소를 저장하는 포인터다.

```c
student a;
student *ptr;

ptr = &a;
```

여기서 `ptr`은 `a`의 주소를 가지고 있다. ( `ptr = &a;` 때문에 )

구조체 포인터를 통해 멤버에 접근할 때는 `->` 연산자를 사용한다.

```c
ptr->id = 20260527;
ptr->grade = 90.0f;
```

이 코드는 아래 코드와 같은 의미다.

```c
(*ptr).id = 20260527;
(*ptr).grade = 90.0f;
```

즉, `->`는 구조체 포인터에서 멤버에 접근하기 쉽게 만든 문법이다.

```text
p->id
```

은 다음과 같다.

```text
(*p).id
```

## 4. `.` 과 `->` 차이

| 상황 | 사용하는 연산자 | 예시 |
|---|---|---|
| 구조체 변수로 접근 | `.` | `a.id` |
| 구조체 포인터로 접근 | `->` | `p->id` |
| 구조체 포인터를 역참조해서 접근 | `.` | `(*p).id` |

따라서 아래 두 코드는 같은 의미다.

```c
scanf("%d", &(*p).id);
scanf("%d", &p->id);
```

다만 실제 코드에서는 `p->id`가 더 읽기 쉽다.

## 5. 함수에 구조체 주소를 넘기기

원본 코드에는 학생 정보를 입력받는 함수 형태가 있었다.

```c
void scan_student(student *p)
{
    scanf("%s", p->name);
    scanf("%d", &p->id);
    scanf("%f", &p->grade);
}
```

이 함수의 매개변수 `p`는 `student` 구조체 변수의 주소를 받는다.

호출할 때는 다음처럼 `&a`를 넘긴다.

```c
student a;
scan_student(&a);
```

여기서 중요한 점은 다음과 같다.

```text
&a  → 구조체 변수 a의 주소
p   → a의 주소를 저장한 포인터
*p  → 주소를 따라가서 만난 원본 구조체 a
```

즉 함수 안에서 `p->id`를 수정하면, 함수 밖의 `a.id`도 실제로 바뀐다.

## 6. `scanf()`에서 `&`를 붙이는 경우와 붙이지 않는 경우

`scanf()`는 값을 저장할 위치, 즉 주소를 필요로 한다.

정수와 실수 변수는 변수 이름만 쓰면 값 자체를 의미하므로 주소 연산자 `&`가 필요하다.

```c
scanf("%d", &p->id);
scanf("%f", &p->grade);
```

하지만 문자 배열 이름은 배열의 시작 주소처럼 사용된다.

```c
scanf("%s", p->name);
```

따라서 `p->name`에는 보통 `&`를 붙이지 않는다.

다만 안전하게 입력받으려면 배열 크기를 고려해서 폭을 제한하는 것이 좋다.

```c
scanf("%31s", p->name);
```

`name` 배열의 크기가 32이므로, 최대 31글자까지만 입력받고 마지막 한 칸은 문자열 끝을 나타내는 `\0`을 위해 남겨 둔다.

## 7. 잘못된 입력 예시: 구조체 전체에 `%d`로 입력할 수 없다

원본 코드에는 다음과 같은 내용이 있다.

```c
scanf("%d", &a); // 오류
```

`a`는 `student` 구조체 변수다. 구조체 전체는 정수 하나가 아니기 때문에 `%d`로 입력받을 수 없다.

잘못된 방식이다.

```c
student a;
scanf("%d", &a);     // 잘못된 코드
```

올바른 방식은 구조체의 각 멤버를 따로 입력받는 것이다.

```c
scanf("%31s", a.name);
scanf("%d", &a.id);
scanf("%f", &a.grade);
```

또는 입력 함수를 만들어서 사용하는 것이 좋다.

```c
scan_student(&a);
```

## 8. 값 전달과 주소 전달

원본 코드에는 다음과 같은 내용이 있다.

```c
void squared(int *ptr)
{
    *ptr *= *ptr;
}
```

이 함수는 `int` 변수의 주소를 받는다.

```c
int i = 88;
squared(&i);
printf("%d\n", i);
```

`&i`를 넘기면 함수 안에서 `i`의 원본 값을 바꿀 수 있다.

```text
처음 i = 88
squared(&i) 실행
i = 88 * 88
결과 i = 7744
```

반대로 값을 그대로 넘기면 함수 안에서는 복사본만 바뀐다.

```c
void squared_value(int value)
{
    value *= value;
}
```

```c
int i = 88;
squared_value(i);
printf("%d\n", i);  // 여전히 88
```

정리하면 다음과 같다.

| 방식 | 함수 호출 | 원본 값 변경 여부 |
|---|---|---|
| 값 전달 | `squared_value(i)` | 변경되지 않음 |
| 주소 전달 | `squared(&i)` | 변경됨 |

## 9. 포인터는 변수의 메모리 주소를 저장한다

포인터는 변수의 값을 직접 저장하는 것이 아니라, 변수의 메모리 주소를 저장한다.

```c
char c = '9';
char *cptr;

cptr = &c;
```

여기서 의미는 다음과 같다.

```text
c     → 문자 '9' 자체
&c    → c의 메모리 주소
cptr  → c의 주소를 저장하는 포인터
*cptr → cptr이 가리키는 위치에 있는 값, 즉 '9'
```

출력할 때는 포인터 주소를 `%u`보다 `%p`로 출력하는 것이 더 적절하다.

```c
printf("%p %c\n", (void *)cptr, *cptr);
```

`%p`는 포인터 주소를 출력하기 위한 서식 지정자다.

## 10. 함수 인자의 자료형과 순서에 주의하기

원본 코드에는 다음 함수 형태도 있었다.

```c
int sum(char a, double b)
{
    printf("%c", a);
    return 0;
}
```

이 함수는 첫 번째 인자로 `char`, 두 번째 인자로 `double`을 받는다.

따라서 호출할 때는 다음처럼 자료형 순서를 맞추는 것이 좋다.

```c
double k = 8.88;
sum('5', k);
```

만약 다음처럼 호출하면 의도와 다르게 형변환이 일어날 수 있다.

```c
sum(k, '5');  // 좋지 않은 예
```

첫 번째 인자는 `char`인데 `k`는 `double`이고, 두 번째 인자는 `double`인데 `'5'`는 `char`이다.

C에서는 어느 정도 자동 형변환이 일어날 수 있지만, 초보 단계에서는 함수 정의와 호출부의 자료형 순서를 정확히 맞추는 습관이 중요하다.

## 11. `sizeof(student)`가 의미하는 것

`sizeof`는 자료형이나 변수의 메모리 크기를 byte 단위로 알려 준다.

```c
printf("%zu %zu\n", sizeof(char), sizeof(student));
```

`char`는 항상 1B이다.

```text
sizeof(char) == 1
```

`student` 구조체는 다음 멤버를 가진다.

```c
char name[32];  // 32B
int id;         // 보통 4B
float grade;    // 보통 4B
```

일반적인 환경에서는 다음과 같이 계산할 수 있다.

```text
name  : 32B
id    : 4B
grade : 4B
합계  : 40B
```

따라서 보통 `sizeof(student)`는 40B가 된다.

다만 구조체 크기는 컴파일러, 시스템, 정렬 기준에 따라 패딩이 붙을 수 있으므로 정확한 값은 직접 `sizeof`로 확인하는 것이 좋다.


## 12. 구조체를 함수에 넘길 때 값으로 넘길지, 주소로 넘길지 선택하기

구조체를 함수에 넘기는 방법은 크게 두 가지다.

### 1) 구조체 값을 넘기는 방식

```c
void print_student(student s)
{
    printf("%s %d %.2f\n", s.name, s.id, s.grade);
}
```

이 방식은 구조체가 복사되어 함수에 전달된다.

함수 안에서 `s`를 수정해도 원본 구조체는 바뀌지 않는다.

출력처럼 값을 읽기만 할 때 적합하다.

### 2) 구조체 주소를 넘기는 방식

```c
void scan_student(student *p)
{
    scanf("%31s", p->name);
    scanf("%d", &p->id);
    scanf("%f", &p->grade);
}
```

이 방식은 원본 구조체의 주소를 전달한다.

함수 안에서 `p->id`, `p->grade` 등을 수정하면 원본 값이 바뀐다.

입력, 수정, 업데이트처럼 원본을 바꿔야 할 때 적합하다.

| 목적 | 추천 방식 | 이유 |
|---|---|---|
| 값만 출력 | 구조체 값 전달 | 원본 수정 필요 없음 |
| 값 입력 | 구조체 포인터 전달 | 원본을 수정해야 함 |
| 값 수정 | 구조체 포인터 전달 | 함수 밖의 값도 바뀌어야 함 |
| 큰 구조체 처리 | 구조체 포인터 전달 | 복사 비용을 줄일 수 있음 |

## 13. 코드에서 주의할 점


### 1. 포인터는 사용하기 전에 유효한 주소를 가져야 한다

```c
student *ptr;
```

위 코드는 포인터 변수만 만든 것이다. 아직 어떤 학생을 가리키는지 정해지지 않았다.

사용하려면 먼저 주소를 넣어야 한다.

```c
student a;
student *ptr = &a;
```

### 2. `scanf()`에서 배열이 아닌 변수에는 `&`가 필요하다

```c
scanf("%d", &p->id);
scanf("%f", &p->grade);
```

하지만 문자열 배열은 다음처럼 쓴다.

```c
scanf("%31s", p->name);
```

### 3. 함수 매개변수 이름도 자료형과 함께 써야 한다

다음 코드는 잘못된 형태다.

```c
void squared(int, ptr)
{
    ptr *= ptr;
}
```

올바르게 쓰려면 매개변수 이름과 자료형을 함께 작성해야 한다.

```c
void squared_value(int ptr)
{
    ptr *= ptr;
}
```

다만 이 함수는 값 전달이므로 원본 변수는 바뀌지 않는다.

## 16. 오늘의 정리

구조체는 여러 데이터를 하나로 묶는 자료형이다.

```c
typedef struct
{
    char name[32];
    int id;
    float grade;
} student;
```

구조체 변수의 멤버에 접근할 때는 `.`을 사용한다.

```c
a.id
```

구조체 포인터의 멤버에 접근할 때는 `->`를 사용한다.

```c
p->id
```

함수 안에서 원본 값을 바꾸고 싶다면 값이 아니라 주소를 넘겨야 한다.

```c
scan_student(&a);
squared(&i);
```

한 줄로 정리하면 다음과 같다.

```text
구조체는 여러 값을 하나로 묶고,
포인터는 그 구조체의 주소를 통해 원본 값을 수정할 수 있게 해 준다.
```
