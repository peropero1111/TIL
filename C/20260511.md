# TIL - 포인터 매개변수와 포인터 연산

> 원본 파일: `20260511.c`  
> 학습 주제: 포인터 매개변수, 배열 구간 합, 주소 출력, 역방향 순회

## 오늘 배운 내용

함수에 포인터를 매개변수로 넘기는 방법과 포인터 연산을 이용해 배열을 순회하는 방법을 배웠다. `scanf()`에 주소를 넘기는 이유, 배열의 일부 구간 합산, 포인터를 증가/감소시키며 출력하는 방식을 확인했다.

## 핵심 개념

### 1. `scanf()`와 주소 전달

```c
void scanf_3floats(float* p, float* q, float* r) {
    scanf("%f %f %f", p, q, r);
}
```

`scanf()`는 입력받은 값을 변수에 저장해야 하므로 변수의 주소가 필요하다. 이미 `p`, `q`, `r`이 주소를 담은 포인터이므로 `scanf()`에 그대로 넘길 수 있다. ( & 를 사용하지 않아도 된다.)

main 에서 호출할 때는 다음처럼 실제 변수의 주소를 넘긴다.

```c
scanf_3floats(&f1, &f2, &f3);
```

### 2. 포인터로 배열 구간 합 구하기

```c
int sum(int* p, int size) {
    int total = 0;

    for (int i = 0; i < size; i++) {
        total += p[i];
    }

    return total;
}
```

`p[i]`는 `*(p + i)`와 같은 의미이다. 예를 들어 `sum(&ia[1], 3)`은 `ia[1]`, `ia[2]`, `ia[3]`을 더한다.

```text
ia = {4, 5, 6, 7, 8, 9}
sum(&ia[1], 3) = 5 + 6 + 7
```

### 3. 포인터 증가와 자료형 크기

```c
char* cp;
int* ip;
```

`cp + 1`은 다음 `char` 위치로 이동하고 ( 1만큼 이동 ), `ip + 1`은 다음 `int` 위치로 이동한다 ( 4 만큼 이동 ). 실제 주소 증가량은 자료형 크기에 따라 달라진다.

그래서 `char*`와 `int*`를 출력해 보면 주소가 증가하는 간격이 다르게 보인다.

### 4. 역방향 순회

```c
void print_backward(int* p, int* q) {
    int* ptr;
    for (ptr = p; ptr > q; ptr--) {
        printf("%d ", *ptr);
    }
    printf("\n");
}
```

포인터도 `--` 연산으로 이전 요소를 가리키게 할 수 있다. 단, 위 조건은 `ptr > q`이므로 `q`가 가리키는 요소는 출력하지 않는다.

## 코드에서 주의할 점

- `scanf_3floats()`는 값을 반환하지 않으므로 반환형을 `float`보다 `void`로 쓰는 것이 자연스럽다.
- 주소 출력에는 `%u`보다 `%p`를 사용하고 `(void*)`로 캐스팅하는 것이 좋다.

## 오늘의 정리

배열 이름과 포인터는 밀접하게 연결되어 있다. 함수에 배열 일부의 시작 주소와 크기를 넘기면 원하는 구간만 처리할 수 있다. 포인터 연산은 자료형의 크기를 기준으로 이동한다는 점을 꼭 기억해야 한다.
