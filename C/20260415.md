# TIL - 배열 순회, 역순 출력, 짝수 합계, 숫자 뒤집기

> 원본 파일: `20260415.c`  
> 학습 주제: 배열, 반복문, 형변환, `%`, `/`

## 오늘 배운 내용

배열을 선언하고 반복문으로 값을 채운 뒤, 역순 출력, 짝수 판별, 짝수 합계 계산, 배열 복사, 정수 뒤집기를 연습했다.

## 핵심 개념

### 1. 배열 크기를 매크로로 관리하기

```c
#define SIZE 3

float fa[SIZE] = { 0 };
```

`SIZE`를 사용하면 배열 크기를 한 곳에서 관리할 수 있다. `{ 0 }`으로 초기화하면 배열 요소가 0으로 초기화된다.

### 2. 배열 채우기와 출력

```c
for (i = 0; i < SIZE; i++) {
    fa[i] = rand() % 100;
}

for (i = 0; i < SIZE; i++) {
    printf("%0.2f ", fa[i]);
}
```

`rand() % 100`은 정수를 만들지만, `float` 배열에 대입하면 실수 형태로 저장된다.

### 3. `rand() % 100`에서 생길 수 있는 모듈러 편향

`rand() % 100`은 사용하기 쉽지만, 모든 숫자가 완전히 같은 확률로 나오지 않을 수 있다. `rand()`는 `0`부터 `RAND_MAX`까지의 값을 만들고, 가능한 값의 개수는 `RAND_MAX + 1`개이다. 이 개수가 100으로 딱 나누어떨어지지 않으면 일부 숫자가 다른 숫자보다 조금 더 자주 나올 수 있다.

예를 들어 `RAND_MAX`가 `32767`이면 가능한 값은 총 `32768`개이다.

```text
32768 = 100 * 327 + 68
```

따라서 `rand() % 100`을 하면 `0`부터 `67`까지는 한 번씩 더 대응될 수 있고, `68`부터 `99`까지는 상대적으로 덜 나올 수 있다. 이런 현상을 **모듈러 편향(modulo bias)** 이라고 한다.

### 4. 해결 방법: 거절 샘플링으로 난수 만들기

남는 구간을 버리고 다시 난수를 뽑으면 편향을 줄일 수 있다.

```c
#include <stdlib.h>
#include <time.h>

int rand_range(int n)
{
    unsigned long r;
    unsigned long range = (unsigned long)RAND_MAX + 1UL;
    unsigned long limit;

    if (n <= 0 || (unsigned long)n > range) {
        return -1;
    }

    limit = range - (range % (unsigned long)n);

    do {
        r = (unsigned long)rand();
    } while (r >= limit);

    return (int)(r % (unsigned long)n);
}
```

배열에 값을 넣을 때는 `rand() % 100` 대신 `rand_range(100)`을 사용할 수 있다.

```c
srand(time(NULL));

for (i = 0; i < SIZE; i++) {
    fa[i] = (float)rand_range(100);
}
```

`fa`는 `float` 배열이므로 `rand_range(100)`으로 만든 정수를 `(float)`으로 변환해서 저장했다.

### 5. 배열 역순 출력

```c
for (i = 0; i < SIZE; i++) {
    printf("%0.2f ", fa[SIZE - i - 1]);
}
```

인덱스는 `0`부터 시작하므로 마지막 요소는 `SIZE - 1`이다.

### 6. 짝수 판별과 합계

```c
float sum = 0;

for (i = 0; i < SIZE; i++) {
    if ((int)fa[i] % 2 == 0) {
        sum += fa[i];
    }
}
```

`fa[i]`가 `float`이므로 `%` 연산자를 직접 사용할 수 없다. 정수로 변환한 뒤 나머지 연산을 한다.

## 배열 복사

C에서는 배열끼리 통째로 대입할 수 없다.

```c
// ia = fa; // 불가능
```

요소를 하나씩 복사해야 한다.

```c
for (i = 0; i < SIZE; i++) {
    ia[i] = (int)fa[i];
}
```

## 정수 뒤집기

정수를 뒤집을 때는 나머지와 나눗셈을 사용한다.

```c
while (x > 0) {
    y = x % 10;
    z = z * 10 + y;
    x = x / 10;
}
```

예를 들어 `416743`은 `347614`로 뒤집힌다.

## 주의할 점

- `sum`처럼 누적하는 변수는 반드시 `0`으로 초기화해야 한다.
- 실수를 정수로 변환하면 소수점 아래가 버려진다.
- `rand()` 결과를 매번 다르게 만들고 싶다면 `srand(time(NULL))`와 `#include <time.h>`를 함께 사용한다.
- `rand() % 100`은 모듈러 편향이 생길 수 있으므로, 값이 더 균등하게 나와야 한다면 `rand_range(100)`처럼 거절 샘플링을 사용한다.
- 배열 인덱스는 항상 `0`부터 `SIZE - 1`까지이다.

## 오늘의 정리

배열 문제는 반복문과 인덱스 계산이 핵심이다. 특히 역순 출력에서는 `SIZE - i - 1`, 숫자 뒤집기에서는 `% 10`과 `/ 10` 패턴을 기억하면 좋다.
