# TIL - for문과 while문으로 중첩 반복 구현하기

> 원본 파일: `20260406.c`  
> 학습 주제: `for`, `while`, 중첩 반복문, 입력 검증

## 오늘 배운 내용

`for`문과 `while`문을 사용해 `n x n` 형태의 좌표를 출력하는 중첩 반복문을 연습했다. 또한 입력값이 조건을 만족할 때까지 다시 입력받는 구조도 확인했다.

## 핵심 개념

### 1. `for`문의 구조

```c
for (i = 0; i < n; i++) {
    for (j = 0; j < n; j++) {
        printf("(%d %d)", i, j);
    }
    printf("\n");
}
```

`for`문은 초기식, 조건식, 증감식이 한 줄에 모여 있어 반복 횟수가 명확할 때 사용하기 좋다.

```c
for (초기식; 조건식; 증감식) {
    실행문;
}
```

### 2. `while`문으로 같은 구조 만들기

`while`문은 조건식만 가지고 반복한다. 따라서 반복 변수 초기화와 증감을 직접 작성해야 한다.

```c
i = 0;
while (i < n) {
    j = 0;
    while (j < n) {
        printf("(%d %d)", i, j);
        j++;
    }
    printf("\n");
    i++;
}
```

안쪽 반복문을 새로 시작할 때마다 `j = 0;`으로 초기화해야 한다.

## 입력 검증

`1 < n < 8` 조건을 만족할 때까지 입력받고 싶다면 `do-while`이 자연스럽다. 최소 한 번은 입력을 받아야 하기 때문이다.

```c
do {
    printf("Enter 1 < n < 8: ");
    scanf("%d", &n);
} while (!(1 < n && n < 8));
```

C에서는 수학식처럼 `1 < n < 8`을 그대로 쓰면 의도와 다르게 동작한다. 반드시 `1 < n && n < 8`처럼 논리 연산자 `&&`를 사용해야 한다.

## 코드에서 주의할 점

- `n`을 입력받기 전에 `while (1 < n && n < 8)`에서 사용하면 초기화되지 않은 값을 비교하게 된다.
- `while` 버전에서는 `i`, `j`를 사용하기 전에 반드시 초기화해야 한다.
- 바깥 반복이 한 번 돌 때마다 안쪽 반복 변수 `j`를 다시 `0`으로 만들어야 한다.
- `for`문 실행 후 `i` 값은 이미 `n`이 되어 있으므로, 이어서 `while (i < n)`을 실행하려면 `i = 0;`으로 다시 초기화해야 한다.

## 오늘의 정리

`for`문과 `while`문은 서로 바꿔 쓸 수 있지만, `while`문은 초기화와 증감식을 직접 관리해야 한다. 중첩 반복문에서는 안쪽 반복 변수의 초기화 위치가 특히 중요하다.
