# TIL - 포인터, 주소, 역참조, 값 전달과 주소 전달

> 원본 파일: `20260506.c`  
> 학습 주제: 포인터, `&`, `*`, 함수 매개변수, 배열과 주소

## 오늘 배운 내용

포인터를 사용해 변수의 주소를 저장하고, 주소를 통해 값을 바꾸는 방법을 연습했다. 특히 `swap_value()`와 `swap()`을 비교하면서 값에 의한 전달과 주소에 의한 전달의 차이를 확인했다.

## 핵심 개념

### 1. 값에 의한 전달

```c
void swap_value(char a, char b) {
    char temp;
    temp = a;
    a = b;
    b = temp;
}
```

이 함수는 `x`, `y`의 값을 복사해서 `a`, `b`로 받는다. 함수 안에서 `a`, `b`를 바꿔도 실제 값이 바뀌지 않았기 때문에 원래 변수 `x`, `y`는 바뀌지 않는다.

### 2. 주소에 의한 전달

```c
void swap(char* a, char* b) {
    char temp;
    temp = *a;
    *a = *b;
    *b = temp;
}
```

`char*`는 `char` 변수의 주소를 저장하는 포인터이다. `*a`는 주소 `a`가 가리키는 실제 값을 의미한다.

```c
swap(&x, &y);
```

`&x`, `&y`를 넘기면 함수 안에서 원래 변수의 값을 직접 바꿀 수 있다. (실제 값이 바뀌기 때문)

## 포인터 기본 문법

```c
int i = 77;
int* p = NULL;

p = &i;
printf("%d\n", *p);
```

- `&i`: 변수 `i`의 주소
- `p`: 주소를 저장하는 포인터 변수
- `*p`: 포인터가 가리키는 위치의 실제 값
- `NULL`: 아직 아무 주소도 가리키지 않는 포인터 상태

## 배열과 포인터

```c
double d[5] = { 2, 5, 6, 4, 9 };
```

배열 이름 `d`는 대부분의 식에서 첫 번째 요소의 주소처럼 사용된다. 따라서 `d + 1`은 다음 `double` 요소의 주소를 의미한다.

## 코드에서 주의할 점

이번 파일에는 포인터 연습 과정에서 고쳐야 할 부분이 있다.

```c
ptr = max(&m, &n, &r);
```

`max`라는 함수가 정의되어 있지 않으므로 컴파일되지 않는다. 의도한 함수명이 `mymax`라면 이름을 맞춰야 한다. 다만 현재 `mymax`의 반환형도 `double`이고 실제로는 포인터처럼 값을 반환하려 하므로 설계를 다시 해야 한다.

```c
printf(d, 5);
```

배열 출력 함수를 호출하려는 의도라면 `printf`가 아니라 직접 만든 `print` 함수를 호출해야 한다.

```c
print(d, 5);
```

주소를 출력할 때는 `%u`보다 `%p`를 사용하는 것이 적절하다.

```c
printf("%p\n", (void*)p);
```

또한 `print()` 함수 안에서 `*(p + 1)`을 반복 출력하고 있는데, 각 요소를 출력하려면 `*(p + i)`가 되어야 한다.

## 오늘의 정리

포인터는 변수의 주소를 저장하고, 그 주소를 통해 실제 값을 다룰 수 있게 해 준다. 함수에서 원래 변수의 값을 바꾸고 싶다면 값이 아니라 주소를 넘겨야 한다. 포인터는 강력하지만, 타입과 반환형이 맞지 않으면 오류나 위험한 동작이 생기므로 주의가 필요하다.
